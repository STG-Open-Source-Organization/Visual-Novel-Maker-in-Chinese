更改游戏字体

 

C更改游戏的字体可以为您的游戏带来很多个性。需要注意的是，有四个区域您可能希望更改字体以保持一致性。

 

  • 冒险（ADV）消息文本 - 使用默认消息框时。
  • 小说（NVL）消息文本 - 使用 NVL 命令时。
  • 日志消息文本 - 查看日志时。
  • 自定义消息文本 - 使用设置消息区域时。

 

您可以通过多种方式执行此操作。

  • 文本代码
  • 消息设置
  • 脚本调用
  • 脚本编辑器

 

使用脚本编辑器

如果您足够勇敢，我们可以使用脚本编辑器来更改字体。

 

  • 转到脚本编辑器。
  • 右键单击 -> 添加新文件夹 并 将其放在 Main 之上。 像这样：
  • 右键单击 ->新文件夹 -> 属性。然后将其命名为您喜欢的任何名称。
  • 选择您刚刚创建的文件夹。 Right Click ->新建 CoffeeScript 文件。
  • Right Click ->新建 CoffeeScript 文件 -> 属性。 让我们将其命名为 Style_New。
  • 插入以下代码！
###
# 字体大小常量
###
class DesktopUIConstants
@TEXT_SIZE_SMALL = 20
@TEXT_SIZE_MESSAGE = 24
@TEXT_SIZE_MESSAGE_NAME = 25
gs.DesktopUIConstants = DesktopUIConstants
gs.UIConstants = DesktopUIConstants
###
# 名称框
###
ui.UIManager.styles.messageBoxNameText = {
"font": {
"name": "Times New Roman",
"size": gs.UIConstants.TEXT_SIZE_MESSAGE_NAME,
"smallCaps": false,
"italic": false,
"color": [59, 59, 59, 255],
}
}
###
# ADV 模式
###
ui.UIManager.styles.advMessageText = {
"font": {
"name": "Times New Roman",
"size": gs.UIConstants.TEXT_SIZE_MESSAGE,
"smallCaps": false,
"italic": false,
"color": [59, 59, 59, 255],
}
}
###
# NVL 模式
###
ui.UIManager.styles.nvlMessageText = {
"font": {
"name": "Times New Roman",
"size": gs.UIConstants.TEXT_SIZE_MESSAGE,
"smallCaps": false,
"italic": false,
"color": [59, 59, 59, 255],
        
}
}
###
# 自定义消息
###
ui.UIManager.styles.customMessageText = {
"font": {
"name": "Times New Roman",
"size": gs.UIConstants.TEXT_SIZE_MESSAGE,
"smallCaps": false,
"italic": false,
"color": [59, 59, 59, 255],
}
}
###
# 日志等
###
ui.UIManager.styles.messageText = {
"font": {
"name": "Times New Roman",
"size": gs.UIConstants.TEXT_SIZE_MESSAGE,
"smallCaps": false,
"italic": false,
}
}
###
# 定义用于消息日志名称列的字体。
###
ui.UIManager.styles.backlogNameText = {
"font": {
"name": "Times New Roman",
"size": gs.UIConstants.TEXT_SIZE_MESSAGE_NAME,
"smallCaps": false,
"italic": false,
"border": true,
"borderSize": 4 }
}

快速分解：

  • name- 字体在 Fonts 文件夹中导入时的名称。您也可以使用系统默认字体，如 Times New Roman 或 Arial。
  • size -字体大小。如果您不想使用常量，可以将其更改为数字。
  • TEXT_SIZE_MESSAGE - 消息字体的默认大小。
  • TEXT_SIZE_MESSAGE_NAME - 名称字体的默认大小。
  • smallCaps - 将所有文本更改为小写。
  • italic - 斜体化字体。
  • outline - 字体的轮廓颜色和大小。

 

您也可以添加自己的属性。例如，为消息添加粗体将如下所示：

###
# ADV 模式
###
ui.UIManager.styles.advMessageText = {
"font": {
"name": "Times New Roman",
"size": gs.UIConstants.TEXT_SIZE_MESSAGE,
"smallCaps": false,
"italic": false,
        "bold": true,

"color": [59, 59, 59, 255],
}
}
