示例：动画

 
Animations 可以使 UI 感觉更流畅，另一方面，如果过度使用或动画太慢，它们可能会惹恼玩家。所以请谨慎使用动画。
 

抖动效果

以下示例仅显示了动画可能性的很小一部分。查看In-Game UI API Reference以查看有关动画功能的更多详细信息。

 

对于我们的标题屏幕，我们想通过在鼠标指针悬停在按钮上时向按钮位置添加偏移量来添加“抖动效果”。

 

ui.UIManager.styles.titleScreenButton = {

"resizable": true,

"margin": [0, 0, 0, 10],

"animations": [

{

"event": "onMouseHover",

"flow": [

{ "type": "changeTo", "duration": 45,"field": "o.offset.x", "value": 10, "easing": "quad_inout", "wait": true },

{ "type": "changeTo", "duration": 45,"field": "o.offset.x", "value": -10, "easing": "quad_inout", "wait": true }

]

},

{

"event": "onMouseLeave",

"flow": [

{ "type": "changeTo", "duration": 0,"field": "o.offset.x", "value": 0, "easing": "quad_inout" }

]

}

]

}

 

正如我们所见，可以使用 animations 属性将动画添加到控件。但与其将该属性添加到每个按钮，不如将其放在我们的 titleScreenButton 样式中，这样它就会自动应用于我们的三个按钮。如果我们现在测试播放我们的游戏，当鼠标悬停在按钮上时，按钮会抖动。

 

动画需要绑定到事件，例如鼠标操作。在我们的例子中，实际上有两个动画，一个绑定到 onMouseHover 事件，仅在鼠标指针悬停在按钮上时执行。另一个绑定到 onMouseLeave 事件，仅在鼠标指针离开按钮区域时执行。

 

动画定义了一个 animation-flow，其中包含多个原始/基本动画，以形成实际的动画效果。基本动画是简单的移动、旋转、缩放等，可以一个接一个地播放，甚至可以并行播放。因此，可以一边移动图像一边旋转和缩放图像。在我们的例子中，我们使用两个“changeTo”动画，先将按钮向右移动，然后用第二个“changeTo”将按钮向左移动。

 

动画流总是循环播放。当最后一个基本动画完成时，流会重复并从动画流的第一个基本动画开始。

 

此外，我们定义了第二个动画，在鼠标离开按钮区域时播放一次。这是为了将按钮的 x 偏移设置回零，以便按钮回到其原始位置。我们将动画持续时间设置为零，以便立即完成动画。您可以尝试一下，然后删除“onMouseLeave”动画看看会发生什么。

 

让我们仔细看看属性：

 

  • animations

当事件发生时为控件执行的动画列表。每个动画都需要绑定到不同的事件。

 

  • event

应执行动画的事件。例如 onMouseHover、onMouseLeave、onMouseDown、onAlways 等。

 

  • flow

动画流，它是基本动画的列表，用于创建实际的动画效果。在我们的例子中，我们想创建一个抖动效果。

 

  • type

原始动画的类型。在我们的例子中，它是 changeTo，它允许我们为任何视觉属性设置动画。在我们的例子中，我们想为按钮的 x 偏移设置动画以创建抖动效果。

 

  • duration

基本动画的持续时间，在我们的例子中是 45 帧。(1 帧 = 1 / FRAMERATE (默认 60) 秒)。

 

  • easing

动画使用的缓动类型。我们使用 quad_inout，一种二次缓动函数，使运动更平滑。但是有许多其他缓动函数可用。要禁用缓动，只需使用 linear_inout。检查Easings Effects页面了解更多信息。

 

  • wait

指示动画流是否应等待当前基本动画完成后再播放下一个。在我们的例子中，我们需要等待右向抖动完成后再开始向另一个方向抖动。但在其他情况下，有必要并行运行两个或多个基本动画，例如同时移动和旋转图像。

 

  • field

此属性特定于 changeTo 动画。在这里，我们可以使用绑定语法定义一个要设置动画的字段，有关绑定的更多信息，请参阅 Data Bindings 示例。

 

  • value

此属性特定于 changeTo 动画。在这里，我们可以指定我们想要达到的目标值。在我们的例子中，我们想在第一步将 x 偏移动画化到 30 像素，然后在第二步将 x 偏移动画化到 -30 像素。

 

脉冲效果

在学习了上一个例子中的一些基本动画之后，我们将尝试下一个动画：当鼠标指针悬停在按钮区域时，“脉冲效果”。

 

ui.UIManager.styles.titleScreenButton = {

"resizable": true,

"margin": [0, 0, 0, 10],

"anchor": [0.5, 0.5],

"animations": [

{

"event": "onMouseHover",

"flow": [

{ "type": "zoomTo", "duration": 45,"zoom": [110, 110], "easing": "quad_inout", "wait": true },

{ "type": "zoomTo", "duration": 45,"zoom": [100, 100], "easing": "quad_inout", "wait": true }

]

},

{

"event": "onMouseLeave",

"flow": [

{ "type": "zoomTo", "duration": 0,"zoom": [100, 100], "easing": "quad_inout", "wait": true }

]

}

]

}

 

如果我们现在测试播放我们的游戏，当鼠标指针悬停在按钮区域时，我们的按钮将放大和缩小（“脉冲”）。在此示例中，我们使用了一种新的基本动画类型，称为 zoomTo，它将按钮缩放到 zoom 属性中定义的百分比。让我们一步一步地分析动画流：

 

在第一步中，我们将按钮放大 110% 以达到按钮的缩小效果。然后，我们将 wait 属性设置为 true，等待我们的缩小效果完成。在下一步中，我们将按钮缩小回 100%，然后再次等待，将 wait 属性设置为 true，直到缩放动画完成。由于动画流总是循环播放，因此看起来按钮正在通过放大和缩小来“脉冲”。

 

您可能注意到我们还为按钮添加了一个新属性“anchor”。使用 anchor 属性，我们可以将按钮的锚点更改为其自身的中心 (0.5, 0.5)，以便缩放效果向四个方向发出。没有它，缩放效果只会朝右下方向发出。最好通过删除 anchor 属性来理解这一点，看看会发生什么。
