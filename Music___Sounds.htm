音乐和声音

 

音乐和声音W

 

 

使用 VN Maker，您可以轻松播放音乐和声音，并进行音量、速度和声像控制。

 

播放声音

可以使用 ResourceManager.getAudioBuffer 加载声音，它返回一个 gs.AudioBuffer 对象，可以通过调用其 play 方法轻松播放。

多次播放相同的声音

 

在最后一个示例中，我们只播放了一个声音。但是，如果我们尝试同时播放该声音多次，例如当我们多次单击屏幕时，我们会发现到目前为止一切正常。每当我们调用音频缓冲对象的 play 方法时，当前声音就会停止然后重新播放。这对于射击游戏来说是一个很大的缺点，因为射击声音会同时播放很多次。我们可以做的一件事是创建具有相同声音文件的 gs.AudioBuffer 的多个实例，但这会浪费内存。

 

一个更好的解决方案是使用 gs.AudioBufferReference 类。它提供了一组与 gs.AudioBuffer 类似的方​​法，但不同之处在于它的构造函数接受一个已有的 gs.AudioBuffer 对象而不是创建一个新的对象，但仍然允许我们独立于其他音频缓冲引用播放声音。因此，我们不是创建许多具有相同声音的 gs.AudioBuffer 对象，而是创建许多引用同一个音频缓冲对象的 gs.AudioBufferReference 对象。

 

让我们来看下面的例子。

# =================================================================== # # 脚本：Component_TestBedBehavior # # 在此处写下您的名字 # # =================================================================== class Component_TestBedBehavior extends gs.Component_SceneBehavior ###* * 一个测试场景行为。您可以在这里玩转 Visual Novel Maker 的 * 游戏引擎，以便更好地了解一切。 ### constructor: -> super # 定义资源上下文属性 @resourceContext = null ###* * 初始化场景。 ### initialize: -> super # 创建一个新的资源上下文 @resourceContext = ResourceManager.createContext() # 设置当前对象管理器 gs.ObjectManager.current = SceneManager # 将其设置为当前资源上下文 ResourceManager.context = @resourceContext ###* * 释放场景。 ### dispose: -> super ###* * 准备场景的所有视觉游戏对象。 ### prepareVisual: -> # 创建音频缓冲引用 1 @soundReference1 = new gs.AudioBufferReference(@audioBuffer) # 创建音频缓冲引用 2 @soundReference2 = new gs.AudioBufferReference(@audioBuffer) # 开始场景过渡 @transition() ###* * 准备场景的所有数据并加载必要的图形和音频资源。 ### prepareData: -> # 加载声音 @audioBuffer = ResourceManager.getAudioBuffer("Audio/Sounds/ambulance_siren") ###* * 更新场景内容。 ### updateContent: -> # 如果鼠标按钮被释放，我们将播放声音 if Input.Mouse.buttonUp # 检查原始音频缓冲是否未在播放 if not @audioBuffer.isPlaying # 播放原始音频缓冲 @audioBuffer.play() # 如果原始音频缓冲已在播放，则检查引用 1 是否未在播放。 else if not @soundReference1.isPlaying # 播放引用 1 @soundReference1.play() # 如果引用 1 也已在播放，则检查引用 2 是否未在播放。 else if not @soundReference2.isPlaying # 播放引用 2 @soundReference2.play() gs.Component_LayoutSceneBehavior = Component_TestBedBehavior

 

现在我们除了原始音频缓冲之外，还有 2 个音频缓冲引用，因此我们可以同时播放同一个声音 3 次。尝试单击屏幕三次以查看区别。当然，这种机制已经实现在 gs.AudioManager 脚本中。因此，使用 gs.AudioManager，我们可以使用 playSound 方法轻松播放任意数量的声音。

# =================================================================== # # 脚本：Component_TestBedBehavior # # 在此处写下您的名字 # # =================================================================== class Component_TestBedBehavior extends gs.Component_SceneBehavior ###* * 一个测试场景行为。您可以在这里玩转 Visual Novel Maker 的 * 游戏引擎，以便更好地了解一切。 ### constructor: -> super # 定义资源上下文属性 @resourceContext = null ###* * 初始化场景。 ### initialize: -> super # 创建一个新的资源上下文 @resourceContext = ResourceManager.createContext() # 设置当前对象管理器 gs.ObjectManager.current = SceneManager # 将其设置为当前资源上下文 ResourceManager.context = @resourceContext ###* * 释放场景。 ### dispose: -> super ###* * 准备场景的所有视觉游戏对象。 ### prepareVisual: -> # 开始场景过渡 @transition() ###* * 准备场景的所有数据并加载必要的图形和音频资源。 ### prepareData: -> # 加载声音 gs.AudioManager.loadSound("ambulance_siren") ###* * 更新场景内容。 ### updateContent: -> # 如果鼠标按钮被释放，我们将播放声音 if Input.Mouse.buttonUp # 播放声音 gs.AudioManager.playSound("ambulance_siren", 100, 100) gs.Component_LayoutSceneBehavior = Component_TestBedBehavior

 

正如我们在这里看到的，我们不再需要直接处理 gs.AudioBuffer 和 gs.AudioBufferReference。我们只需要调用 AudioManager.loadSound 来加载声音，然后就可以轻松地使用 playSound 来播放它。

 

播放音乐

 

要播放音乐文件，我们可以像处理声音一样使用 gs.AudioBuffer 对象。但是，由于音乐文件通常要大得多，因此在播放之前将它们完全加载和解码到内存中可能不是一个好主意。特别是在某些移动设备上，这可能会导致延迟。因此，更推荐流式传输音乐数据。流式传输意味着不是将整个音频文件加载到内存中，而是只加载和解码一小部分，然后播放该部分，释放内存，然后加载、解码和播放下一部分。我们可以使用 gs.AudioBufferStream 而不是 gs.AudioBuffer 来轻松实现这一点。

# =================================================================== # # 脚本：Component_TestBedBehavior # # 在此处写下您的名字 # # =================================================================== class Component_TestBedBehavior extends gs.Component_SceneBehavior ###* * 一个测试场景行为。您可以在这里玩转 Visual Novel Maker 的 * 游戏引擎，以便更好地了解一切。 ### constructor: -> super # 定义资源上下文属性 @resourceContext = null ###* * 初始化场景。 ### initialize: -> super # 创建一个新的资源上下文 @resourceContext = ResourceManager.createContext() # 设置当前对象管理器 gs.ObjectManager.current = SceneManager # 将其设置为当前资源上下文 ResourceManager.context = @resourceContext ###* * 释放场景。 ### dispose: -> super ###* * 准备场景的所有视觉游戏对象。 ### prepareVisual: -> # 开始场景过渡 @transition() ###* * 准备场景的所有数据并加载必要的图形和音频资源。 ### prepareData: -> # 加载音乐 @audioStream = ResourceManager.getAudioStream("Audio/Music/Tutorial_-_Good_Mood") ###* * 更新场景内容。 ### updateContent: -> # 如果鼠标按钮被释放，我们将播放音乐 if Input.Mouse.buttonUp # 播放音乐 @audioStream.play() gs.Component_LayoutSceneBehavior = Component_TestBedBehavior
