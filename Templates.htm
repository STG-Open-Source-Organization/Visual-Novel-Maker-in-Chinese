第一行，与布局和样式类似，总是具有相同的格式：

ui.UIManager.customTypes["<module>.<unique_template_name>"] = {

或者也只是：

ui.UIManager.customTypes.<unique_template_name> = {

不一定需要完全理解这一行，你只需要知道你必须为你的模板使用一个唯一的名称。

我们可以在这里看到 ui.Button 是如何实际定义的。我们可以看到 ui.Button 只是一个 free-layout，里面有一个 ui.SelectableWindow 和一个 ui.Text 控件。ui.SelectableWindow 本身也是一个模板。因此，模板可以使用其他模板，这允许你构建更复杂的 UI。

ui.SelectableWindow 是一个具有默认 UI 设计阴影的框架。它使用“100%”的大小来缩放它并适应父 free-layout 的尺寸。因此，百分比值在模板中非常有用，可以使模板与动态尺寸一起使用。

ui.Text 仅显示 text 属性的文本。在此示例中，文本设置为“-> p.text”，这不是要显示的实际文本，而是一个占位符函数，因为我们希望按钮能够处理任何类型的文本。占位符可用于模板中的任何属性。每当我们想使某个值可调时，我们可以使用以下格式定义一个占位符：

-> p.<placeholder_name>

占位符名称在模板内应该是唯一的，并且不应包含空格或特殊字符。占位符的实际值可以在使用模板时通过 params 属性设置。我们已经在标题屏幕示例中做到了。

{

"type": "ui.Button",

"params": { "text": "New Game" },

"resizable": true,

 

"margin": [0, 0, 0, 10]

 

}

 

因此，params 属性包含已使用模板的所有占位符的值。params 属性仅对模板有效。

 

如果使用 params 属性没有将占位符的值传递给模板，则默认值为 null/空。但如果需要，您可以使用以下格式为占位符定义一个默认值：

 

-> p.<placeholder_name> 或 <default_value>

 

例如：

 

-> p.text

 

?

 

"A Button"

 

我们使用的是 ?-运算符，所以如果我们不为 text 占位符指定有效值，文本将是“A Button”。

 

因此，使用模板，您可以非常轻松地构建复杂的控件和布局。如果您查看默认模板，您会发现模板经常使用其他模板。但是有一小组基本控件不是作为模板定义的，例如 ui.Text 或 ui.Image。通常，您使用这些基本控件来构建您自己更强大的控件。
