自定义控件


To 要创建数据库类别或自定义视图/窗口，Visual Novel Maker 已提供一套强大的标准 UI 控件，如按钮、复选框、文本字段、表格等。但是，如果您正在开发一个大型或非常特定的扩展，您可能希望创建自己的 UI 控件，以便为用户提供更简单、更高效的方式来使用您的扩展。

 

在 Visual Novel Maker 中，您可以使用Objective-J文件和Cappuccino+ VN Maker Objective-J API 来开发自定义 UI 控件。

示例：滑块控件

要创建新的自定义 UI 控件，只需创建一个新的 Objective-J 文件。Objective-J 文件名必须与类定义名称匹配。您可以查看 Visual Novel Maker 默认附带的 Extension Editor > Scripts > Custom Controls 中的 EXSliderItemView 示例。这是一个关于如何实现滑块控件的示例。
