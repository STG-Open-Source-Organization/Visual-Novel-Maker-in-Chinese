外部脚本编辑器

 

Visual Novel Maker 提供了一个基于流行的 ACE Code Editor 的集成脚本编辑器。但是，如果您更喜欢另一个代码编辑器，VN Maker 允许您为自己的自定义脚本使用任何您想要的编辑器。

 

准备您的项目

 

要使用外部脚本编辑器，请导航到您的项目文件夹，并创建一个名为“scripts”的新文件夹。现在您可以将所有自定义脚本作为 .js 文件放在那里，VN Maker 将自动识别这些脚本并将其添加到您的游戏中。您可以为脚本添加数字后缀来控制包含顺序，例如：

 

Fruit-0.js

Apple-1.js

Banana-2.js

 

这在继承的情况下很有用，其中基类脚本必须在派生类脚本之前包含。

 

选择你的编程语言

 

VN Maker 期望你的脚本以 JavaScript 编程语言编写。 如果 JavaScript 不是你最喜欢的语言，你可以选择任何你想要的语言，只要该语言可以编译成 JavaScript，例如 CoffeeScript、TypeScript、Ruby 等。

 

编辑默认脚本

 

你不能在外部脚本编辑器中编辑默认脚本，因为它们需要由 VN Maker 的 DMS（文档管理系统）来管理。 但在常规情况下这完全不是问题，因为直接编辑默认脚本从来都不是一个好主意，因为如果发生更新/迁移，你的修改将会丢失。

 

如果你想修改默认脚本，你可以创建一个副本，然后重写你想要的函数和行为，这样你的修改就不会被迁移覆盖。 然后你也可以使用外部脚本编辑器，只需将默认脚本复制到 scripts-folder 中，然后进行修改即可。

 

但是，如果你想将所有默认脚本导出为外部文件，你可以使用“工具 > 脚本代理 > 默认 > 游戏脚本导出器”脚本代理。 该导出器允许你将所有脚本导出为 .js 或 .coffee 文件。 如果你选中“导出为 JavaScript”复选框，则只会导出编译后的 JavaScript 或常规 JavaScript，而不会导出 CoffeeScript 代码。
