在本主题中，我们将从技术层面探讨 VN Maker 的游戏内 UI 是如何构建的，以提供深入修改所需的信息。UI 对象VN Maker 的游戏内 UI 是 ui 命名空间中的一组游戏对象，例如 ui.Object_Text 用于显示文本标签，ui.Object_Image 用于显示图像，或 ui.Object_Frame 用于显示框架。 它还包含一组布局对象，例如 ui.Object_StackLayout 或 ui.Object_GridLayout。 这些布局对象用于更轻松地在屏幕上定位 UI 元素，而无需使用直接像素坐标。UI 游戏对象是非常原始的对象，你不会找到 ui.Object_Button 对象之类的东西。 这是因为 VN Maker 的 UI 系统希望你组合原始 UI 元素来创建更高级的元素。 要创建一个按钮，你可以将 ui.Object_Image 与 ui.Object_Text 结合起来，例如。 当然，你也可以创建自己的自定义 UI 对象和 UI 组件。 你可以在 Objects > UI 文件夹中找到默认的 UI 对象集，在 Components > UI 文件夹中找到组件。JSON 布局、模板和样式在 VN Maker 中，默认的游戏内 UI 是使用 JSON 布局、样式和模板创建的，而不是直接在代码中处理 UI 对象。 基于 JSON 的布局是构建在基本游戏内 UI 系统之上的附加系统。 其理念是通过一些易于使用的 JSON 描述更轻松地创建你的游戏内 UI。 JSON 结构由 ui.UIManager 类解析和处理，以根据 JSON 结构的**信息**构建所有必需的 UI 对象。

 

这使得初学者更容易更改游戏内 UI，因为他们不再需要处理实际编程，感觉更像是设计网站。 在大多数情况下，整个游戏内 UI 设计都可以在没有编程的情况下更改。 只有当你添加附加功能或想进行大量行为更改时，可能才需要进行一些编程。

 

所有布局、模板和样式都存储在脚本编辑器中的“Layouts”文件夹下。 可以通过编辑 Layout_XXX 脚本或 Template_XXX 脚本轻松更改设计。 字体、颜色和动画可以通过编辑 Style_Default 脚本轻松更改。
