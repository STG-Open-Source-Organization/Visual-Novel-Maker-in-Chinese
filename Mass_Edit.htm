批量编辑

Mass Edit 是一个菜单，允许你在章节或场景中批量修改特定命令（或如果您有编程经验，则更多命令）。

 

命令

您可以选择任何场景命令进行修改。

 

数字字段

修改命令的数字字段，例如 Wait。

 

  • 设置为用于替换内容。

  • 增加用于添加到当前值。

  • 减少用于从当前值中减去。

 

文本字段

修改命令的文本字段，例如 Show Message。它只会更改设置的默认语言。

翻译不受影响，只能在语言配置选项卡中编辑。

 

  • 设置为用于替换内容。

  • 追加用于添加到该命令当前内容的末尾。

  • 移除搜索输入的关键字并将其替换为空文本。

 

脚本

使用编程来创建深入的条件或替换，例如正则表达式，用于选定的命令。内部会创建一个包含您的脚本代码的 JavaScript 函数：

 

function(command) { Your Code is inserted here }

 

该函数将当前命令作为参数。因此，您可以使用本地“command”变量在脚本中检查和修改命令。查看 Visual Novel Maker 的数据格式文档，以获取有关命令数据结构更多的信息。

 

条件
