Component_MessageTextRenderer 类

模块:gs

文本渲染器组件，用于渲染使用游戏对象目标矩形的尺寸进行动画和交互的消息文本。消息使用每个文本行的精灵来显示，而不是绘制到游戏对象的位图对象。
