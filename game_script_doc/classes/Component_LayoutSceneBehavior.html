createControl

(
  • sender
  • params
)

从指定的描述符创建一个新控件的动作方法。

参数：

  • sender gs.Object_Base
    • 发送者对象。
  • params String
    • 包含构造控件所需的描述符和其他数据。
    • params.descriptor - 控件的描述符。可以是直接描述符定义或模板名称
    • params.parent - 一个绑定表达式，它返回控件的父级。
    • params.senderData - 一个对象，包含合并到控件对象中的其他数据。

executeBindings

(
  • sender
  • params
)

改变游戏宽高比的动作方法。

参数：

  • sender gs.Object_Base
    • 发送者对象。
  • params Boolean
    • 如果true游戏屏幕将被拉伸，以便它填充玩家的整个屏幕，没有任何黑色边框。 否则，游戏屏幕会拉伸但保持其比例

因此，如果游戏分辨率的比例与目标显示器的比例不匹配，则可能会出现黑色边框。 也可以是一个绑定表达式。
