Component_Draggable 类

模块：gs

使游戏对象可以通过鼠标/触摸拖动。 拖动可以是垂直、水平或两者兼有。 它可以配置为逐像素或逐步拖动。 例如：要为具有固定步骤的 UI 创建滑块，逐步拖动很有用，而逐像素拖动可以用于音量滑块。

方法

dispose

()

释放组件。

onDataBundleRestore.

(
  • Object
  • gs.ObjectCodecContext
)

如果此对象实例是从数据包中恢复的，则调用此方法。 可用于重新分配事件处理程序、匿名函数等。

参数：

  • Object Object

    data - 数据包

  • gs.ObjectCodecContext Object

    context - 编解码器上下文。

setup

()

初始化组件。 添加鼠标/触摸事件的事件处理程序，以便仅在发生用户操作时才更新组件。

setupEventHandlers

()

添加鼠标/触摸事件的事件处理程序，以便仅在发生用户操作时才更新组件。

update

()

更新拖动逻辑。

updateAxisX

() protected (受保护的)

如果配置了X轴拖动，则更新X轴的拖动过程。

updateAxisY

() protected (受保护的)

如果配置了Y轴拖动，则更新Y轴的拖动过程。

updateDragging

() protected (受保护的)

如果为此组件配置了步长，则计算单个步长的大小。 否则，步长为 1 像素。

updateDragging

() protected (受保护的)

更新游戏对象的拖动状态，并在必要时触发 dragged (拖动) 事件。
