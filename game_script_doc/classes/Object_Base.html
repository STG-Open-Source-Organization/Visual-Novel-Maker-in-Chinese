Object_Base 类

模块:gs

所有游戏对象的基类。游戏对象本身不实现任何游戏逻辑，而是使用组件和子对象来实现。

属性

active

Unknown

默认:true 指示游戏对象是否处于活动状态。非活动游戏对象不会被更新。

components

gs.Component

默认:[] 定义游戏对象逻辑/行为和外观的组件列表。

componentsById

Object

默认:[] 按 ID 排序的所有关联组件。

disposed

Boolean

默认:false 指示游戏对象是否已释放。已释放的游戏对象不能再使用。

group

string 游戏对象的组。要获取特定组的所有对象，可以使用 gs.ObjectManager.objectsByGroup 属性。

默认:null

id

String

默认:null 游戏对象的 UID (唯一 ID)

initialized

Boolean

默认:true 指示游戏对象及其组件是否已初始化。

needsSort

Boolean

默认:true 指示子对象列表是否需要按顺序排序，因为有更改。

needsSort

Boolean

默认:true 指示 UI 对象是否需要更新。

order

Number

默认:0 控制更新顺序。值越小，游戏对象在更新其他游戏对象之前被更新的顺序越早。

parent

gs.Object_Base

默认:null 父对象，如果游戏对象是另一个游戏对象的子对象。

rIndex

Number

默认:0 如果游戏对象在屏幕上有图形表示，则保存渲染索引。渲染索引是游戏对象图形对象 (gs.GraphicObject) 在当前图形对象列表中的索引。渲染索引是只读的。将渲染索引设置为某个值无效。

subObjects

gs.Object_Base

默认:[] 分组在此游戏对象下的游戏对象列表。
