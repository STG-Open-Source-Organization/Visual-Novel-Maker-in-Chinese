方法

appear

(
  • callback
)

执行为 "onInitialize" 事件定义的动画。每个 UI 对象 都可以在 JSON 中为某些事件定义动画。

参数：

  • callback Function
    • 动画结束时调用的可选回调函数。

blur

()

移除此 UI 对象的输入焦点。如果 UI 对象不可聚焦，则不会发生任何事情。

disappear

(
  • callback
)

执行为 "onTerminate" 事件定义的动画。每个 UI 对象 都可以在 JSON 中为某些事件定义动画。

参数：

  • callback Function
    • 动画结束时调用的可选回调函数。

dispose

()

释放组件。

executeAnimation

(
  • event
  • callback
)

执行为指定事件定义的动画。每个 UI 对象 都可以在 JSON 中为某些事件定义动画。

参数：

  • event String
    • 要执行动画的事件，例如 "onTerminate" 或 "onInitialize"。如果 没有为指定事件定义动画，则不会发生任何事情，并且会立即调用回调。
  • callback Function
    • 动画结束时调用的可选回调函数。

focus

()

将输入焦点赋予此 UI 对象。如果 UI 对象不可聚焦，则不会发生任何事情。

onDataBundleRestore.

(
  • Object
  • gs.ObjectCodecContext
)

由gs模块提供。

如果此对象实例是从数据包还原的，则调用。它可以用于 重新分配事件处理程序、匿名函数等。

参数：

  • Object Object

    data - 数据包

  • gs.ObjectCodecContext Object

    context - 编解码器上下文。

prepare

()

准备用于显示的 UI 对象。应该调用此方法 在显示新创建的 UI 对象之前，以正确地定位所有 子元素。

setup

()

初始化绑定处理程序。

setupEventHandlers

()

为鼠标/触摸事件添加事件处理程序

update

()

更新绑定处理程序。
