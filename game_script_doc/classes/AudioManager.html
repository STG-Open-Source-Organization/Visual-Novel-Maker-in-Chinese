(
  • name
  • volume
  • rate
  • fadeInTime
  • layer
)

播放音乐。

参数：

  • name String | Object (字符串 | 对象)
    • 要播放的音乐。可以是名称或音乐数据对象。
  • volume Number (数字)
    • 音乐的音量，以百分比表示。
  • rate Number (数字)
    • 音乐的播放速率，以百分比表示。
  • fadeInTime Number (数字)
    • 淡入时间。
  • layer Number (数字)
    • 要在其上播放音乐的层。

playMusicRandom (随机播放音乐)

(
  • music
  • fadeTime
  • layer
  • playTime
  • playRange
)

以随机音乐的形式播放音乐。随机音乐将在随机时间淡入和淡出。这可以与其他音频层结合使用，以创建 音频轨道更好的循环。

参数：

  • music Object (对象)
    • 要播放的音乐。
  • fadeTime Number (数字)
    • 单个淡入/淡出的时间，以帧为单位。
  • layer Number (数字)
    • 要使用的音频层。
  • playTime gs.Range (gs.范围)
    • 播放时间范围，例如 10 秒到 30 秒。
  • playRange gs.Range (gs.范围)
    • 播放范围。

playSound (播放声音)

(
  • name
  • volume
  • rate
  • musicEffect
  • voice
)

播放声音。

参数：

  • name String (字符串)
    • 要播放的声音的名称。
  • volume Number (数字)
    • 声音的音量。
  • rate Number (数字)
    • 声音的播放速率。
  • musicEffect Boolean (布尔值)
    • 指示声音是否应作为音乐效果播放。在这种情况下，音频层中的当前音乐将被暂停，直到声音播放完毕。
  • voice Boolean (布尔值)
    • 指示声音是否应作为语音处理。
