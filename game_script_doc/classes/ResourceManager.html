ResourceManager 类

模块：gs

管理游戏资源，如图形、音频、字体等。它 提供了许多方法来轻松访问游戏资源并自动 缓存它们。因此，如果一个图像被第二次请求，它将从 缓存中加载，而不是再次加载。

获取音频缓冲区

（
  • 文件路径
）
gs.AudioBuffer

获取一个音频缓冲区。音频数据已完全加载并解码到内存中。建议 用于音效，但对于长时间的背景音乐，获取音频流应被使用。这尤其 在移动设备上。

参数：

  • 文件路径 字符串
    • 音频文件路径。

返回：

gs.AudioBuffer：

音频缓冲区或null如果指定的路径不存在音频文件。

上下文

gs.ResourceManagerContext

系统资源上下文。所有加载的系统资源都与之关联。与系统上下文关联 的资源将在游戏结束前不会被销毁。
