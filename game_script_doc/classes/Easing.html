Easing 类 (缓动类)

模块：gs

Easing 类使用不同的缓动函数提供不同类型的动画。动画的缓动控制动画开始和/或停止时的缓急程度。

  • 方法
  • 属性

方法

start (开始)

(
  • sx
  • sy
  • dx
  • dy
  • duration
)

开始移动/滚动动画。

参数：

  • sx Number (数字)
    • 起始 x 坐标。
  • sy Number (数字)
    • 起始 y 坐标。
  • dx Number (数字)
    • x 轴上的距离/量。
  • dy Number (数字)
    • y 轴上的距离/量。
  • duration (持续时间) Number (数字)
    • 动画的持续时间。

startEndless (无限开始)

(
  • speedX
  • speedY
)

开始无限移动/滚动动画。

参数：

  • speedX Number (数字)
    • x 轴上的动画速度。
  • speedY Number (数字)
    • y 轴上的动画速度。

startValue (开始值)

(
  • value
  • distance
  • duration
)

开始值动画。

参数：

  • value Number (数字)
    • 起始值。
  • distance Number (数字)
    • 值要改变的距离/量。
  • duration (持续时间) Number (数字)
    • 动画的持续时间。

startValueEndless (无限开始值)

(
  • value
  • speedY
)

开始无限值动画。

参数：

  • value Number (数字)
    • 起始值。
  • speedY Number (数字)
    • 动画速度。

()

停止动画
