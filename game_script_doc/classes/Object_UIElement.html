属性

alignment

ui.Alignment

UI 对象的对齐方式。

anchor

gs.Point

UI 对象的锚点。例如：锚点为 0,0 时，对象以其左上角位于其位置；但锚点为 0.5, 0.5 时，对象以其中心位于其位置。锚点为 1,1 时，对象以其右下角位于其位置。

angle

Number

UI 对象的旋转角度（以度为单位）。旋转中心取决于锚点。

breakBindingChain

Boolean

指示 UI 对象是否会中断绑定链。如果

true，UI 对象在当前绑定执行周期内不会更改任何绑定目标。clipRect_

gs.Rect

受保护的 对象的剪裁矩形，用于视觉呈现。

color

gs.Color

UI 对象的颜色。

dstRect

ui.Component_UIElementRectangle

UI 对象在屏幕上的目标矩形。

enabled

Boolean

指示 UI 对象是否已启用并响应用户操作。

events

gs.Component_EventEmitter

用于发出事件的事件发射器。

image_

String

受保护的 margin

ui.Space

UI 对象的边距。边距定义了 UI 对象周围的额外空间。默认值为 { left: 0, top: 0, right: 0, bottom: 0 }。

mask

gs.Mask

UI 对象的蒙版，用于蒙版效果。

offset

gs.Vector2

UI 对象的偏移量。

opacity

Number

UI 对象的透明度，用于控制透明度。例如：0 = 透明，255 = 不透明，128 = 半透明。

origin

gs.Vector2

UI 对象的原点。

padding

ui.Space

UI 对象的内边距。默认值为 { left: 0, top: 0, right: 0, bottom: 0 }。

resizable

Boolean

UI 对象的缩放行为。

updateBehavior

ui.UpdateBehavior

UI 对象的更新行为。默认值为 ui.UpdateBehavior.NORMAL。

visible

Boolean

指示 UI 对象是否在屏幕上可见。

visible_

Boolean

受保护的 zoom

gs.Point

UI 对象的缩放设置，用于 x 和 y 轴。默认值是 { x: 1.0, y: 1.0 }。

The UI object's zoom-setting for x and y axis. The default value is { x: 1.0, y: 1.0 }
