属性

锚点

gs.Point

由模块提供。

对象的锚点。例如：锚点 0,0 将对象的左上角放置在其位置，但锚点 0.5, 0.5 将对象居中放置。锚点 1,1 将对象的右下角放置在其位置。

混合模式

数字

由模块提供。

对象的混合模式控制如何计算对象视觉表示的混合。

默认：gs.BlendMode.NORMAL

目标矩形

gs.Rect

由模块提供。

对象的屏幕目标矩形。

效果

gs.EffectCollection

由模块提供。

包含可以为对象激活的各种着色器效果。

运动模糊

gs.MotionBlur

由模块提供。

对象的运动模糊设置。

偏移量

gs.Point

由模块提供。

对象的偏移量。

不透明度

数字

由模块提供。

对象的透明度控制。例如：0 = 透明，255 = 不透明，128 = 半透明。

原点

gs.Point

由模块提供。

对象的原点。

位置锚点

gs.Point

由模块提供。

位置锚点。例如：锚点 0,0 将对象的左上角放置在其位置，但锚点 0.5, 0.5 将对象居中放置。锚点 1,1 将对象的右下角放置在其位置。它对对象的旋转/缩放锚点没有影响。为此，请查看锚点属性。

视口

gs.Viewport

由模块提供。

对象的视口。

可见性

布尔值

由模块提供。

指示游戏对象是否在屏幕上可见。

Z 索引

数字

由模块提供。

对象的 z 索引控制渲染顺序/图像重叠。z 索引较小的对象在 z 索引较大的对象之前渲染。例如：要确保游戏对象始终位于屏幕顶部，其 z 索引应是所有游戏对象中最大的。
