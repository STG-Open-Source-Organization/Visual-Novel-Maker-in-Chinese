Component_Animator 类

模块：gs

动画器组件允许在游戏对象上执行不同类型的动画。 这些动画使用游戏对象的 dstRect 和 offset 属性来执行。

appear（出现）

(
  • x
  • y
  • animation（动画）
  • easing（缓动）
  • duration（持续时间）
  • [callback]（[回调]）
)

让游戏对象使用指定的动画出现在屏幕上。

参数：

  • x Number

    目标位置的 x 坐标。

  • y Number

    目标位置的 y 坐标。

  • animation（动画） gs.AppearAnimationInfo

    动画信息对象。

  • easing（缓动） Object

    缓动类型。

  • duration（持续时间） Number

    持续时间，以帧为单位。

  • [callback]（[回调]） Function 可选

    动画完成时调用的可选回调函数。
