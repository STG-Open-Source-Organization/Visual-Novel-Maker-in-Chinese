Component_HotspotBehavior 类

模块：gs

为游戏对象添加热点行为。 允许游戏对象通过触发动作事件或更改游戏对象的图像来响应鼠标/触摸操作。

  • 方法
  • 属性

  • onDataBundleRestore (数据包恢复时)
  • setup (设置)
  • setupEventHandlers (设置事件处理器)
  • update (更新)
  • updateColor (更新颜色)
  • updateEvents (更新事件)
  • updateFromTarget (从目标更新)
  • updateImage (更新图像)

方法

checkShape

(
  • x
  • y
)

检查指定点是否在热点的形状内。

参数：

  • x Object
    • 该点的 x 坐标。
  • y Object
    • 该点的 y 坐标。

返回值：

如果true该点在热点的形状内。 否则false。

dispose

()

销毁组件。

onDataBundleRestore.

(
  • Object
  • gs.ObjectCodecContext
)

由ui模块提供。

如果从数据包中恢复此对象实例，则调用此方法。 它可用于重新分配事件处理程序、匿名函数等。

参数：

  • Object Object

    data - 数据包

  • gs.ObjectCodecContext Object

    context - 编解码器上下文。

setup

()

初始化热点组件。

setupEventHandlers

()

设置事件处理程序。

update

()

更新热点组件。

updateColor

() protected (受保护的)

根据热点的状态更新游戏对象的颜色。

updateEvents

() protected (受保护的)

更新事件处理并触发必要的事件。

updateFromTarget

() protected (受保护的)

从另一个目标游戏对象更新热点的位置和大小。 例如，这对于向另一个移动的游戏对象添加热点非常有用。

updateImage

() protected (受保护的)

根据热点状态更新图像。

updateInput

() protected (受保护的)

存储鼠标/触摸指针和按钮的当前状态。

属性

actionButton

Number (数字)

默认操作按钮。 默认情况下使用左键。

actionButtons

Object (对象) protected (受保护的)

buttonDown

Boolean (布尔值) protected (受保护的)

指示是否按下操作按钮。

buttonUp

Boolean (布尔值) protected (受保护的)

指示之前是否按下过操作按钮。

contains

Boolean (布尔值) protected (受保护的)

指示鼠标/触摸指针是否在热点边界内。

enabled

Boolean (布尔值)

指示是否启用热点。

imageHandling

Number (数字) protected (受保护的)

selected

Boolean (布尔值)

指示是否选择了热点。

shape

Boolean (布尔值)

用于检测是否单击、悬停等热点的形状。

sound

Object (对象)

执行热点操作时播放的声音。

sounds

Object (对象)

根据热点状态播放的声音。

  • 0 = 选择声音
  • 1 = 取消选择声音
