方法

addCharacter

(
  • character (角色)
  • noAnimation (无动画)
  • animationData (动画数据)
)

向场景中添加一个新角色。

参数：

  • character (角色) vn.Object_Character
    • 要添加的角色。
  • noAnimation (无动画) Boolean
    • 指示是否应该立即添加角色，而没有任何出现动画。
  • animationData (动画数据) Object
    • 包含出现动画数据 -> { animation, easing, duration }。

changeBackground

(
  • background (背景)
  • noAnimation (无动画)
  • animation (动画)
  • easing (缓动)
  • duration (持续时间)
  • ox (x原点)
  • oy (y原点)
  • layer (图层)
  • loopHorizontal (水平循环)
  • loopVertical (垂直循环)
)

更改场景的背景。

参数：

  • background (背景) Object
    • 背景图形对象 -> { name }
  • noAnimation (无动画) Boolean
    • 指示是否应该立即更改背景，而没有任何更改动画。
  • animation (动画) Object
    • 要使用的出现/消失动画。
  • easing (缓动) Object
    • 更改动画的缓动函数。
  • duration (持续时间) Number
    • 更改的持续时间（以帧为单位）。
  • ox (x原点) Number
    • 背景的x原点。
  • oy (y原点) Number
    • 背景的y原点。
  • layer (图层) Number
    • 要更改的背景图层。
  • loopHorizontal (水平循环) Boolean
    • 指示是否应该水平循环背景。
  • loopVertical (垂直循环) Boolean
    • 指示是否应该垂直循环背景。

()

销毁场景。

()

初始化场景。

pauseScene

()

暂停当前场景。 暂停的场景将不会继续，消息、图片等将停止，直到场景恢复。

prepareData

()

准备场景的所有数据并加载必要的图形和音频资源。

prepareVisual

()

准备场景的所有视觉游戏对象。

removeCharacter

(
  • character (角色)
  • animationData (动画数据)
)

从场景中移除一个角色。

参数：

  • character (角色) vn.Object_Character
    • 要移除的角色。
  • animationData (动画数据) Object
    • 包含消失动画数据 -> { animation, easing, duration }。

() protected (受保护的)

从加载的存档游戏中恢复音频播放。

restoreInterpreter

() protected (受保护的)

restoreMessageBox

() protected (受保护的)

restoreMessages

() protected (受保护的)

从加载的存档游戏中恢复消息。

restoreScene

() protected (受保护的)

从当前加载的存档游戏中恢复场景对象。 如果 GameManager.loadedSaveGame 中没有存档游戏，则什么也不会发生。

()

如果当前场景已暂停，则恢复该场景。

show

(
  • visible (可见的)
)

显示/隐藏当前场景。 隐藏的场景不再显示和执行，但所有对象和数据仍然存在，可以随时再次显示。

参数：

  • visible (可见的) Boolean
    • 指示是否应该显示或隐藏场景。

showChoices

(
  • choices (选择)
  • callback (回调)
)

显示选择，让用户选择一个选项。

参数：

  • choices (选择) Object
    • 一个选择数组
  • callback (回调) gs.Callback
    • 如果用户选择了某个选项，则调用的回调函数。

showInputNumber

(
  • digits (位数)
  • callback (回调)
)

显示数字输入框，让用户输入一个数字。

参数：

  • digits (位数) Number
    • 用户可以输入的最大位数。
  • callback (回调) gs.Callback
    • 如果用户接受了数字输入框，则调用的回调函数。

showInputText

(
  • letters (字母数)
  • callback (回调)
)

显示文本输入框，让用户输入文本。

参数：

  • letters (字母数) Number
    • 用户可以输入的最大字母数。
  • callback (回调) gs.Callback
    • 如果用户接受了文本输入框，则调用的回调函数。

() protected (受保护的)

skipMessageAreas

跳过所有消息区域的所有动画。

() protected (受保护的)

跳过 MESSAGE_BOX_IDS UI 常量中定义的所有消息框的所有动画。

skipPictures

() protected (受保护的)

跳过所有图片动画。

() protected (受保护的)

skipVideos

() protected (受保护的)

skipViewports

() protected (受保护的)

updateContent

()
