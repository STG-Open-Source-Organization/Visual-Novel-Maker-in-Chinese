Component_ZoomAnimation 类

模块：gs

在游戏对象上执行缩放动画。

  • 索引
  • 方法
  • 属性

条目索引

方法

  • toDataBundle (转换为数据包)
  • update (更新)
  • zoomTo (缩放到)

属性

  • easing (缓动)

方法

toDataBundle

()

将缩放动画序列化为数据包。

update

()

更新缩放动画。

zoomTo

(
  • x
  • y
  • duration
  • easingType
  • [callback]
)

启动缩放动画。

参数：

  • x Number (数字)

    X 轴缩放因子。

  • y Number (数字)

    Y 轴缩放因子。

  • duration Number (数字)

    持续时间，以帧为单位。

  • easingType Object (对象)

    缓动类型。

  • [callback] Function (函数) optional (可选)

    一个可选的回调函数，在混合完成后调用。

属性

easing

gs.Easing

用于动画的缓动对象。
