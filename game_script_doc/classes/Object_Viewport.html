属性

angle

数字

图片的旋转角度（以度为单位）。旋转中心取决于锚点。

animator

vn.Component_Animator

对象的动画组件，用于在其上执行各种动画，如移动、旋转等。

color

gs.Color

用于视觉呈现的对象颜色。

tone

gs.Tone

用于视觉呈现的对象的色调。

visual

gs.Component_Sprite

对象的视觉组件，用于在屏幕上显示游戏对象。
