Component_TextRenderer 类

模块：gs

文本渲染器组件允许在游戏对象的位图上绘制纯文本或格式化文本。对于格式化文本，可以使用不同的文本代码来添加格式或定义占位符。

文本代码使用以下语法：

{code:value} <- 单个值
{code:value1,value2,...} <- 多个值


示例：

"This is {Y:I}a Text{Y:N}" <- "a Text" 在这里将是斜体。
"The value is {GN:1}" <- "{GN:1}" 将被替换为全局数字变量 0001 的值。

有关所有可用文本代码及其示例的列表，请查看官方帮助文件。

calculateLines

(
  • message
  • wordWrap
  • [firstLineWidth=0]
)
Array

创建一个行对象数组。每个行对象都是一个 token 对象列表。 token 对象可以只是一个字符串，也可以是一个包含更多信息的对象，用于在运行时处理 token。

行对象还包含其他信息，例如行的宽度和高度（以像素为单位）。

如果设置了 wordWrap 参数，如果行不适合游戏对象位图的宽度，则会自动创建换行符。

参数：

  • message String
    • 用于创建行对象的消息。
  • wordWrap Boolean
    • 如果 wordWrap 设置为 true，则会自动创建换行符。
  • [firstLineWidth=0] Number 可选的
    • 第一行的当前宽度。

返回值：

Array:

行对象数组。
