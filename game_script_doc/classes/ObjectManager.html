ObjectManager 类

模块：gs

通过在必要时更新游戏对象并提供添加或删除游戏对象的方法来管理游戏对象。所有游戏对象都按 order 属性排序，以便控制更新顺序。

游戏对象可以使用唯一的 ID 注册，然后使用该 ID 轻松访问。 如果对象被注册，则会创建一个全局变量 $。但是，该全局变量仅用于 In-Game UI 的属性绑定。 请参阅 ui.Component_BindingHandler。

此外，可以将游戏对象分配给一个组，例如，一组 UI 切换按钮可以分配到同一组，然后可以使用 gs.ObjectManager.objectsByGroup 方法轻松访问。
