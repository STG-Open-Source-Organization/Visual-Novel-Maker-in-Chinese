方法

checkForHandlerFunction

(
  • eventName
  • handlerFunction
)
Boolean

检查给定事件是否存在具有指定处理函数 (handler-function) 的事件处理程序 (event-handler)。

参数：

  • eventName String
    • 事件名称。
  • handlerFunction Function
    • 要搜索的处理函数。

返回值：

Boolean：

如果为 true，则给定事件存在具有指定处理函数的观察者。否则为 false。

checkForOwner

(
  • eventName
  • owner
)
Boolean

检查给定事件是否存在具有指定所有者 (owner) 的事件处理程序。

参数：

  • eventName String
    • 事件名称。
  • owner Function
    • 要搜索的所有者。

返回值：

Boolean：

如果为true，则给定事件存在具有指定所有者的事件处理程序。否则为false。

clear

()

通过删除所有处理程序/监听器来清除事件发射器。

emit

(
  • eventName
  • [sender=null]
  • [data={}]
)

触发指定的事件。将通知为指定事件注册的所有观察者/监听器。

参数：

  • eventName String
    • 要触发的事件的名称。
  • [sender=null] Object 可选
    • 事件的发送者。
  • [data={}] Object 可选
    • 传递给每个处理函数的可选对象。

off

(
  • eventName
  • [handler=null]
)

从指定事件中删除观察者/监听器。如果 handler 参数为空，则删除指定事件的所有观察者。

参数：

  • eventName String
    • 事件名称。
  • [handler=null] gs.EventObserver 可选
    • 要删除的观察者对象。如果为空，则删除指定事件的所有观察者。

offByOwner

(
  • eventName
  • owner
)
Number

删除属于指定所有者的事件中的所有观察者/监听器。

参数：

  • eventName String
    • 事件名称。
  • owner Object
    • 所有者。

返回值：

Number：

已删除的观察者/监听器的数量。

on

(
  • eventName
  • handler
  • [data={}]
  • [owner=null]
  • priority
)
gs.EventObserver

为指定事件添加新的观察者/监听器。

参数：

  • eventName String
    • 事件名称。
  • handler Function
    • 触发事件时调用的处理函数。
  • [data={}] Object 可选
    • 传递给处理函数的可选信息对象。
  • [owner=null] Object 可选
    • 与观察者/监听器关联的可选所有者对象。
  • priority Number
    • 可选的优先级。优先级较高的观察者/监听器将在优先级较低的观察者/监听器之前接收到事件。

返回值：

gs.EventObserver：
  • 添加的观察者对象。

once

(
  • eventName
  • handler
  • [data={}]
  • [owner=null]
  • priority
)
gs.EventObserver

为指定事件添加新的观察者/监听器，并在事件触发一次后将其删除。

参数：

  • eventName String
    • 事件名称。
  • handler Function
    • 触发事件时调用的处理函数。
  • [data={}] Object 可选
    • 传递给处理函数的可选信息对象。
  • [owner=null] Object 可选
    • 与观察者/监听器关联的可选所有者对象。
  • priority Number
    • 可选的优先级。优先级较高的观察者/监听器将在优先级较低的观察者/监听器之前接收到事件。

返回值：

gs.EventObserver：
  • 添加的观察者对象。
