模块：ui

方法

apply

(
  • object
)

将样式应用于 UI 对象。

参数：

  • object ui.Object_UIElement
    • 应应用样式的 UI 对象。

applyAnimations

(
  • object
)
受保护的

将样式的动画数据应用于 UI 对象。如果 UI 对象还没有 id 为“animationHandler”的 animation-handler 组件（ui.Component_AnimationHandler），则会自动添加一个。

参数：

  • object ui.Object_UIElement
    • 应应用动画数据的 UI 对象。

applyLooping

(
  • object
)
受保护的

将样式的循环数据应用于 UI 对象。

参数：

  • object ui.Object_UIElement
    • 应应用循环数据的 UI 对象。

revert

(
  • object
)

撤销此样式对 UI 对象所做的更改。但是，这将重置此样式设置的所有可样式化属性。因此，有必要重新应用所有其他样式，但这已在 ui.Component_UIBehavior 中处理。

参数：

  • object ui.Object_UIElement
    • 应撤销样式的 UI 对象。

revertAnimations

(
  • object
)

撤销此样式应用于 UI 对象的动画数据更改。

参数：

  • object ui.Object_UIElement
    • 应撤销动画数据更改的 UI 对象。

revertLooping

(
  • object
)

撤销此样式应用于 UI 对象的循环数据更改。

参数：

  • object ui.Object_UIElement
    • 应撤销循环数据更改的 UI 对象。

setFromDescriptor

(
  • descriptor
)

从样式描述符初始化样式。

参数：

  • descriptor Object
    • 样式描述符。

setupFont

(
  • descriptor
)
受保护的

从样式描述符初始化字体数据。

参数：

  • descriptor Object
    • 样式描述符。

属性

alignment

ui.Alignment

UI 对象的可视对齐方式。

alignmentX

Number

对象在 x 轴上的对齐方式。需要布局支持。

alignmentY

Number

对象在 y 轴上的对齐方式。需要布局支持。

anchor

gs.Point

UI 对象的锚点。例如：锚点为 0,0 时，对象的左上角位于其位置；但锚点为 0.5, 0.5 时，对象的中心位于其位置。锚点为 1,1 时，对象的右下角位于其位置。

animations

Object

UI 对象用于视觉呈现的动画。

默认：null

clipRect

gs.Rect 受保护的

对象用于视觉呈现的剪裁矩形。

默认：null

color

gs.Color

UI 对象的颜色。

descriptor

Object

原始样式描述符。

font

gs.Font

用于文本显示的字体。

默认：null

frameCornerSize

Number

边框的圆角大小。

frameThickness

Number

边框的厚度。

id

Number

ID 号，用于快速访问此样式并关联到此样式。

image

String

UI 对象用于视觉呈现的图像。

looping

ui.Orientation

图像的循环方式。

margin

Object

UI 对象的边距。边距定义了 UI 对象周围的额外空间。

默认：

{ left: 0, top: 0, right: 0, bottom: 0 }

mask

gs.Mask

UI 对象用于遮罩效果的遮罩。

opacity

Number

UI 对象的透明度，用于控制透明度。例如：0 = 透明，255 = 不透明，128 = 半透明。

padding

Object

UI 对象的内边距。

默认：

{ left: 0, top: 0, right: 0, bottom: 0 }

resizable

Boolean

对象的重置大小行为。

selector

Number

选择器 ID，用于控制样式在何种条件下激活。

target

Number

目标对象的样式 ID。此样式仅应用于作为此样式所应用 UI 对象的子对象的具有该样式 ID 的 UI 对象。

zIndex

Number

对象的 z-index 控制渲染顺序/图像重叠。z-index 值较小的对象在 z-index 值较大的对象之前渲染。例如：为了确保游戏对象始终位于屏幕顶部，它应该具有所有游戏对象中最大的 z-index。zoom
