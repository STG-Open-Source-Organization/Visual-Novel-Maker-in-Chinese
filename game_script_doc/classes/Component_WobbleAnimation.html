Component_WobbleAnimation 类

模块：gs

在游戏对象上执行摇摆动画。

  • 索引
  • 方法
  • 属性

条目索引

方法

  • start (开始)
  • update (更新)

属性

  • easing (缓动)

方法

start (开始)

(
  • power (强度)
  • duration (持续时间)
  • easingType (缓动类型)
  • [callback] (回调)
)

启动混合动画。

参数：

  • power (强度) Number (数字)

    目标强度。

  • duration (持续时间) Number (数字)

    以帧为单位的持续时间。

  • easingType (缓动类型) Object (对象)

    缓动类型。

  • [callback] (回调) Function (函数) 可选

    动画完成时调用的可选回调函数。

update (更新)

()

更新混合动画。

属性

easing (缓动)

gs.Easing

用于动画的缓动对象。
