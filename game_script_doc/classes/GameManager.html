GameManager 类

模块：gs

管理游戏相关的通用事务，例如保存游戏设置，管理游戏的保存/加载等等。

方法

createSaveGameIndex

() protected

创建所有保存游戏的索引。 应该在创建新保存游戏时调用。

dispose

()

释放 GameManager。 应该在退出游戏之前调用。

exit

()

退出游戏。 该实现取决于平台。 因此，例如在移动设备上，此方法无效。

exitGame

()

退出游戏并重置 GameManager，这在返回主菜单或标题画面之前非常重要。

getSaveGame

(
  • slot
)
Object

获取指定槽位的保存游戏数据。

参数：

  • slot Number
    • 要从中获取保存数据的槽位。

返回：

Object：

保存游戏数据。

initialize

()

初始化 GameManager，应在实际游戏开始之前调用。

load

(
  • slot
)

加载指定保存游戏槽位的游戏。 此方法会触发自动场景更改。

参数：

  • slot Number
    • 应从中加载游戏的槽位。

newGame

()

开始新游戏。

reset

()

通过释放并重新初始化 GameManager 来重置它。

resetGlobalData

()

重置当前全局数据。 所有关于已读消息、持久变量和CG画廊的存储数据将被删除。

resetSettings

()

将游戏设置重置为其默认值。

save

(
  • slot
  • thumbWidth
  • thumbHeight
)

在指定的槽位保存当前游戏。

参数：

  • slot Number
    • 游戏应保存到的槽位。
  • thumbWidth Number
    • 快照缩略图的宽度。您可以指定null或0来使用自动计算的宽度。
  • thumbHeight Number
    • 快照缩略图的高度。您可以指定null或0来使用自动计算的高度。

saveGlobalData

()

保存当前全局数据。

saveSettings

()

保存当前游戏设置。

setupCommonEvents

()

设置公共事件。

setupCursor

()

根据系统设置设置光标。

update

()

更新 GameManager。 应每帧调用一次。

属性

backlog

Object

游戏的 backlog。

chapters

gs.Document

游戏的章节。

characterParams

Object

按角色 ID 分配的角色参数。

commonEvents

gs.Object_CommonEvent

公共事件列表。

commonEvents

gs.Object_CommonEvent

指示 GameManager 是否已初始化。

defaults

Object

存储背景、图片等默认值。

globalData

Object

存储全局数据，例如持久性游戏变量的状态。

inLivePreview

Object

指示游戏是否在编辑器的实时预览中运行。

messages

Object

游戏当前显示的消息。 尤其是在 NVL 模式下，当前页面的消息存储在此处。

saveGameSlots

Object

保存游戏索引。 包含每个保存游戏槽位的头部信息。

saveSlotCount

Number

保存槽位的数量。 默认为 100。

sceneData

Object

当前场景数据。

sceneViewport

gs.Object_Viewport

场景视口，包含所有视觉对象，这些对象是场景的一部分并且受游戏内摄像头的影响。

tempFields

Object

临时游戏字段。

tempSettings

Object

临时游戏设置。
