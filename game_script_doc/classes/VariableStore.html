VariableStore 类

Module:gs

一个存储不同类型游戏变量的容器。存在以下作用域的变量：

  • 局部变量 -> 仅对当前场景有效。
  • 全局变量 -> 对整个游戏有效，但绑定到单个存档。
  • 持久变量 -> 对整个游戏有效，与存档无关。

存在以下数据类型：

- 字符串 -> 存储文本数据的变量。 - 数字 -> 存储整数的变量。 - 布尔值 -> 存储布尔值的变量。（为了更容易理解，称为“开关”） - 列表 -> 存储多个其他变量的变量。列表也可以包含列表。

局部变量按场景 UID 存储。每个场景 UID 都存储着一个局部变量列表。

全局和持久变量存储在一个特定的域中。域只是一个唯一的名称，例如：com.example.game例如。默认域为空字符串。域有助于避免在与其他用户共享内容时变量编号重叠。

clearGlobalVariables

(
  • type
  • range
)

清除全局变量。

参数：

  • type Number
    • 确定要清除哪种类型的变量。
    • 0 = 全部
    • 1 = 开关/布尔值

    • 3 = 文本
    • 4 = 列表

    • 要清除的变量 ID 范围。如果null则清除所有变量。
