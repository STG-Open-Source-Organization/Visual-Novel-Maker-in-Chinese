Component_StackLayoutBehavior 类

模块：gs

将一个游戏对象转换为堆叠布局，并像垂直或水平堆叠一样布局所有子对象。该游戏对象需要一个容器组件。
堆叠布局中的子对象可以配置为可调整大小或不可调整大小（固定大小）。例如：

假设我们有一个宽度为 500px 的布局，其中包含三个控件。

| 80px | 动态 | 80px ||||

两个控件的固定大小为 80px，中间控件具有动态大小，因为它被配置为可调整大小。在这种情况下，可调整大小的控件的大小将为 340px，因为这是减去固定大小控件的大小 (160px) 后剩下的可用空间。

此外，每个子对象都可以有不同的对齐选项。

方法

calculateDynamicSizeHorizontal

() Number protected (受保护)

计算水平堆叠布局的动态大小。该大小用于可调整大小的控件，以使其填充所有可用空间。它的计算方式如下：

dynamic-size = sum-of-all-fixed-control-sizes / count-of-resizable-controls

返回：

Number:

动态大小。

Number:
