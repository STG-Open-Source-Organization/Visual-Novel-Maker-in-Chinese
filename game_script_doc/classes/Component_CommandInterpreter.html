Component_CommandInterpreter 类

模块：gs

一个允许游戏对象处理命令（例如场景对象命令）的组件。对于每个命令，都存在一个命令函数。要向解释器添加自己的自定义命令，只需创建一个子类并覆盖 gs.Component_CommandInterpreter.assignCommand 方法，并为您的自定义命令分配命令函数。

(

  • index

获取指定索引处的布尔变量的值。

booleanValueOf

(
  • object
)
Boolean

获取一个（可能的）布尔变量的值。如果指定了一个常量布尔值，此方法什么也不做，只是返回该常量值。这样做是为了更方便地传递一个可以通过变量计算的值，也可以只是一个常量值。

参数：

  • object Boolean | Object
    • 一个布尔变量或常量布尔值。

返回：

Boolean：

变量的值。

callCommonEvent

(
  • id
  • parameters
  • wait
)

调用一个通用事件，并返回它的子解释器。

参数：

  • id 编号
    • 要调用的公共事件的 ID。
  • 参数 对象
    • 可选的公共事件参数。
  • 等待 布尔值
    • 指示即使子解释器已完成，解释器是否应保持等待模式。

调用场景

(
  • uid
)

调用一个场景，并返回其子解释器。

参数：

  • uid 字符串
    • 要调用的场景的 UID。

更改十进制变量

(
  • params
  • roundMethod
)

更改数字变量，并允许使用十进制数值，如 0.5。

参数：

  • params 对象
    • 来自命令的输入参数。
  • roundMethod 对象
    • 运算结果将使用指定的方法进行四舍五入。
    • 0 = 无。结果将不进行四舍五入。
    • 1 = 商业（四舍五入）
    • 2 = 向上取整
    • 3 = 向下取整
