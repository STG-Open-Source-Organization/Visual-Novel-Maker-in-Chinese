maskIn（遮罩进入）

(
  • mask（遮罩）
  • duration（持续时间）
  • easingType（缓动类型）
  • [callback]（[回调]）
)

使用遮罩效果让游戏对象出现在屏幕上。

参数：

  • mask（遮罩） gs.Mask

    用于动画的遮罩。

  • duration（持续时间） Number（数字）

    帧数。

  • easingType（缓动类型） Object（对象）

    缓动类型。

  • [callback]（[回调]） Function（函数） 可选

    动画完成时调用的可选回调函数。
