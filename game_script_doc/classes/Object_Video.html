vn.Component_Animator

对象的动画组件，用于在其上执行移动、旋转等各种动画。

gs.Color

用于视觉呈现的对象颜色。

domain

字符串

对象所属的域。

events

gs.Component_EventEmitter

一个用于发出事件的事件发射器。

loop

布尔值指示视频是否应循环播放。默认为

false

gs.Mask

对象的蒙版，用于在其上执行蒙版效果。

布尔值

指示对象的可视化呈现是否应水平镜像。

gs.Rect

视觉呈现。

tone

gs.Tone

用于视觉呈现的对象色调。

video

字符串

用于视觉呈现的视频资源名称。
