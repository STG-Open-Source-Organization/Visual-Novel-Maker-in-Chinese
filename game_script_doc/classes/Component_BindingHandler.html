Component_BindingHandler 类

模块：ui

绑定处理器组件允许 UI 游戏对象执行属性绑定。

例如：文本标签可以将其 text 属性绑定到后端字段，例如当前的音乐音量，以便始终显示正确的音乐音量。如果音量发生变化，text 属性将自动更新。

要定义绑定，需要使用特殊的属性路径语法。例如：

$myTextField.text

是访问标识符为“myTextField”的文本字段对象的 text 属性的属性路径。有关更多信息，请查看帮助文件的“In Game UI System”（游戏内 UI 系统）部分。
