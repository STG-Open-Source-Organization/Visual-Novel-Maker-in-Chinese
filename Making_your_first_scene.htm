HTML 制作你的第一个场景

制作你的第一个场景吧

 

在本教程中，我们将向你演示如何搭建一个最基本的场景。首先你得确保读过《添加章节和场景》，这样你才能明白怎么创建章节和场景！对于本次教程，我们将使用默认的样例项目。

 

  • 在测试场景章节中，让我们创建一个New Scene名为“我的第一个场景”。

 

添加命令

当你第一次打开 Visual Novel Maker， 你就会注意到这块的命令面板：

 

如果想要查看这些命令，按下这些小图标之后，你就能看到命令列表了。添加命令有很多方法。比如，如果我们想在场景中添加一个开关（Switch）, 点击Basic命令 -- 如果你默认不在该部分的话。你也可以通过单击，拖拽或者在场景内容（Scene Content）中输入所需的命令，来添加开关命令。

 

现在我们知道了如何添加命令，那么让我们开始第一个场景吧！请记住，你在添加命令时可以通过实时预览来测试场景。

 

 

添加背景

  • 点击Background命令。
  • 添加Change Background。单击文件并选择一个背景。
  • 你也许会发现，在实时预览（Live Preview）中，动画是从左开始的。点击更改背景（Change Background）旁边的箭头，我们就能看到一些扩展选项。如果你想看有关这些命令的完整解释，只需点击更改背景的链接去那个词条阅读即可。但现在，我们将更改动画。
  • 点击 Animation 并选择 Blending。

 

添加背景音乐

  • 点击Audio Playback命令。
  • 添加Play Music命令。单击文件并选择一个音轨。有关每个命令的更多信息，只需参考页面即可。

 

在场景中添加一个角色

  • 单击Character命令。
  • 选择Join Scene 并选择一个角色。默认情况下，我们使用的是 Ace，并将动画更改为混合模式。
  • 要将角色移动到屏幕中央，请使用 Direct 或 Predefined -> Top。如果不确定，请参考此设置。
  • 现在角色就会出现在我们的场景中！

 

添加对话

  • 单击Message命令。
  • 选择Message Box Visibility并将 Visible 更改为 Yes。
  • 添加Show Message命令。将 Character 更改为 Ace。
  • 点击 Insert message text here 以输入文本！它可以是任何内容！

 

 

如果你正确执行了以上步骤，场景应该看起来像这样：

 

测试你的场景！

现在你的第一个场景已完成，是时候进行试玩了！

  • 右键单击场景并选择Set as Start Scene.  
  • 保存并按下Play按钮！
  • 会弹出一个小提示，这只是为了确保你在测试前已保存。只需点击 Yes。
  • 现在你可以测试你的游戏了！

 

注意：

  • 如果你想跳过语言屏幕和标题屏幕，右键单击场景并选择 Set as Intro Scene.

  • 你可以在Database -> System选项卡中更改介绍场景和开始场景。

 

恭喜你，你刚刚创建了你的第一个场景！
