示例：添加新的场景命令

 

Visual Novel Maker 附带了许多有用的内置命令，可以轻松创建自己的视觉小说。但是，在某些特殊情况下，根据视觉小说的复杂性，内置命令可能不够用，或者有必要修改它们。

 

在本例中，我们想添加一个场景命令，允许我们在屏幕上显示“添加新数据库类别”示例中的卡片。为此，让我们通过菜单下的“视图 > 扩展”打开 Extension Editor。

 

接下来，我们将右键单击“场景命令”文件夹，然后选择“新建 > 场景命令”来创建一个新场景命令。我们将它命名为“显示卡片”，因为我们想在屏幕上显示我们的卡片之一。它已经包含了一些基本的 JSON，如下所示：

 

{

"id": "ext.ShowCard",

"group": "Custom",

"defaultValue": {},

"quickItems": []

}

 

让我们一步一步地介绍 JSON：

 

  • id

命令的唯一标识符。它可以是任何文本，只要它足够独特即可。因此，您不必遵循任何格式或语法。但是，默认语法是 <module>.<name>，例如使用 vn.<name> 的视觉小说命令更具体，而更通用的命令使用 gs.<name>。但是，为了避免混淆，您不应使用 vn.<name> 或 gs.<name>，因为它们仅用于内置命令。

 

  • group

新命令应添加到的组/类别。您可以使用任何现有类别，或者仅定义您自己的类别，例如“我的自定义命令”。在我们的例子中，我们只使用“Custom”。

 

  • defaultValue

如果命令是新创建的，例如当用户将新命令从工具箱拖到场景内容时，命令的默认值。

 

  • quickItems

包含项目列表。项目是用户可以与之交互的 UI 控件，用于输入数字或文本值或从下拉菜单中选择值。

 

有关场景命令可能字段的完整列表，请查看Plugin API Reference.

 

在设计命令的 UI 之前，我们需要考虑该命令究竟应该做什么以及我们需要哪些数据。在我们的例子中，我们需要两件事：卡片和卡片在屏幕上显示的位置。让我们接下来实现 UI：

 

"quickItems": [

{

"type": "GSQDataRecordField",

"attribute": "cardId",

"dataSource":"cards",

"label": "Card",

"valueFormula": "return fmtRecord('cards', p.cardId);",

"variableButton": { "dataSource": "numbers" }

},

{

"type": "GSQStepper",

"attribute": "position.x",

"valueFormula": "return fmtNumVar(p.position.x);",

"label": "X",

"variableButton": { "dataSource": "numbers" },

"minimum": -GS.CONST.MAX_NUMBER_VALUE,

"maximum": GS.CONST.MAX_NUMBER_VALUE

},

{

"type": "GSQStepper",

"attribute": "position.y",

"valueFormula": "return fmtNumVar(p.position.y);",

"label": "Y",

"variableButton": { "dataSource": "numbers" },

"minimum": -GS.CONST.MAX_NUMBER_VALUE,

"maximum": GS.CONST.MAX_NUMBER_VALUE

}

]

 

正如我们所见，我们在命令中添加了三个项目。一个弹出式控件用于选择要显示的卡片，两个数字字段用于选择位置。让我们更深入地了解每个项目的字段。每个项目都可以有一些通用字段，这些字段适用于每种项目类型，也可以有一些特定于类型的字段。让我们从本例中使用的通用字段开始：

 

  • type (Required)

指示项目的类型，例如它是弹出式字段、数字字段等。必须存在该类型。

 

  • attribute

项目将存储其数据的后端 JavaScript 属性名。您稍后可以使用该名称通过脚本访问数据。该名称对于命令应该是唯一的，以避免冲突。

 

  • valueFormula

用于计算控件显示文本的 JavaScript 公式。我们在这里使用 fmtXXX 函数，它们会自动完成大部分工作。例如，fmtRecord 自动返回指定记录的显示文本，fmtNumVar 返回可以由变量计算的值的显示文本。有关更多信息，请查看Plugin API Reference.

 

  • label

字段的标签/描述，显示给用户。

 

  • variableButton

指示该值也可以由变量计算。通过“dataSource”，您可以指定要使用的变量类型。由于我们的所有字段内部都存储数字值，因此我们为数字变量使用“numbers”。

 

现在让我们看看本例中使用的特定于类型的字段：

 

  • dataSource

在我们的数据记录字段中使用，用于定义用于获取数据记录的数据源。这是数据记录视图的 category/attribute 字段中指定的名称。所以我们在这里使用“cards”来访问我们的卡片。内部我们的卡片存储为数字。

 

  • minimum

我们数字字段的最小值。我们在这里使用全局常量 GS.CONST.MAX_NUMBER_VALUE 来允许最大的负数。

 

  • maximum

我们数字字段的最大值。我们在这里使用全局常量 GS.CONST.MAX_NUMBER_VALUE 来允许最大的正数。

 

接下来让我们单击“预览”按钮，以查看我们命令的交互式预览，以检查 UI 是否正确。

 

就是这样！我们在编辑器端完成了！我们只需要保存我们的项目并重新启动 Visual Novel Maker 来查看我们的更改。如果我们打开一个场景并转到命令工具箱，我们将看到一个新的类别“Custom”，其中包含我们准备好使用的新命令！
