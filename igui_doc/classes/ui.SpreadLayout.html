ui.SpreadLayout 类

继承自ui.Layout

将所有控件平均分布在布局空间内，垂直或水平方向。

属性

action

ActionDescriptor

继承自ui.Control:

定义控件执行的操作。操作执行的确切时间取决于控件及其组件，但通常情况下，如果组件被点击，操作就会被触发。

actions

ActionDescriptor[]

继承自ui.Control:

允许定义控件执行的多个操作。操作按照其定义的顺序执行。有关更多信息，请参阅 ui.Control.action 属性。

alignmentX

String

继承自ui.Control:

控件在 x 轴上的对齐方式。需要布局支持。可用的对齐方式如下：

  • left
  • center
  • right

默认值："left"

alignmentY

String

继承自ui.Control:

控件在 y 轴上的对齐方式。需要布局支持。可用的对齐方式如下：

  • top
  • center
  • bottom

默认值："left"

anchor

Number

继承自ui.Control:

定义控件的锚点，用于旋转和缩放。例如：如果锚点设置为 [0.5, 0.5]，执行旋转时会围绕其自身中心旋转。否则，使用 [0, 0] 则会围绕其左上角旋转。锚点对目标矩形的（x/y）位置没有影响。

默认值：[0, 0]

animations

AnimationDescriptor[]

继承自ui.Control:

定义控件的动画。每个动画都需要绑定到不同的事件。

bindings

BindingDescriptor[]

继承自ui.Control:

控件使用的数据绑定。

blendMode

String

继承自ui.Control:

使用的混合模式。支持以下混合模式：

  • add - 加法混合
  • sub - 减法混合
  • normal - 正常混合

color

Number

继承自ui.Control:

控件的颜色。

components

ComponentDescriptor[]

继承自ui.Control:

添加到控件的附加组件。

customFields

Object

继承自ui.Control:

定义自定义数据的对象。该自定义数据默认不起作用，但可用于绑定或自定义组件。

默认值：null

dataField

String

继承自ui.Layout:

将布局与数据源关联。在这种情况下，布局的控件会根据数据量自动生成。使用 template 属性定义每个控件的外观。该值是一个绑定表达式，应返回数据数组或数值。如果是数值，则用作创建控件的数量。

该布局需要支持数据字段。只有 ui.StackLayout 和 ui.GridLayout 支持。

dataFilter

ConditionDescriptor

继承自ui.Layout:

对每个数据对象执行的条件。只有当条件返回true时，数据对象才会被处理。

draggable

DraggableDescriptor

继承自ui.Control:

使对象可以垂直或水平拖动。用于实现滑块、滚动条等。有关更多信息，请参见 descriptor。

enabled

Boolean

继承自ui.Control:

指示控件是否已启用。禁用的控件外观不同，并且不响应用户输入。确切的行为取决于控件的组件。

默认值：true

fixedSize

Boolean

继承自ui.Control:

如果设置为true，控件的大小将不会调整以适应关联的图像（例如 ui.Image 控件）。

默认值：false

frame

Number

继承自ui.Control:

定义控件的位置和大小。也可以使用百分比值和简单的公式。例如：

[0, 0, "100%", "100% - 50"]
[0, 0, "100%", "Math.max(100% - 50, 10)"]

group

String

继承自ui.Control:

将控件分配到一个组。效果取决于组件。

id

String

继承自ui.Control:

组件的唯一标识符。在公式和绑定表达式中可以使用 $访问控件。

inheritProperties

Boolean

继承自ui.Control:

指示控件是否从其父布局继承不透明度、缩放、角度、颜色、色调和锚点。

默认值：false

margin

Number

继承自ui.Control:

定义控件周围的空间。父布局必须支持边距。否则，此属性无效。格式为 [上, 左, 下, 右]。

opacity

Number

继承自ui.Control:

控件的不透明度。范围从 0（透明）到 255（不透明）。

默认值：255

order

Number

继承自ui.Control:

用于控制控件更新顺序的索引。值越高，控件在控件列表中更新得越早。

orientation

String

布局的方向，可以是 "vertical" 或 "horizontal"。

padding

Number

继承自ui.Control:

定义控件视觉内容周围的空间。它允许移动视觉内容而不影响控件的位置和大小。格式为 [上, 左, 下, 右]。

selectable

Boolean

继承自ui.Control:

指示控件是否可选。可选控件在选中/未选中状态下可能有不同的外观，但具体行为取决于组件。例如：gs.Component_HotspotBehavior 组件允许为选中/未选中状态使用不同的控件图像，并将游戏对象的 selected 属性设置为当前选择状态。

默认值：false

style

String

继承自ui.Control:

控件的样式名称。样式允许在中心位置定义控件属性，然后将其用于多个控件，以减少冗余数据。样式需要添加到 ui.UIManager.styles 对象中，该对象存储以样式名称为键、样式数据为值的键值对。例如：

ui.UIManager.styles.myCustomStyle = { "font": { "name": "Tahoma", "size": 40, "color": [255, 255, 255, 255] } }

要使用该样式，必须使用 style 属性：

{ "type": "ui.Text", "style": "myCustomStyle", "frame": [0, 0], "text": "White Text", "sizeToFit": true }

styles

String

继承自ui.Control:

允许向控件添加多个样式。有关更多信息，请参阅 ui.Control.style。

template

ui.Control| String

继承自ui.Layout:

定义在存在数据字段时用于创建控件的模板。它可以只是模板的名称或模板定义。要访问数据，模板应显示，可以使用 index 属性，该属性是布局中显示的每个控件的一部分。例如：

假设 dataField 定义为 "$dataFields.database.characters" 来显示所有字符。模板定义为简单的 ui.Text 控件。要显示每个字符的名称，可以使用以下绑定：

{ "sourceField": "$dataFields.database.characters[o.index].name", "targetField": "o.text" }

type

String

继承自ui.Control:

控件的类型名称。可以是模板的名称或内部类型名称。内部类型包括：

  • ui.Text
  • ui.Image
  • ui.ImageButton
  • ui.ImageMap
  • ui.Video
  • ui.FreeLayout
  • ui.StackLayout
  • ui.SpreadLayout
  • ui.GridLayout

updateBehavior

String

继承自ui.Control:

updateBehavior 控制控件在何种情况下被更新。

  • normal - 仅在必要时更新控件。但是，在某些情况下这还不够。
  • continuous - 每帧都更新控件。

更新一个控件并不意味着只有一个控件被更新。一个控件的单个更新可能会触发其他控件的更新，如果存在依赖关系，并且父布局也会被更新。

默认值："normal"

visible

Boolean

继承自ui.Control:

指示控件是否可见。不可见的控件不会被渲染，但仍然会在布局中占用空间。

默认值：true

zIndex

Number

继承自ui.Control:

z-index 控制控件的重叠。z-index 值较高的控件会绘制在 z-index 值较低的控件之上。
