ComponentDescriptor 类

描述一个组件，它应该使用 ui.Control.components 属性添加到控件中。

  • 索引
  • 属性

项目索引

属性

  • id
  • 字符串
  • 组件的可选标识符。该 ID 可用于将组件设置为特定操作的目标。
  • 默认：

null

module

字符串

应从中加载组件的模块名称。默认为“gs”模块。

默认："gs"

params

对象

一个可选的参数对象，该对象将被传递给组件的构造函数

默认：null

type

字符串

组件的类名，不带命名空间/模块前缀。

Default: null

type

String

The class-name of the component without namespace/module prefix.
