事件描述符类

描述一个事件，该事件可以与绑定和动画结合使用，仅在 指定事件发生时才执行它们。

在大多数情况下，事件描述符只是一个字符串，而不是一个对象。支持以下事件：

  • onInitialize - 仅在控件初始化后触发一次
  • onAlways - 此事件每帧都会触发。
  • onMouseHover - 仅在鼠标指针位于控件区域上方时触发。
  • onMouseLeave - 仅在鼠标指针离开控件区域后触发一次
  • onMouseEnter - 仅在鼠标指针进入控件区域后触发一次
  • onMouseDown - 仅在鼠标指针位于控件区域上方且按下鼠标左键时触发。
  • onChange - 此事件被定义为一个对象，而不仅仅是一个纯字符串。仅在指定字段更改时触发。

示例 1：将事件定义为字符串

{ .... "event": "onMouseHover" ....}

示例 2：定义一个 on-change 事件

{ .... "event": { "onChange": "o.text" } .... }
