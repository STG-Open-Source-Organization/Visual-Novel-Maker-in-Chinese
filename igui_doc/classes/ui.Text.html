action

ActionDescriptor

继承自ui.Control:

定义了控件执行的操作。操作执行的确切时间取决于控件及其组件，但通常情况下，如果组件被点击，操作就会触发。

actions

ActionDescriptor[]

继承自ui.Control:

允许定义控件执行的多个操作。操作按其定义顺序执行。有关更多信息，请参阅 ui.Control.action 属性。

alignmentX

String

继承自ui.Control:

控件在 x 轴上的对齐方式。需要布局支持。以下对齐方式可用：

  • left
  • center
  • right

默认值："left"

alignmentY

String

继承自ui.Control:

控件在 y 轴上的对齐方式。需要布局支持。以下对齐方式可用：

  • top
  • center
  • bottom

默认值："left"

anchor

Number

继承自ui.Control:

定义了用于旋转和缩放的控件锚点。例如：如果锚点设置为 [0.5, 0.5]，并且执行旋转，它将围绕自身的中心旋转。否则，使用 [0, 0]，它将围绕其左上角旋转。锚点对 dstRect 的位置（x/y）没有影响。默认值：[0, 0]

继承自

ui.Control:

控件的样式名称。样式允许在一个中心位置定义控件属性，然后将其用于多个控件以减少冗余数据。样式需要添加到 ui.UIManager.styles 对象中，该对象存储键值对，以样式名称作为键，样式数据作为值。例如：

updateBehavior 控制控件在哪些情况下会被更新。

normal - 仅在必要时更新控件。但有时这还不够。

continuous - 每帧都更新控件。更新一个控件并不意味着只有一个控件被更新。单个控件的更新也可能触发其他控件的更新，如果存在依赖关系，并且父布局也会被更新。默认值：

"normal"
