MaskToPrimitiveAnimationDescriptor 类

继承自PrimitiveAnimationDescriptor

描述了一个遮罩动画。

属性

duration

Number

持续时间的帧数。

easing

String

继承自PrimitiveAnimationDescriptor:

要使用的缓动类型。对 "sound"、"wait" 和 "playAnimation" 无效。可能的类型有：

  • linear_in/linear_out/linear_inout - 无平滑的线性运动
  • quad_in/quad_out/quad_inout - 二次缓动
  • quart_in/quart_out/quart_inout - 四次缓动
  • sine_in/sine_out/sine_inout - 正弦缓动
  • cubic_in/cubic_out/cubic_inout - 三次缓动
  • expo_in/expo_out/expo_inout - 指数缓动
  • circ_in/circ_out/circ_inout - 圆形缓动

默认值："linear_inout"

mask

String

要使用的遮罩图像。通常是一个灰度图像。

repeat

Boolean

继承自PrimitiveAnimationDescriptor:

指示动画流在下次运行时是否应再次播放。

默认值：true

type

String

继承自PrimitiveAnimationDescriptor:

定义要执行的动画的类型。支持的类型有：

  • changeTo
  • moveTo
  • blendTo
  • zoomTo
  • maskTo
  • shake
  • playAnimation
  • changeImages
  • sound
  • wait

有关更多信息，请查看不同的原始动画描述符。

vague

Number

边缘的平滑度 (vague)。如果0边缘是锐利的，这对于复古风格的游戏很有用而255

则非常平滑。

value

Number

要达到的目标值（0-255）。
