WaitPrimitiveAnimationDescriptor 类

扩展自PrimitiveAnimationDescriptor

暂停动画流程指定的时长。

  • 索引
  • 属性

项索引

属性

  • duration
  • easing
  • repeat
  • type
  • wait

属性

duration

数字

持续时长（以帧为单位）。

easing

字符串

继承自PrimitiveAnimationDescriptor：

要使用的缓动类型。对“sound”、“wait”和“playAnimation”没有影响。可能的类型包括：

  • linear_in/linear_out/linear_inout - 线性移动，无平滑处理
  • quad_in/quad_out/quad_inout - 二次缓动
  • quart_in/quart_out/quart_inout - 四次缓动
  • sine_in/sine_out/sine_inout - 正弦缓动
  • cubic_in/cubic_out/cubic_inout - 三次缓动
  • expo_in/expo_out/expo_inout - 指数缓动
  • circ_in/circ_out/circ_inout - 圆形缓动

默认值："linear_inout"

repeat

布尔值

继承自PrimitiveAnimationDescriptor：

指示动画是否应在动画流程的下一次运行时再次播放。

默认值：true

type

字符串

继承自PrimitiveAnimationDescriptor：

定义要执行的动画类型。支持的类型包括：

  • changeTo
  • moveTo
  • blendTo
  • zoomTo
  • maskTo
  • shake
  • playAnimation
  • changeImages
  • sound
  • wait

查看不同的原始动画描述符以获取更多信息。

wait

布尔值

继承自PrimitiveAnimationDescriptor：

指示动画流程在播放下一个动画之前是否等待当前动画完成。如果设置为false，则可以并行播放多个动画。

默认值：false
