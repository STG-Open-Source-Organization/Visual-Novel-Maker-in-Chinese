属性

action

ActionDescriptor

继承自ui.Control:

定义控件执行的操作。操作执行的确切时间取决于控件及其组件，但通常情况下，如果组件被点击，就会触发该操作。

actions

ActionDescriptor[]

继承自ui.Control:

允许定义控件执行的多个操作。操作按其定义顺序执行。有关更多信息，请参见 ui.Control.action 属性。

alignmentX

String

继承自ui.Control:

控件在 x 轴上的对齐方式。需要布局支持。以下对齐方式可用：

  • left
  • center
  • right

默认值："left"

alignmentY

String

继承自ui.Control:

控件在 y 轴上的对齐方式。需要布局支持。以下对齐方式可用：

  • top
  • center
  • bottom

默认值："left"

anchor

Number

继承自ui.Control:

定义控件的锚点，用于旋转和缩放。例如：如果锚点设置为 [0.5, 0.5]，执行旋转时，它将围绕自身的中心旋转。否则，使用 [0, 0] 时，它将围绕左上角旋转。锚点对 dstRect 的位置 (x/y)没有影响。默认值：

[0, 0]animations

AnimationDescriptor[]

继承自

ui.Control:为控件定义动画。每个动画都需要绑定到不同的事件。

bindings

BindingDescriptor[]

继承自

ui.Control:控件使用的数据绑定。

blendMode

String

继承自

ui.Control:用于混合的混合模式。支持以下混合模式：

add - 加法混合

  • sub - 减法混合
  • normal - 正常混合
  • color

Number

继承自

ui.Control:控件的颜色。

components

ComponentDescriptor[]

继承自

ui.Control:添加到控件的其他组件。

customFields

Object

继承自

ui.Control:一个用于定义自定义数据的对象。这些自定义数据默认没有效果，但可以在绑定或自定义组件中使用。

默认值：

nulldraggable

DraggableDescriptor

继承自

ui.Control:使对象可以垂直或水平拖动。适用于实现滑块、滚动条等。有关更多信息，请参见 descriptor。

enabled

Boolean

继承自

ui.Control:指示控件是否已启用。禁用控件的渲染方式不同，并且不会响应用户输入。具体行为取决于控件的组件。

默认值：

truefixedSize

Boolean

selectableBoolean继承自

ui.Control

:

指示控件是否可选。可选控件在选中/未选中状态下可能具有不同的外观，但具体行为取决于组件。例如：gs.Component_HotspotBehavior 组件允许控件在选中/未选中状态下使用不同的图像，并将游戏对象的 selected 属性设置为当前选择状态。

默认值：falsestyle

String

继承自ui.Control

:

控件的样式名称。样式允许集中定义控件属性，然后将其用于多个控件以减少冗余数据。样式需要添加到 ui.UIManager.styles 对象中，该对象存储键值对，以样式名称作为键，样式数据作为值。例如：

ui.UIManager.styles.myCustomStyle = { "font": { "name": "Tahoma", "size": 40, "color": [255, 255, 255, 255] } }要使用该样式，必须使用 style 属性：{ "type": "ui.Text", "style": "myCustomStyle", "frame": [0, 0], "text": "White Text", "sizeToFit": true }

updateBehavior 控制控件在何种情况下被更新。

normal - 仅在必要时更新控件。然而，在某些情况下这可能不够。continuous - 每帧都更新控件。更新一个控件并不意味着只有一个控件被更新。一个控件的更新可能会触发其他控件的更新，如果存在依赖关系，并且父布局也会被更新。

默认值：

  • "normal"
  • visible

Boolean

继承自ui.Control

:

指示控件是否可见。不可见的控件不会被渲染，但仍会在布局中占据空间。

默认值：truezIndex

Number

继承自ui.Control

:

z-index 控制控件的重叠。具有较高 z-index 的控件将绘制在具有较低 z-index 的控件之上。

Inherited from ui.Control:

The z-index controls the overlapping of controls. A control with a higher z-index is drawn above a control with a lower z-index.
