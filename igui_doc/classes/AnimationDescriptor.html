动画描述符 类

描述使用 ui.Control.animations 属性在控件上执行的动画。

  • 索引
  • 属性

项目索引

属性

  • clear
  • event
  • flow

属性

clear

布尔值

指示如果不再触发事件，是否立即停止所有正在运行的动画。

默认：true

event

事件描述符

将执行动画的事件。

flow

PrimitiveAnimationDescriptor[]

一组基础动画，例如简单的移动、旋转、缩放等，用于定义实际动画。
