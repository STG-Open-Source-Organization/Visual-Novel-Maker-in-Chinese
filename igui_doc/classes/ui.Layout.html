UI 布局 类

继承自UI 控件

属性

action

ActionDescriptor

继承自UI 控件:

定义了控件执行的操作。操作执行的确切时间取决于控件及其组件，但通常在组件被点击时触发操作。

actions

ActionDescriptor[]

继承自UI 控件:

允许定义控件执行的多个操作。操作按其定义顺序执行。有关更多信息，请参阅 ui.Control.action 属性。

alignmentX

String

继承自UI 控件:

控件在 x 轴上的对齐方式。需要由布局支持。可用对齐方式如下：

  • left
  • center
  • right

默认："left"

alignmentY

String

继承自UI 控件:

控件在 y 轴上的对齐方式。需要由布局支持。可用对齐方式如下：

  • top
  • center
  • bottom

默认："left"

anchor

Number

继承自UI 控件:

定义控件的锚点，用于旋转和缩放。例如：如果锚点设置为 [0.5, 0.5]，执行旋转时，它将围绕自身中心旋转。否则，使用 [0, 0] 将围绕其左上角旋转。锚点对目标矩形的位置（x/y）没有影响。默认：

[0, 0]animations

AnimationDescriptor[]

继承自

UI 控件:为控件定义动画。每个动画都需要绑定到不同的事件。

bindings

BindingDescriptor[]

继承自

UI 控件:控件使用的数据绑定。

blendMode

String

继承自

UI 控件:使用的混合模式。支持以下混合模式：

add - 加法混合

  • sub - 减法混合
  • normal - 普通混合
  • color

Number

继承自

UI 控件:控件的颜色。

components

ComponentDescriptor[]

继承自

UI 控件:添加到控件的附加组件。

customFields

Object

继承自

UI 控件:一个用于定义自定义数据的对象。这些自定义数据默认情况下没有效果，但可以用于绑定或自定义组件。

默认：

nulldataField

String

将布局与数据源关联。在这种情况下，布局的控件会根据数据量自动生成。使用 template 属性来定义每个控件的外观。该值是一个绑定表达式，应返回一个数据数组或一个数值。如果是一个数值，它将用作要创建的控件的数量。

布局需要支持数据字段。只有 ui.StackLayout 和 ui.GridLayout 才支持此功能。

dataFilter

ConditionDescriptor

一个在每个数据对象上执行的条件。只有当条件返回

true时，数据对象才会被处理。draggable

DraggableDescriptor

继承自

UI 控件:使对象可以垂直或水平拖动。对于实现滑块、滚动条等非常有用。有关更多信息，请参阅描述符。

enabled

Boolean

继承自

UI 控件:指示控件是否已启用。禁用的控件显示不同，并且不响应用户输入。具体行为取决于控件的组件。

默认：

truefixedSize

Boolean

继承自

UI 控件:如果为

true，则控件的大小不会像 ui.Image 控件那样调整以适应关联的图像。默认：

falseframe

Number

继承自

UI 控件:定义控件的位置和大小。也可以使用百分比值和简单的公式。例如：

[0, 0, "100%", "100% - 50"]

[0, 0, "100%", "Math.max(100% - 50, 10)"]
group

String

继承自

UI 控件:将控件分配到一个组。其效果取决于组件。

id

String

继承自

UI 控件:组件的唯一标识符。可以在公式和绑定表达式中使用 $

来访问控件。inheritProperties

Boolean

继承自

UI 控件:指示控件是否从其父布局继承不透明度、缩放、角度、颜色、色调和锚点。

默认：

falsemargin

Number

继承自

UI 控件:定义控件周围的空间。父布局必须支持边距。否则，此属性无效。格式为 [上, 左, 下, 右]。

opacity

Number

继承自

UI 控件:控件的不透明度。从 0=透明到 255=不透明。

默认：

255order

Number

继承自

UI 控件:用于控制控件更新顺序的顺序索引。值越高，控件在控件列表中更新的越早。

padding

Number

继承自

UI 控件:定义控件视觉内容周围的空间。它允许在不影响控件位置和大小的情况下移动视觉内容。格式为 [上, 左, 下, 右]。

selectable

Boolean

继承自

UI 控件:指示控件是否可选择。可选择控件在选中/未选中状态下可能具有不同的外观，但具体行为取决于组件。例如：gs.Component_HotspotBehavior 组件允许为选中/未选中状态使用不同的控件图像，并将游戏对象的 selected 属性设置为当前选择状态。

默认：

falsestyle

String

继承自

UI 控件:控件的样式名称。样式允许在中心位置定义控件属性，然后将其重用于多个控件以减少冗余数据。样式需要添加到 ui.UIManager.styles 对象中，该对象存储键值对，样式名称作为键，样式数据作为值。例如：

ui.UIManager.styles.myCustomStyle = { "font": { "name": "Tahoma", "size": 40, "color": [255, 255, 255, 255] } }

要使用该样式，必须使用 style 属性：

{ "type": "ui.Text", "style": "myCustomStyle", "frame": [0, 0], "text": "White Text", "sizeToFit": true }

styles

String

继承自

UI 控件:允许向控件添加多个样式。有关更多信息，请参阅 ui.Control.style。

template

ui.Control

| String定义当 data-field 存在时用于创建控件模板。它可以只是模板的名称或

模板定义。要访问模板应显示的，可以使用 index 属性，该属性是布局中显示的每个控件的一部分。例如：

{ "sourceField": "$dataFields.database.characters[o.index].name", "targetField": "o.text" }

type

String

继承自UI 控件:

控件的类型名称。可以是模板的名称或内部类型名称。内部类型包括：

  • ui.Text
  • ui.Image
  • ui.ImageButton
  • ui.ImageMap
  • ui.Video
  • ui.FreeLayout
  • ui.StackLayout
  • ui.SpreadLayout
  • ui.GridLayout

updateBehavior

String

继承自UI 控件:

updateBehavior 控制在何种情况下控件会被更新。

  • normal - 仅在必要时更新控件。然而，在某些情况下这还不够。
  • continuous - 每帧都更新控件。

更新一个控件并不意味着只有一个控件被更新。单个控件的更新可能会触发其他控件的更新，如果存在依赖关系，并且父布局也会被更新。

默认："normal"

visible

Boolean

继承自UI 控件:

指示控件是否可见。不可见控件将不会被渲染，但在布局中仍会占用空间。

默认：true

zIndex

Number

继承自UI 控件:

z-index 控制控件的重叠。z-index 值较高的控件将绘制在 z-index 值较低的控件之上。
