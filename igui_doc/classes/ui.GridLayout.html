action

ActionDescriptor

继承自ui.Control:

定义控件执行的操作。操作执行的确切时间取决于控件及其组件，但通常情况下，如果组件被点击，则会触发操作。

actions

ActionDescriptor[]

继承自ui.Control:

允许定义控件执行的多个操作。操作按其定义的顺序执行。有关更多信息，请参阅 ui.Control.action 属性。

alignmentX

String

继承自ui.Control:

控件在 x 轴上的对齐方式。需要布局支持。以下对齐方式可用：

  • left
  • center
  • right

默认值："left"

alignmentY

String

继承自ui.Control:

控件在 y 轴上的对齐方式。需要布局支持。以下对齐方式可用：

  • top
  • center
  • bottom

默认值："left"

anchor

Number

继承自ui.Control:

定义控件的锚点，用于旋转和缩放。例如：如果锚点设置为 [0.5, 0.5]，执行旋转时，它将围绕自身的中心旋转。否则，使用 [0, 0]，它将围绕其左上角旋转。锚点对 dstRect 的位置（x/y）没有影响。默认值：[0, 0]

  • String
  • 继承自
  • ui.Control
  • :
  • updateBehavior 控制控件在哪些情况下会被更新。
  • normal - 仅在必要时更新控件。然而，在某些情况下这还不够。

continuous - 每帧更新控件。

更新一个控件并不意味着只有一个控件被更新。一个控件的更新可能会触发其他控件的更新，如果存在依赖关系，并且父布局也会被更新。

默认值："normal"visible
