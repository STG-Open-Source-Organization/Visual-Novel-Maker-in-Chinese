ConditionDescriptor 类

描述用于操作和绑定的条件。条件检查指定的 binding-expression 的值是否 与 equalTo-、greaterThan-、lessThan- 和 notEqualTo- 属性定义的值匹配。

属性

equalTo

Object | Number | String | Boolean

用于定义要检查的值的绑定表达式。检查 field 值是否等于此值。

field

String

用于定义要检查的值的绑定表达式。

greaterThan

Object | Number | String | Boolean

用于定义要检查的值的绑定表达式。检查 field 值是否大于此值。

lessThan

Object | Number | String | Boolean

用于定义要检查的值的绑定表达式。检查 field 值是否小于此值。

notEqualTo

Object | Number | String | Boolean

用于定义要检查的值的绑定表达式。检查 field 值是否不等于此值。
