属性

action

ActionDescriptor

定义控件执行的动作。动作执行的确切时间取决于控件及其组件，但通常情况下，如果组件被点击，则会触发该动作。

actions

ActionDescriptor[]

允许定义控件执行的多个动作。动作按其定义顺序执行。有关更多信息，请参见 ui.Control.action 属性。

alignmentX

String

控件在 x 轴上的对齐方式。需要布局支持。可用的对齐方式如下：

  • left
  • center
  • right

默认值："left"

alignmentY

String

控件在 y 轴上的对齐方式。需要布局支持。可用的对齐方式如下：

  • top
  • center
  • bottom

默认值："left"

anchor

Number

定义控件的锚点，用于旋转和缩放。例如：如果锚点设置为 [0.5, 0.5]，并且执行旋转，它将围绕自身的中心旋转。否则，使用 [0, 0]，它将围绕其左上角旋转。锚点对位置（dstRect 的 x/y）没有影响。Default:[0, 0]

animationsAnimationDescriptor[]

定义控件的动画。每个动画都需要绑定到不同的事件。

bindings

BindingDescriptor[]

控件使用的数据绑定。

blendMode

String

使用的混合模式。支持以下混合模式：

add - 加法混合

sub - 减法混合

  • normal - 正常混合
  • color
  • Number

控件的颜色。

components

ComponentDescriptor[]

添加到控件的附加组件。

customFields

Object

用于定义自定义数据的对象。该自定义数据默认情况下不起作用，但可以与绑定或自定义组件一起使用。

默认值：

null

draggableDraggableDescriptor

使对象可垂直或水平拖动。用于实现滑块、滚动条等。有关更多信息，请参见描述符。

enabled

Boolean

指示控件是否启用。禁用的控件会以不同的方式呈现，并且不会响应用户输入。确切的行为取决于控件的组件。

默认值：

true

fixedSizeBoolean

如果为 true，则控件的大小不会调整以适应关联的图像（如 ui.Image 控件）。

默认值：

falseframeNumber

定义控件的位置和大小。也可以使用百分比值和小型公式。例如：[0, 0, "100%", "100% - 50"]

[0, 0, "100%", "Math.max(100% - 50, 10)"]

group

String

将控件分配给一个组。其效果取决于组件。
id

String

组件的唯一标识符。可以使用 $ 在公式和绑定表达式中访问控件。

inheritProperties

Boolean

指示控件是否从其父布局继承不透明度、缩放、角度、颜色、色调和锚点。

默认值：false

margin

Number

定义控件周围的空间。父布局必须支持边距。否则，此属性无效。格式为 [上, 左, 下, 右]。

opacityNumber

控件的不透明度。从 0=透明到 255=不透明。

默认值：

255

order

Number

用于控制控件更新顺序的顺序索引。值越高，控件在控件列表中更新的顺序越早。

paddingNumber

定义控件视觉内容周围的空间。它允许在不影响控件的位置和大小的情况下移动视觉内容。格式为 [上, 左, 下, 右]。

selectable

Boolean

指示控件是否可选择。可选择控件在选中/未选中状态下可能具有不同的外观，但确切的行为取决于组件。例如：gs.Component_HotspotBehavior 组件允许选中/未选中状态下不同的控件图像，并将游戏对象的 selected 属性设置为当前选择状态。

默认值：

false

style

String

控件的样式名称。样式允许在一个中心位置定义控件属性，然后将其重用于多个控件以减少冗余数据。样式需要添加到 ui.UIManager.styles 对象中，该对象存储键值对，以样式名称作为键，样式数据作为值。例如：

ui.UIManager.styles.myCustomStyle = { "font": { "name": "Tahoma", "size": 40, "color": [255, 255, 255, 255] } }要使用该样式，必须使用 style 属性：

{ "type": "ui.Text", "style": "myCustomStyle", "frame": [0, 0], "text": "White Text", "sizeToFit": true }

styles

String

允许向控件添加多个样式。有关更多信息，请参见 ui.Control.style。

type

String

控件的类型名称。可以是模板的名称或内部类型名称。内部类型包括：

ui.Text

ui.Image

ui.ImageButton

ui.ImageMap

ui.Video

  • updateBehavior
  • String
  • updateBehavior 控制控件在何种情况下被更新。
  • normal - 仅在必要时更新控件。但是，在某些情况下这还不够。
  • continuous - 每帧都更新控件。

更新控件并不意味着只更新一个控件。控件的单个更新可能会触发其他控件的更新，如果存在依赖关系，并且父布局也会被更新。

默认值：

"normal"

  • visible
  • Boolean

指示控件是否可见。不可见的控件不会被渲染，但仍会在布局中占用空间。

默认值：true

zIndex

Number

z-index 控制控件的重叠。z-index 值较高的控件绘制在 z-index 值较低的控件之上。

Default: true

zIndex

Number

The z-index controls the overlapping of controls. A control with a higher z-index is drawn above a control with a lower z-index.
