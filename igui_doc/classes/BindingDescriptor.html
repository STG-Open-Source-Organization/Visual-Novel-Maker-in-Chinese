BindingDescriptor 类

描述了可在组件的 bindings-property 中使用的绑定。数据绑定支持许多高级功能，但

  • 建议使用自己的组件来构建复杂的控件，而不是尝试用复杂的绑定表达式来构建。

convertRatio

BindingRatioConversionDescriptor

定义了比例转换。有时需要将一个值从一个值空间转换为另一个值空间。例如，

一个音量滑块控件，滑块旋钮在 0 - 500 像素之间垂直移动，但其值应存储在 0 和 100 之间。

在这种情况下，在写入 target-field 之前，需要将旋钮的 y 坐标 (0 - 500) 转换为音量值空间 (0 到 100)。

上面的例子可以使用以下比例转换来实现：

{... "sourceField": "$slider_knob.dstRect.y", "targetField": "$dataFields.settings.generalMusicVolume", "convertRatio": { "target": 100, "source": 500 } ... }

实际用于比例转换的内部公式是：targetField = (convertRatio.target - convertRatio.targetSize) / (sourceField - convertRatio.sourceSize) * (source-field - value-offset) + offset

因此，还有一些其他属性可用于更好地控制比例转换。有关更多信息，请参阅 BindingRatioConversionDescriptor。
