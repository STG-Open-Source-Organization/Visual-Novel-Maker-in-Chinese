ActionDescriptor 类

描述了一个可以由组件执行的操作。

  • 索引
  • 属性

项目索引

  • conditions
  • name
  • params
  • target
  • wait

属性

conditions

ConditionDescriptor[]

定义了在操作执行之前必须满足的条件。如果为控件定义了多个操作，则只有条件为true的操作才会执行。nameString

要执行的操作的名称。该名称必须与目标对象类中的操作方法的名称匹配。

params

Object

一个可选的参数对象，作为第二个参数传递给目标对象的操作方法。

target

String

应该在其上执行操作的目标对象。目标对象的类需要包含在 ActionDescriptor.name 属性中定义的操作方法。默认目标对象是当前场景行为组件。

target 属性首先被解释为绑定表达式。如果该表达式没有返回结果，则将其解释为操作目标表达式，语法如下：

[control-id].[component-id]

例如：

{ .... "target": "myControl.myComponent" .... }

如果控件或组件不存在，则使用当前场景行为组件。

wait

Number

定义操作执行前的延迟时间（以帧为单位）。

Number

Defines a time-delay in frames before the action is executed.
