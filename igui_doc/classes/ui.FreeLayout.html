ui.FreeLayout 类

继承自ui.Layout

以其指定位置排列所有控件。因此，这种布局允许每个控件 自由定位。

此外，每个控件还可以具有不同的对齐选项。

属性

action

ActionDescriptor

继承自ui.Control:

定义控件执行的动作。动作执行的确切时间取决于控件及其组件 ，但通常情况下，如果组件被点击，动作就会触发。

actions

ActionDescriptor[]

继承自ui.Control:

允许定义多个由控件执行的动作。动作按其定义顺序执行。有关更多信息，请参见 ui.Control.action 属性。

alignmentX

String

继承自ui.Control:

控件在 x 轴上的对齐方式。需要布局支持。以下对齐方式可用：

  • left
  • center
  • right

默认值:"left"

alignmentY

String

继承自ui.Control:

控件在 y 轴上的对齐方式。需要布局支持。以下对齐方式可用：

  • top
  • center
  • bottom

默认值:"left"

anchor

Number

继承自ui.Control:

定义用于旋转和缩放的控件锚点。例如：如果锚点设置为 [0.5, 0.5] 并执行旋转 ，则会围绕其自身中心旋转。否则，使用 [0, 0] 会围绕其左上角旋转。锚点对 dstRect 的位置（x/y）没有影响。

默认值:[0, 0]

animations

AnimationDescriptor[]

继承自ui.Control:

定义控件的动画。每个动画都需要绑定到不同的事件。

bindings

BindingDescriptor[]

继承自ui.Control:

控件使用的数据绑定。

blendMode

String

继承自ui.Control:

使用的混合模式。支持以下混合模式：

  • add - 加法混合
  • sub - 减法混合
  • normal - 正常混合

color

Number

继承自ui.Control:

控件的颜色。

components

ComponentDescriptor[]

继承自ui.Control:

添加到控件的附加组件。

customFields

Object

继承自ui.Control:

用于定义自定义数据的对象。此自定义数据默认无效，但可用于绑定或自定义组件。

默认值:null

dataField

String

继承自ui.Layout:

将布局与数据源关联。在这种情况下，布局的控件将自动生成 ，具体取决于数据量。使用 template 属性来定义每个控件的外观。该值 是绑定表达式，应返回数据数组或数值。如果返回的是数值，则将 用于创建控件的数量。

布局需要支持数据字段。只有 ui.StackLayout 和 ui.GridLayout 支持。

dataFilter

ConditionDescriptor

继承自ui.Layout:

对每个数据对象执行的条件。仅当条件返回true时，才会处理数据对象。

draggable

DraggableDescriptor

继承自ui.Control:

使对象可以垂直或水平拖动。用于实现滑块、滚动条等。有关更多信息，请参见描述符。

enabled

Boolean

继承自ui.Control:

指示控件是否已启用。禁用控件的显示方式不同，也不会响应用户输入。确切的行为取决于 控件的组件。

默认值:true

fixedSize

Boolean

继承自ui.Control:

如果为true，则控件的大小不会调整以适应关联的图像，例如对于 ui.Image 控件。

默认值:false

frame

Number

继承自ui.Control:

定义控件的位置和大小。还可以使用百分比值和简单公式。例如：

[0, 0, "100%", "100% - 50"]
[0, 0, "100%", "Math.max(100% - 50, 10)"]

group

String

String

继承自

ui.Control:控件的样式名称。样式允许在中心位置定义控件属性，然后为多个控件重用，以减少 冗余数据。样式需要添加到 ui.UIManager.styles 对象中，该对象存储键值对，其中样式名称作为键，样式数据作为值。例如：

String

继承自

ui.Control:updateBehavior 控制控件在何种情况下会被更新。

normal - 仅在必要时更新控件。但是，在某些情况下这还不够。

  • continuous - 每帧都更新控件。
  • 更新控件并不意味着只更新一个控件。单个控件的更新可能会触发其他控件的更新，如果存在依赖关系，并且父布局也会被更新。

默认值:

"normal"visible

truezIndex

Number

继承自

ui.Control:z-index 控制控件的重叠。z-index 值更高的控件会绘制在 z-index 值较低的控件之上。

The z-index controls the overlapping of controls. A control with a higher z-index is drawn above a control with a lower z-index.
