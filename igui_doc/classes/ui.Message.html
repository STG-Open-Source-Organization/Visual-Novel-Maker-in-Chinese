ui.Message 类

继承自ui.Control

在屏幕上显示游戏消息。此控件没有任何控件特定的属性可设置。如果用于

  • game-scene 中，其 ID 应为 "gameMessage_message"，以便 game-scene 解释器可以控制
  • 消息。
