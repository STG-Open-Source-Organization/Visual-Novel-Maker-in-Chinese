示例：操作

 

With 操作，您可以执行各种后台函数，例如开始新游戏、保存游戏、退出游戏、切换到另一个布局等等。如果需要，您甚至可以定义自己的操作。在我们第一个例子中，我们已经为自己的标题屏幕使用了操作来开始新游戏或退出游戏。现在让我们更仔细地看看它。对于我们的标题屏幕，我们使用了一个操作来开始新游戏：

 

{

"type": "ui.Button",

"params": { "text": "新游戏", "action": { "name": "newGame" } },

"style": "titleScreenButton"

}

 

如果我们单击该按钮，新游戏就会开始。有时还需要将额外数据传递给操作，如下例所示：

 

{

"type": "ui.Button",

"params": { "text": "加载游戏", "action": { "name": "switchLayout", "params": { "name": "loadMenuLayout" } } },

"style": "titleScreenButton"

}

 

在这里，我们执行“switchLayout”操作，该操作会切换到新布局。但是我们需要指定要切换到的布局的名称。

 

操作的逻辑在操作的目标中定义。默认情况下，目标是场景组件，例如 Component_LayoutSceneBehavior 或 Component_GameSceneBehavior。在上面的例子中，“newGame”操作就像一个常规方法一样定义在 Component_LayoutSceneBehavior 脚本中。

 

newGame: (sender, params) ->

...........................

 

作为操作方法调用的方法应始终提供两个参数：sender 和 params。Sender 是触发此操作的对象，在我们的例子中，它将是按钮对象。Params 对象包含我们通过 params 属性传递给操作的数据。

 

因此，操作的名称必须与目标对象的一个方法名称匹配。该方法将 sender 对象作为第一个参数，将 params 对象作为第二个参数。

 

不强制要求，但建议为操作方法使用“action_”前缀，例如“action_myMethod”，以清楚地表明此方法可以安全地作为操作方法执行。
