示例：数据绑定

 

A在上一节示例中学习了一些基本知识后，我们在本示例中尝试一些更高级的内容：数据绑定。数据绑定允许我们显示甚至更改后台数据，如游戏设置、数据库中的角色等。因为绑定是一个更复杂的主题，请查看游戏内UI API参考和现有的布局和模板以了解更多关于绑定的信息。

 

好处是，如果您只想更改游戏内UI的设计而不更改逻辑，在大多数情况下您不需要完全理解绑定。只有当您想开发新东西时，才需要完全理解绑定。

 

但让我们看看下面的例子：

 

ui.UIManager.layouts.titleLayout = {

"类型": "ui.FreeLayout",

"框架": [0, 0, Graphics.width, Graphics.height],

"控件": [

{

"类型": "ui.Text",

"sizeToFit": true,

"绑定": [{ "sourceField": "$dataFields.database.characters[0].name", "targetField": "o.text" }]

"alignmentX": "center",

"alignmentY": "center"

}

]

}

 

如果我们用这个标题布局测试游戏，我们将看到一个黑色的屏幕，上面居中显示着第一个角色的名字。这是因为我们将第一个角色的 name 属性绑定到了我们的文本控件的 text 属性。

使用 bindings 属性，我们可以向控件添加多个绑定。让我们看看绑定属性：

 

  • sourceField

在这里，我们定义了要写入 targetField 的源字段。在我们的例子中，我们使用绑定语法定义了以下源字段：

 

"$dataFields.database.characters[0].name"

 

使用 $dataFields，我们访问当前为布局定义的数据源。在大多数情况下，这是在“DataSource_Default”脚本中定义。但我们稍后会检查。使用“database”，我们访问数据库，使用“characters”，我们访问 characters 集合。使用“[<index>]”，我们指定要访问哪个字符。在我们的例子中是“0”，所以我们想使用“name”来访问第一个字符的名字。

 

  • targetField

在这里，我们定义了目标字段。源字段的值将被写入此字段。我们定义了“o.text”作为目标字段。使用“o”，我们表示我们要访问当前正在执行绑定表达式的对象，在本例中是文本控件，使用“text”，我们表示我们要写入 text 属性。这就是为什么字符的名字会出现在屏幕上的原因。

 

内部来说，绑定表达式只是 JavaScript 公式。但你不应该滥用绑定表达式来执行更复杂的 JavaScript 代码。如果当前的可能性对您来说不够强大，您应该只使用公式或编写自己的组件，就像我们在下一个示例中将要学习的那样。
