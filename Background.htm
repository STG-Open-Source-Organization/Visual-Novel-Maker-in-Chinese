背景

 

背景的命令允许你通过特效(effects)，为你的场景带来生命。

 

改变背景

为你的场景设置背景。

  • 文件- 将要运行的图片文件。

  • 层- 设置你的背景的优先级顺序。数字越大，它们出现的层级越高。

  • 持续时间- 设置切换动画应花费的时间。将其设置为零 (0) ms 将使其立即出现。

  • 等待/继续- 设置命令为等待，意味着场景将在背景出现后再执行下一个命令。

  • 特效- 这些选项会影响背景的出现方式。

  • 缓动设置背景的缓动运动。更多信息请参阅缓动特效页面。

  • 动画设置背景动画。

    • 移动是背景出现的位置点，它可以从左/上/右/下出现。

    • 混合允许你使用调和(blending)来让背景淡入/淡出。

    • 遮罩允许你从Masks文件夹里面，用遮挡图片(a mask image)来淡入。

      • 模糊遮罩边缘的平滑度。

  • 循环- 设置“是”以进行垂直或水平循环。或“否”以关闭循环。

  • 显示- 允许你指定背景的显示顺序和锚点。

  • 锚点设置你的背景在左上角和中心之间的锚点。仅当使用缩放和旋转命令时，将锚点设置为中心才重要，并且不会影响定位。

  • Z 顺序设置背景的显示顺序。

  • 视口- 背景将被分配到的视口。视口决定背景是否受到摄像机移动或屏幕效果的影响。

    • 场景- 背景被分配到场景视口，并表现得像属于场景的对象，因此会受到摄像机移动和屏幕效果的影响。

    • 用户界面- 背景被分配到 UI 视口，并表现得像属于用户界面的对象，因此不会受到摄像机移动和屏幕效果的影响。

 

混合背景

将背景混合到指定的透明度。

  • 数字- 设置将受影响的背景图像。

  • 不透明度- 不透明度。

  • 持续时间 -混合动画的持续时间。

  • 继续将使场景立即继续。

  • 等待将使场景等待直到混合动画完成。

  • 缓动影响混合动画。更多信息请参阅缓动特效页面。

 

缩放背景

缩放背景，使其朝向锚点。

  • 层- 设置将受影响的背景图像。

  • X 缩放- 设置水平缩放。

  • Y 缩放- 设置垂直缩放。

  • 持续时间- 确定背景缩放效果需要多长时间。

  • 等待/继续- 设置命令为等待，意味着场景将在执行下一个命令集之前等待此命令完成。

  • 缓动设置背景的缓动运动。更多信息请参阅缓动特效页面。

 

旋转背景

以指定的 speeds 和方向旋转你的背景。

  • 层 - 设置将受影响的背景图像。

  • 方向- 设置顺时针或逆时针旋转方向。

  • 速度- 旋转速度。值越高，旋转越快。

  • 持续时间- 确定旋转效果需要多长时间。

  • 继续将使场景立即继续。

  • 等待将使场景等待直到退出动画完成。

  • 缓动影响旋转动画。更多信息请参阅缓动特效页面。

 

 

摇动背景

摇动背景，适用于描绘震惊或冲击的场景。

  • 层- 设置将受影响的背景图像。例如，如果你有不止一张，你可以摇动层二 (2) 而不影响显示在层一的背景。

  • X 范围- 设置背景图像的水平移动。它会在你设定的值的负值和正值之间随机变化。
    例如，如果你输入 5，背景将从 -5 到 5 摇动。

  • Y 范围- 设置背景图像的垂直移动。它会在你设定的值的负值和正值之间随机变化。
    例如，如果你输入 5，背景将从 -5 到 5 摇动。

  • 速度- 通过设置像素偏移量来确定摇动的强度或力度。

  • 持续时间- 确定背景将摇动多长时间。

  • 等待/继续- 设置命令为等待，意味着场景将在背景停止摇动后再加载下一个命令。

  • 缓动设置背景的缓动运动。更多信息请参阅缓动特效页面。

 

滚动背景

为你的背景图像创建滚动效果。

  • 层- 设置受此滚动命令影响的背景层。

  • X 速度- 设置水平滚动速度。

  • Y 速度 -设置垂直滚动速度。

  • 持续时间- 背景将继续滚动的时长。

  • 等待/继续- 设置命令为等待，意味着场景将在执行下一个命令集之前等待此命令完成。

  • 缓动设置背景的缓动运动。更多信息请参阅缓动特效页面。

 

滚动背景到

将背景滚动到指定位置。

  • 层- 设置将受影响的背景图像。

  • 位置- 角色的目标位置。

  • 预定义 -允许选择在数据库 > 系统 > 预定义对象位置中配置的预定义位置之一。

  • 直接- 允许你使用图形编辑器设置目标位置。

  • 计算 -- 允许通过变量计算目标位置。

  • 持续时间- 背景需要多长时间才能到达选定的位置。

  • 等待/继续- 设置命令为等待，意味着场景将在执行下一个命令集之前等待此命令完成。

  • 缓动设置背景的缓动运动。更多信息请参阅缓动特效页面。

 

背景特效

对角色应用特效。

  • 类型- 将应用于背景的特效。

  • 摆动使背景以不规则和摇摆的运动。只有在禁用循环时才有效。

    • 强度设置摆动的强度。值越高，摆动效果越明显。

    • 速度 设置摆动的速度。值越高，速度越快。

    • 方向- 设置摆动方向。

      • 垂直将摆动方向设置为垂直方向。

      • 水平将摆动方向设置为水平方向

      • 两者将摆动方向设置为两个方向。

    • 持续时间设置效果持续的时间（以毫秒为单位）。

  • 模糊对背景无效。

  • 像素化使背景看起来像素化/块状。

    • 宽度设置单个块/像素的宽度。

    • 高度设置单个块/像素的高度。

    • 持续时间设置像素化达到指定块/像素尺寸所需的时间（以毫秒为单位）。使用此选项可以平滑地像素化背景。

  • 缓动将缓动应用于特效动画。更多信息请参阅缓动特效页面。
