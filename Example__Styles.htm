示例：样式

 

如果您查看第一个示例中的自定义标题屏幕，您会发现我们的按钮定义有一些冗余数据，例如底部边距为 10 像素，并且它们都是可调整大小的。在我们的示例中没问题，但在更复杂的场景中，如果您以后决定进行更改，例如使用 15 像素的边距而不是 10 像素，这将成为一个巨大的问题。因为那时我们必须检查并更改我们所有的控件。这就是样式（styles）可以帮助你的地方！

 

样式（style）定义

样式（style）允许您一次定义一组属性，然后将其重新用于任意数量的控件或布局。如果要定义新样式（style），可以在每个脚本中定义，甚至可以创建一个新脚本。所有默认样式都位于“Style”文件夹中的“Style_Default”脚本。示例样式如下所示：

 

ui.UIManager.styles.titleScreenButton = {

"resizable": true,

"margin": [0, 0, 0, 10]

}

 

我们把它放在“Style_Default”脚本的末尾。第一行的格式始终相同：

 

ui.UIManager.styles.<style_name> = {

 

没有必要完全理解这一行，重要的是您必须为您的样式（style）定义一个唯一的名称。名称不应包含任何空格或特殊字符。

 

定义样式(style)后，我们可以像这样更改标题屏幕示例：

 

ui.UIManager.layouts.titleLayout = {

"类型": "ui.FreeLayout",

"框架": [0, 0, Graphics.width, Graphics.height],

"控件": [

{

"类型": "ui.Image",

"图像": "bg-generic",

"框架": [0, 0, "100%", "100%"]

},

{

"类型": "ui.StackLayout",

"方向": "vertical",

"框架": ["35%", "60%", "30%", "30%"]

"控件": [

{

"类型": "ui.Button",

"参数": { "文本": "新游戏", "动作": { "名称": "newGame" } },

"样式": "titleScreenButton"

},

{

"类型": "ui.Button",

"参数": { "文本": "加载游戏", "动作": { "名称": "switchLayout", "参数": { "名称": "loadMenuLayout", "savePrevious": true } } },

"样式": "titleScreenButton"

},

{

"类型": "ui.Button",

"参数": { "文本": "退出", "动作": { "名称": "quitGame" } },

"样式": "titleScreenButton"

}

]

}

]

}

 

您甚至可以在一个项目（item）上应用多种样式，如下所示：

 

"styles": ["titleScreenButton", "otherStyle"]

 

在这种情况下，样式（style）将一个接一个地应用。如果存在冲突属性，如两个样式（style）包含相同的属性，则最后应用的样式（style）获胜。

 

事件

如果发生特定事件，也可以在运行时更改控件的样式。例如：如果我们用鼠标指针悬停控件区域，则可以应用另一个样式，为用户提供视觉反馈，如更改控件的颜色。

 

要将样式绑定到事件，您首先需要定义在没有特殊事件发生时使用的基本样式：

 

ui.UIManager.styles.hyperlink = {

"font": { "color": [255, 255, 255], "size": 30 }

}

 

在此示例中，我们想创建一个可用于创建超链接的样式。所以如果我们悬停它，文本颜色会改变。

 

ui.UIManager.styles["hyperlink:hover"] = {

"font": { "color": [255, 0, 0], "size": 30 }

}

 

要将样式绑定到事件，我们使用语法：

 

:<event>

 

以下事件可用：

 

  • hover - 如果控件区域被鼠标指针悬停，则应用样式。
  • selected - 如果控件被选中，则应用样式。

 

在我们的示例中，我们使用了“hover”事件，因此我们的样式将应用在鼠标悬停时到每个具有基本“hyperlink”样式设置的控件上。所以如果我们现在创建这样的文本：

 

{

"类型": "ui.Text",

"样式": "hyperlink",

"文本": "Hover Me",

"框架": [0, 0],

"sizeToFit": true

}

 

它会在悬停时改变颜色！
