gs.GraphicEffectType 类

属性

  • ADDON 静态

  • INTERNAL 静态

属性

ADDON

Number 静态

附加特效使用 gl_FragColor 作为输入。意味着它只是将其效果添加到 gl_FragColor 中已存在的颜色值中。 这就是诸如着色或遮罩之类的特效的情况。

BASE

Number 静态

基础特效覆盖/替换 gl_FragColor 的内容，并且不使用 gl_FragColor 作为输入。这就是诸如像素化或模糊之类的特效的情况。

INTERNAL

Number 静态

内部特效。这仅用于引擎的某些内置特效。
