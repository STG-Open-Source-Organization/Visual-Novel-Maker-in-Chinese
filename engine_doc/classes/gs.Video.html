gs.Video 类

允许在屏幕上显示视频。 支持的视频格式取决于平台。 目前仅支持 WEBM 格式。

构造函数

gs.Video

(
  • filePath
  • [languageCode=null]
)

参数：

  • filePath String
    • 视频资源的路径。
  • [languageCode=null] String 可选
    • 根据语言加载视频资源的语言代码。

方法

dispose

()

释放视频并释放资源/内存。 如果不再需要视频，则应调用此方法。

pause

()

暂停视频。

play

()

释放视频并释放资源/内存。 如果不再需要视频，则应调用此方法。

stop

()

停止视频。

update

()

更新视频。 需要每帧调用一次。

属性

disposed

Boolean

指示视频是否已释放。

filePath

String

视频资源的路径。

height

Number

视频的高度。

isPlaying

Boolean

指示视频当前是否正在播放。

loaded

Boolean

指示视频是否已加载。

loop

Boolean

指示视频在播放完毕后是否重复播放。

onCanPlay

Function

视频准备好播放时调用的回调函数。

onEnded

Function

视频播放完毕时调用的回调函数。

onError

Function

发生错误时调用的回调函数。

playbackRate

Number

播放速度（百分比）。

volume

Number

视频音频的音量。 范围从 0 到 100%。

width

Number

视频的宽度。
