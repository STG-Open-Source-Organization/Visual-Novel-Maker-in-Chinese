gs.Graphics 类

此类管理图形系统。 在执行任何图形操作之前，需要对其进行初始化。 它初始化必要的图形上下文并分配必要的资源。

它管理所有图形对象，并按照每个对象的 z-index 对它们进行排序，然后在屏幕上自动渲染。

initialize

(
  • width
  • height
  • parent
  • keepRatio
)
static

初始化图形系统。 必须在创建任何图形对象或执行任何其他图形操作之前调用。

参数：

  • width Number
    • 游戏分辨率的宽度。
  • height Number
    • 游戏分辨率的高度。
  • parent HTMLElement
    • 应将画布添加到的 HTML 元素。
  • keepRatio Boolean
    • 指示画布在缩放时是否应保持分辨率的比例。

transition

(
  • duration
  • [transitionBitmap=null]
  • [vague=null]
)
static

执行从冻结状态到当前状态的过渡。 如果不存在冻结状态，则不执行过渡。 要冻结当前状态，请使用 gs.Graphics.freeze 方法。

参数：

  • duration Number
    • 过渡持续时间（以帧为单位）。
  • [transitionBitmap=null] gs.Bitmap optional
    • 用于过渡的掩码位图。 如果null则执行使用混合的简单过渡。
  • [vague=null] Number optional
    • 如果指定了掩码位图，则为掩码的模糊度。

update

() static

更新屏幕。 渲染所有图形对象。 应每帧调用一次。

画布/屏幕对象。 在大多数平台上，这是一个 HTMLCanvasElement，但不能保证。 不建议直接访问画布，只有在真正需要时才应该这样做。
