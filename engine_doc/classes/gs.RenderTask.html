gs.RenderTask 类

一个渲染任务保存了关于一个需要在屏幕上渲染的图形对象的信息。 这个类实际上仅供内部使用。唯一的例外是当你使用自定义 GLSL 着色器时。

如果你想了解更多关于 Basic Engine 的某些类被隐藏且不可编辑的原因，请阅读帮助文件中的 Basic Engine 章节。

属性

  • blend-mode（混合模式）
  • clip（裁剪）
  • effects（特效）
  • opacity（不透明度）
  • texture（纹理）
  • tilemap（瓦片地图）
  • tiling（平铺）

属性

blend-mode（混合模式）

Number（数值）

要使用的混合模式。

默认值：0

clip（裁剪）

gs.Rect

要使用的裁剪矩形。

默认值：new Rect(0, 0, Graphics.width, Graphics.height)

effects（特效）

gs.EffectCollection

要使用的图形特效。

默认值：new gs.EffectCollection()

opacity（不透明度）

Number（数值）

要使用的不透明度。

默认值：0

texture（纹理）

gs.Texture2D

要渲染的默认纹理。

默认值：null

tilemap（瓦片地图）

gs.TilemapRenderInfo

如果渲染任务渲染一个瓦片地图，则此属性包含更多关于它的信息。

默认值：null

tiling（平铺）

Boolean（布尔值）

指示是否应该平铺纹理。

默认值：false
