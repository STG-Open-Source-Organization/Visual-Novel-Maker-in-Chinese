gs.EffectInfo 类

effect-info 封装了注册和编译自定义 GLSL 着色器效果所需的所有信息。 要真正使用自定义效果，还需要创建一个自定义效果类并从 gs.GraphicEffect 类派生。

构造函数

gs.EffectInfo

(
  • [data=null]
)

参数:

  • [data=null] 对象 可选
    • 用于从中创建 effect-info 的可选数据包。 可以是null。

属性

defines

String

GLSL 预处理器定义的数组。 每个条目代表一个单独的预处理器定义。 预处理器定义必须采用正确的语法。 例如：

#define PI 3.14159

functionCalls

String

GLSL 函数调用的数组。 每个条目代表一个单独的函数调用。 函数调用必须采用正确的语法，包括尾随分号。 例如：

my_powerful_effect();

函数调用被粘贴到片段着色器的主函数中。

functions

String

GLSL 函数定义的数组。 每个条目代表一个单独的函数定义。 函数定义必须采用正确的语法。 例如：

void texture_color() { gl_FragColor = texture2D(Texture0, textureCoord); }

函数定义粘贴在所有 define、uniform 和 varying 声明之后。

id

Number

内部 ID 号。

name

String

效果名称。 该名称必须与效果类中定义的名称匹配。

type

gs.GraphicEffectType

效果类型。

uniforms

String

GLSL uniform 声明的数组。 每个条目代表一个单独的 uniform 声明。 uniform 声明必须采用正确的语法，包括尾随分号。 例如：

uniform float MyValue;

varying

String

GLSL varying 声明的数组。 每个条目代表一个单独的 varying 声明。 varying 声明必须采用正确的语法，包括尾随分号。 例如：

varying vec2 textureCoord;
