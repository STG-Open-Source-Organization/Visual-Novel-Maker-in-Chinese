gs.Sprite 类

继承自gs.GraphicObject（图形对象）

精灵在屏幕上显示位图或视频。它还支持各种 视觉效果，如缩放、旋转、着色等。

gs.Sprite

(
  • [viewport=gs.Graphics.viewport]
)

绘制精灵。不应手动调用。

initialize（初始化）

() protected（受保护的）

初始化该图形对象。

update（更新）

()

继承自gs.GraphicObject（图形对象）

更新精灵的运动模糊和其他效果。需要在每一帧调用一次。

属性

anchor（锚点）

gs.Point（点）

继承自gs.GraphicObject（图形对象）:

锚点。 例如：锚点为 0,0 会使对象绕其左上角旋转， 而锚点为 0.5, 0.5 会使对象绕其中心旋转。 锚点为 1,1 会使对象绕其右下角旋转。 它对对象的位置没有影响。 关于位置，请查看positionAnchor（位置锚点）属性。

angle（角度）

Number（数字）

旋转角度，以度为单位。

bitmap（位图）

gs.Bitmap（位图）

要渲染的位图。

blendingMode（混合模式）

gs.BlendMode（混合模式）

用于 Alpha 混合的混合模式。

clipRect（裁剪矩形）

gs.Rect（矩形）

裁剪矩形。 裁剪矩形之外的所有内容都将被裁剪并且不可见。

color（颜色）

Boolean（布尔值）

颜色。 可用于闪烁效果等。

disposed（已释放）

Boolean（布尔值）

继承自gs.GraphicObject（图形对象）:

指示对象是否已释放。 已释放的对象将不会被渲染。

effects（特效）

gs.EffectCollection（特效集合）

继承自gs.GraphicObject（图形对象）:

用于各种视觉效果（如摆动等）的特效设置。

id（ID）

Number（数字）

继承自gs.GraphicObject（图形对象）:

图形对象的唯一标识符。

index（索引）

Number（数字）

继承自gs.GraphicObject（图形对象）:

全局渲染列表中的当前索引。 此属性是只读的，并且会自动 在运行时根据 Z 属性计算。

mask（遮罩）

gs.Mask（遮罩）

用于遮罩效果的遮罩。

mirror（镜像）

Boolean（布尔值）

指示精灵是否已水平镜像/翻转。

motionBlur（运动模糊）

gs.MotionBlur（运动模糊）

运动模糊设置。

onIndexChange（索引变更时）

Function（函数）

继承自gs.GraphicObject（图形对象）:

当图形对象在全局渲染列表中的当前索引发生更改时触发。

默认值：null（空）

opacity（不透明度）

Number（数字）

不透明度从 0 到 255。例如：值为 0 表示完全透明，255 表示完全不透明，128 表示半透明。

ox（原点 X）

Number（数字）

继承自gs.GraphicObject（图形对象）:

原点的 X 坐标。

oy（原点 Y）

Number（数字）

继承自gs.GraphicObject（图形对象）:

原点的 Y 坐标。

positionAnchor（位置锚点）

gs.Point（点）

继承自gs.GraphicObject（图形对象）:

位置锚点。 例如：锚点为 0,0 会将对象的左上角 放置在其位置，而锚点为 0.5, 0.5 会将对象的中心放置在其位置。 锚点为 1,1 会将对象的右下角放置在其位置。 它对对象的旋转/缩放锚点没有影响。 对于旋转/缩放锚点，请查看anchor（锚点）属性。

srcRect（源矩形）

gs.Rect（矩形）

源矩形。 只有位图的该区域才会渲染到屏幕上。

tone（色调）

gs.Tone（色调）

颜色色调。

transform（变换）

Mat2d

继承自gs.GraphicObject（图形对象）:

图形对象的变换矩阵。

video（视频）

gs.Video（视频）

要渲染的视频。

video（视频）

gs.Video（视频）

要渲染的视频。

visible（可见）

Boolean（布尔值）

继承自gs.GraphicObject（图形对象）:

指示对象是否被渲染。

x（X 坐标）

Number（数字）

精灵位置的 X 坐标。

y（Y 坐标）

Number（数字）

精灵位置的 Y 坐标。

z（Z 索引）

Number（数字）

继承自gs.GraphicObject（图形对象）:

Z 索引控制渲染顺序/图像重叠。 具有较小 Z 索引的对象在具有较大索引的对象之前渲染。 例如：为了确保图形对象始终位于屏幕顶部，它 应该具有所有图形对象中最大的 Z 索引。

zoomX（X 轴缩放）

Number（数字）

X 轴上的缩放。

zoomY（Y 轴缩放）

Number（数字）

Y 轴上的缩放。
