gs.TilemapRenderInfo 类

tilemap-render 信息保存着更多关于在屏幕上渲染的 tilemap 的信息。这个类 实际上只供内部使用。唯一的例外是 当你使用自定义 GLSL 着色器时。

如果你想了解更多关于 Basic Engine 的某些类为什么是隐藏的且不可编辑，请阅读帮助文件中的 Basic Engine 章节。

属性

autotileAreaStart

Number

"红线"的 x 坐标，用于分隔常规图块和特殊图块区域。有关更多信息，请查看帮助文件中的 Scripter's Guide。

默认值：0

autotileOffset

Number

要显示的自动/动画/特殊动画帧编号。它与特殊图块的宽度相乘，以 确定要显示的动画帧/图块。 假设一个动画图块是 32x32，有 4 个动画帧， 那么计算公式是：

source-rectangle.x = regular-tiles-area.x + autotileOffset * 32

默认值：0

dataBitmap

gs.Bitmap

一个位图对象，它的大小与地图相同。 每个像素描述一个单独的图块。 像素的红色分量 存储图块在图块集上的列，绿色分量存储行。

默认值：null

ox

Number

x 轴上的偏移值。 更改此值以滚动 tilemap。

默认值：0

oy

Number

y 轴上的偏移值。 更改此值以滚动 tilemap。

默认值：0

tilesetBitmap

gs.Bitmap

tilemap 的图块集。

默认值：null

tileSize

Number

以像素为单位的图块大小。

默认值：32
