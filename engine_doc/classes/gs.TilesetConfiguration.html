gs.TilesetConfiguration 类

图块集配置用于 gs.Tilemap 来描述图块集的结构。 更多信息，请查看帮助文件中的 "Scripter's Guide" 中的 "Tilemaps" 章节。

构造函数

gs.TilesetConfiguration

(
  • tileSize
)

参数：

  • tileSize Number
    • 图块集上单个图块的大小。 单个图块需要是正方形的，因此值为 32 表示 32x32 像素。 如果省略，则使用值 32。

属性

@specialTileSize

gs.Rect

定义特殊/动画图块的大小。 对于普通动画图块，此大小只是常规图块大小。 但是对于自动或地形图块，这是扩展的自动/地形图块集的大小，而不是单个图块的大小。

此设置对于正确地动画自动/地形图块非常重要。 宽度用作动画偏移。

默认值：{ width: tileSize*8, height: tileSize*6 }

animationFrames

Number

动画图块的动画帧数。

默认值：4

expandedSize

gs.Size

内部图块集的大小。 原始图块集将被复制到内部图块集中，位置由 regularTiles 区域定义。 这只有在 useOriginalTileset 设置为false时才会发生。

默认值：{ width: 2048, height: 2048 }

expandedSize

gs.Rect

原始图块集将被复制到内部图块集中，位置在此处定义。 这只有在 useOriginalTileset 设置为false时才会发生。

默认值：{ 0, 0, tileSize * 8, tileSize * 64 }

invisibleTileId

Number

用于不可见图块的图块 ID。 建议使用不可见图块 ID 来表示不可见图块，而不是选择图块集上的随机透明图块，因为它能提高性能。

默认值：32767

specialTiles

gs.Rect

定义图块集上用于特殊图块（例如自动/地形或动画图块）的区域。 重要的是，此区域的 y 坐标始终为 0，并且高度应与图块集高度匹配，或者应可被特殊图块高度整除。

只能配置 x 坐标和宽度。 x 坐标越向右移动，常规图块可用的空间就越多。 但作为交换，动画帧的空间就会减少。 因此，如果您根本不使用动画图块，则可以将 x 坐标完全移到右侧。

从技术上讲，自动/地形图块或动画图块之间没有区别。 每个图块集仅支持一种特殊图块。 例如：如果您决定使用扩展状态下占用 256x192 像素的自动/地形图块，则您不能额外拥有 32x32 的动画图块。 在这种情况下，您的动画图块也需要是自动/地形图块，每个动画帧的偏移量为 256x192。 这种限制对于在移动设备上进行优化是必要的。

默认值：{ tileSize * 8, 0, tileSize * 8 * 4, tileSize * 6 * 10 }

useOriginalTileset

Boolean

指示是否不应创建内部图块集，而应按原样使用原始图块集图像。 在这种情况下，expandedSize、regularTiles 和 specialTiles 属性无效。 此外，gs.Tilemap.autotiles 也将被忽略，并且不会发生自动图块扩展。 您必须自己准备原始图块集图像。

请注意，默认情况下此值设置为true。

默认值：true
