属性

anchor

gs.Point

继承自gs.GraphicObject:

锚点。例如：锚点为 0,0 会使对象围绕其左上角旋转， 但锚点为 0.5, 0.5 会使对象围绕其中心旋转。锚点为 1,1 会使对象围绕其右下角旋转。它对对象的位置没有影响。对于定位，请查看positionAnchor属性。

angle

Number

旋转角度，单位为度。

blendingMode

gs.BlendMode

用于 alpha 混合的混合模式。

breathIntensity

Number

呼吸动画的强度。该值越高，呼吸动画越强烈。 值为 0 会禁用呼吸动画。默认为 1.0。

默认值：1.0

color

Boolean

颜色。可用于闪烁效果等。

currentMotion

gs.Live2DMotion

当前的动作。

disposed

Boolean

继承自gs.GraphicObject:

指示对象是否已释放。已释放的对象不会被渲染。

effects

gs.EffectCollection

继承自gs.GraphicObject:

不同视觉效果（如摆动等）的效果设置。

expressionManager

MotionQueueManager

表情管理器。

eyeBlink

L2DEyeBlink

用于支持眨眼的眨眼对象。

id

Number

继承自gs.GraphicObject:

图形对象的唯一标识符。

idleIntensity

Number

默认空闲动画的强度。该值越高，空闲动画越强烈。 值为 0 会禁用默认空闲动画。默认为 1.0。

默认值：1.0

index

Number

继承自gs.GraphicObject:

全局渲染列表中的当前索引。此属性是只读的，并且根据 z 属性在运行时自动计算。

lipSyncSensitivity

Number

如果 Live2D 模型正在说话，则唇形同步的灵敏度。该值越高，嘴巴在高音量时张开得越大。 值为 0 会禁用唇形同步。默认为 1.0。

默认值：1.0

loopMotion

Boolean

指示是否应循环播放动作。

mask

gs.Mask

用于遮罩效果的遮罩。

model

gs.Live2DModel

要渲染的 Live2D 模型。

motionManager

gs.Live2DMotionManager

动作管理器。

onIndexChange

Function

继承自gs.GraphicObject:

如果图形对象在全局渲染列表中的当前索引已更改，则触发。

默认值：null

opacity

Number

不透明度。范围从 0 到 255。

ox

Number

继承自gs.GraphicObject:

原点的 x 坐标。

oy

Number

继承自gs.GraphicObject:

原点的 y 坐标。

positionAnchor

gs.Point

继承自gs.GraphicObject:

位置锚点。例如：锚点为 0,0 会将对象的左上角放置 在其位置，但锚点为 0.5, 0.5 会将对象的中心放置在其位置。锚点为 1,1 会将对象的右下角放置在其位置。它对对象的旋转/缩放锚点没有影响。对于这一点，请查看anchor属性。

talking

Boolean

指示 Live2D 模型当前是否正在说话。

talkingVolume

Number

如果 Live2D 模型正在说话，则说话音量。范围从 0.0 到 1.0。该值越大，Live2D 模型的嘴巴张开得越大。

tilesetConfig

gs.TilesetConfiguration static

当前的 tileset 配置。

tileSize

Number static

单个瓷砖的大小。

默认值：32

tone

gs.Tone

色调。

transform

Mat2d

继承自gs.GraphicObject:

图形对象的变换矩阵。

visible

Boolean

继承自gs.GraphicObject:

指示对象是否被渲染。

x

Number

对象位置的 x 坐标。

y

Number

对象位置的 y 坐标。

z

Number

继承自gs.GraphicObject:

z-index 控制渲染顺序/图像重叠。具有较小 z-index 的对象在 具有较大索引的对象之前渲染。例如：要确保图形对象始终位于屏幕顶部，它 应具有所有图形对象中最大的 z-index。

zoomX

Number

x 轴上的缩放因子。

zoomY

Number

y 轴上的缩放因子。
