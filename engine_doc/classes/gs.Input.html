gs.Input 类

此类管理输入系统。在接收任何输入数据之前，需要先对其进行初始化。它支持键盘、鼠标、触摸和游戏手柄输入数据。

输入系统有一组名为 LEFT、UP、RIGHT、DOWN、A、B、C、X、Y、Z、L、R、START 和 SELECT 的按钮，这些按钮是模拟的，并且可在大多数平台上使用。 它们映射到不同的输入设备，例如键盘上的键或游戏手柄上的按钮。

clear

() static

dir4

() Number static

检查是否按下了 4 个方向键/按钮之一。

返回值:

Number:

0 = NONE, 2 = DOWN, 4 = LEFT, 6 = UP, 8 = RIGHT

dir8

() Number static

检查是否按下了 8 个方向键/按钮之一。

返回值:

Number:

0 = NONE, 1 = DOWN-LEFT, 2 = DOWN, 3 = DOWN-RIGHT, 4 = LEFT, 5 = RIGHT-UP, 6 = UP, 7 = LEFT-UP, 8 = RIGHT

repeat

(
  • key
)
Boolean static

检查指定的键是否被按下。它检查用户是否按住某个键一段时间，然后在固定的时间间隔内返回true。

参数:

  • key Number
    • 要检查的键。

返回值:

Boolean:

如果键被按下则返回true。它随后检查用户是否按住某个键一段时间，然后在固定的时间间隔内返回true。
