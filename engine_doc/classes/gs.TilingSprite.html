gs.TilingSprite 类

继承自gs.GraphicObject

一个平铺精灵会将位图或视频在屏幕上进行平铺。它也支持各种视觉效果，如着色、混合等。

构造函数

gs.TilingSprite

(
  • [viewport=gs.Graphics.viewport]
  • [managed=yes]
)

参数：

  • [viewport=gs.Graphics.viewport] gs.Viewport 可选的
    • 视口。
  • [managed=yes] Boolean 可选的
    • 指示该精灵是否应由图形系统管理。

()

() protected (受保护的)

初始化该图形对象。

update (更新)

()

继承自gs.GraphicObject

更新精灵的运动模糊和其他效果。 每帧需要调用一次。

属性

anchor (锚点)

gs.Point

继承自gs.GraphicObject:

锚点。 例如：一个 0,0 的锚点会使对象绕其左上角旋转，而一个 0.5, 0.5 的锚点会使对象绕其中心旋转。 1,1 的锚点会使对象绕其右下角旋转。 它对对象的位置没有影响。 对于定位，请查看positionAnchor (位置锚点)属性。

angle (角度)

Number (数字)

以度为单位的旋转角度。 将分配给该视口的所有对象绕视口的锚点旋转。

bitmap (位图)

gs.Bitmap

要渲染的位图。

blendingMode (混合模式)

gs.BlendMode

用于 alpha 混合的混合模式。

clipRect (裁剪矩形)

gs.Rect

裁剪矩形。 裁剪矩形外部的所有内容都会被裁剪掉，并且不可见。

disposed (已销毁)

Boolean

继承自gs.GraphicObject:

指示该对象是否已销毁。 已销毁的对象不会被渲染。

effects (特效)

Object (对象)

继承自gs.GraphicObject

用于不同类型视觉效果（如摆动等）的特效设置。

horizontal (水平平铺)

Boolean

指示精灵是否水平平铺。

id (ID)

Number (数字)

继承自gs.GraphicObject:

图形对象的唯一标识符。

index (索引)

Number (数字)

继承自gs.GraphicObject:

全局渲染列表中的当前索引。 此属性是只读的，并且在运行时根据 z 属性自动计算。

mask (遮罩)

gs.Mask

用于遮罩效果的遮罩。

mirror (镜像)

Boolean

颜色。 可用于闪烁效果等。

motionBlur (运动模糊)

gs.MotionBlur

运动模糊设置。

onIndexChange (索引改变事件)

Function (函数)

继承自gs.GraphicObject:

如果图形对象在全局渲染列表中的当前索引已更改，则触发。

默认值：null

opacity (不透明度)

Number (数字)

不透明度从 0 到 255。例如：0 表示完全透明，255 表示完全不透明，128 表示半透明。

ox (原点 X)

Number (数字)

继承自gs.GraphicObject:

原点的 X 坐标。

oy (原点 Y)

Number (数字)

继承自gs.GraphicObject:

原点的 Y 坐标。

positionAnchor (位置锚点)

gs.Point

继承自gs.GraphicObject:

位置锚点。 例如：一个 0,0 的锚点会将对象的左上角放置在其位置处，而一个 0.5, 0.5 的锚点会将对象的中心放置在其位置处。 1,1 的锚点会将对象的右下角放置在其位置处。 它对对象的旋转/缩放锚点没有影响。 对于旋转/缩放锚点，请查看anchor (锚点)属性。

rect (矩形)

gs.Rect

平铺区域。 精灵将仅在该区域上平铺。 要在整个屏幕上平铺，只需将矩形设置为屏幕大小。

rect (矩形)

gs.Rect

平铺区域。 精灵将仅在该区域上平铺。 要在整个屏幕上平铺，只需将矩形设置为屏幕大小。

srcRect (源矩形)

gs.Rect

源矩形。 只有位图/视频的该区域会在屏幕上平铺。

tone (色调)

gs.Tone

色调。

transform (变换)

Mat2d

继承自gs.GraphicObject:

图形对象的变换矩阵。

vertical (垂直平铺)

Boolean

指示精灵是否垂直平铺。

video (视频)

gs.Video

要渲染的视频。

visible (可见)

Boolean

继承自gs.GraphicObject:

指示该对象是否被渲染。

x (X坐标)

Number (数字)

滚动的 X 坐标。

y (Y坐标)

Number (数字)

滚动的 Y 坐标。

z (Z坐标)

Number (数字)

继承自gs.GraphicObject:

z-index 控制渲染顺序/图像重叠。 具有较小 z-index 的对象在具有较大索引的对象之前渲染。 例如：要确保图形对象始终位于屏幕顶部，它 应该具有所有图形对象中最大的 z-index。

zoomX (X轴缩放)

Number (数字)

X 轴上的缩放。

zoomY (Y轴缩放)

Number (数字)

Y 轴上的缩放。
