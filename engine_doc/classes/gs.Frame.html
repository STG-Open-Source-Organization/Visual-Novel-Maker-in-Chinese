gs.Frame 类

继承自gs.GraphicObject

一个用于创建游戏内 UI 元素（如按钮或窗口）的帧。有关帧皮肤图形的更多信息，请参见帮助文件。帧会自动添加到图形系统中，并在每次刷新时渲染，直到它被释放。

方法

dispose

()

继承自gs.GraphicObject

释放帧并释放资源。之后，帧不再被渲染。相关的皮肤位图不会被释放。

draw

()

继承自gs.GraphicObject

绘制帧。不应手动调用。

initialize

() 受保护的

继承自gs.GraphicObject:

初始化图形对象。

update

()

继承自gs.GraphicObject

更新帧。

属性

anchor

gs.Point

继承自gs.GraphicObject:

锚点。例如：锚点为 0,0 时，对象绕其左上角旋转，但锚点为 0.5, 0.5 时，对象绕其中心旋转。锚点为 1,1 时，对象绕其右下角旋转。它对对象的位置没有影响。对于定位，请查看positionAnchor属性。

color

布尔值

颜色。可用于闪烁效果等。

cornerSize

数字

帧的角尺寸。默认值为 16。(16x16)

disposed

布尔值

继承自gs.GraphicObject:

指示对象是否已释放。已释放的对象不被渲染。

effects

gs.EffectCollection

继承自gs.GraphicObject:

不同类型的视觉效果（如摆动等）的效果设置。

height

数字

帧的高度。

id

数字

继承自gs.GraphicObject:

图形对象的唯一标识符。

index

数字

继承自gs.GraphicObject:

全局渲染列表中的当前索引。此属性是只读的，并在运行时根据 z 属性自动计算。

onIndexChange

函数

继承自gs.GraphicObject:

如果图形对象在全局渲染列表中的当前索引发生更改，则触发。

默认值：null

opacity

数字

帧的不透明度从 0 到 255。例如：值为 0 表示完全透明，255 表示完全不透明，128 表示半透明。

ox

数字

继承自gs.GraphicObject:

原点的 x 坐标。

oy

数字

继承自gs.GraphicObject:

原点的 y 坐标。

positionAnchor

gs.Point

继承自gs.GraphicObject:

位置锚点。例如：锚点为 0,0 时，对象以其左上角放置在其位置，但锚点为 0.5, 0.5 时，对象将以其中心放置。锚点为 1,1 时，将以其右下角放置对象。它对对象的旋转/缩放锚点没有影响。为此，请查看anchor属性。

skin

gs.Bitmap

皮肤位图。

srcRect

gs.Rect

源矩形。只有皮肤的该区域用于构建帧。

thickness

数字

帧的厚度。默认值为 16。

tone

gs.Tone

帧的色调。

transform

Mat2d

继承自gs.GraphicObject:

图形对象的变换矩阵。

visible

布尔值

继承自gs.GraphicObject:

指示对象是否被渲染。

width

数字

帧的宽度。

x

帧位置的 x 坐标。

y

帧位置的 y 坐标。

gs.GraphicObject

数字
