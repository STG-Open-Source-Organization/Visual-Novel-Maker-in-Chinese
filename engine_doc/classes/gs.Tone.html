gs.Tone 类

描述用于着色图形对象或屏幕的色调。

构造函数

gs.Tone

(
  • red|tone
  • [green=null]
  • [blue=null]
  • [grey=null]
)

参数：

  • red|tone Numbergs.Tone
    • 色调的红色值或者要从中复制值的色调对象。
  • [green=null] Number 可选
    • 色调的绿色值。
  • [blue=null] Number 可选
    • 色调的蓝色值。
  • [grey=null] Number 可选
    • 色调的灰色值。

方法

fromArray

(
  • a
)
gs.Tone static

从指定的色调值数组创建一个新的色调。该数组应该有4个元素， 分别按顺序包含红色、绿色、蓝色和灰色的色调值。

参数：

  • a Number
    • 色调值数组。

返回值：

gs.Tone：

一个使用指定色调值创建的新色调。

fromObject

(
  • o
)
gs.Tone static

从原始对象创建一个色调。该对象应该包含 4 个属性， 分别命名为 red、green、blue 和 grey。

参数：

  • o Object
    • 包含色调的红色、绿色、蓝色和灰色属性的对象。

返回值：

gs.Tone：

新创建的色调。
