gs.GameStorage 类

继承自 gs.EventEmitter

GameStorage 帮助永久地存储不同类型的游戏数据，例如 保存游戏或游戏设置。数据的存储方式取决于平台。 例如：如果游戏在 Web 浏览器中运行，数据将存储在 Web 浏览器的内部本地存储中，但如果游戏在本地运行，则 数据存储在磁盘上。

所有对象都存储为 JSON，因此重要的是要存储的对象可以 序列化为 JSON，并且不包含任何循环引用。除了 gs.GameStorage.setData 和 gs.GameStorage.getData 方法，因为这些方法 处理常规字符串。

方法

clear (清除)

() 静态

清除游戏存储。所有数据都将丢失。

exists (存在)

() Boolean 静态

检查是否已存在指定 id/key 的数据。

返回值：

Boolean:

如果true则已存在该 id/key 的数据。否则false

(
  • id
)
String 静态

参数：

  • id String
    • 要获取的字符串/数据的 id/key。

返回值：

String:

字符串/数据，或者null如果该 id/key 不存在数据。

getObject (获取对象)

(
  • id
)
Object 静态

获取指定 id/key 存储的对象。

参数：

  • id String
    • 要获取的对象的 id/key。

返回值：

Object:

对象，或者null如果该 id/key 不存在对象。

initialize (初始化)

() 静态

初始化游戏存储。需要在游戏启动时调用一次。它会根据平台初始化 存储。如果是云存储，它将连接到云服务器 以获取存储数据。

此方法是异步的，并在完成时触发“finishInitialize”事件。

remove (移除)

() String 静态

删除存储在指定 id/key 下的数据。

返回值：

String:

id - 应删除数据的 id/key。

(
  • id
  • data
)
静态

在指定的 id/key 下存储一个字符串。

参数：

  • id String
    • 应存储数据的 id/key。
  • data String
    • 要存储的字符串。

setObject (设置对象)

(
  • id
  • object
)
静态

在指定的 id/key 下存储一个对象。该对象将被序列化为 JSON，因此重要的是该对象不包含任何循环引用。

参数：

  • id String
    • 应存储对象的 id/key。
  • object Object
    • 要存储的对象。

storagePath (存储路径)

() 静态

数据存储的路径。结果取决于平台。 例如：对于 Web 游戏，结果是一个空字符串，但对于本地 运行的游戏，结果是游戏的配置存储目录的文件路径。
