gs.Color 类

用于描述 RGBA 颜色的类。它也提供一些辅助方法。

构造函数

gs.Color

(
  • red/color
  • [green=null]
  • [blue=null]
  • [alpha=null]
)

参数：

  • red/color Number
    • 颜色的红色值或者另一个用于创建副本的颜色。
  • [green=null] Number 可选
    • 颜色的绿色值。
  • [blue=null] Number 可选
    • 颜色的蓝色值。
  • [alpha=null] Number 可选
    • 颜色的 Alpha 值。

fromArray

(
  • a
)
gs.Color static (静态)

从指定的颜色值数组创建一个新颜色。该数组应包含 4 个元素，顺序为红色、绿色、蓝色和 Alpha 颜色值。

参数：

  • a Number
    • 颜色值数组。

返回值：

gs.Color:

使用指定颜色值创建的新颜色。

gs.Color static (静态)

参数：

  • o Object

gs.Color:

Object static (静态)

将指定的 RGB 值转换为 HSL 空间。

参数：

  • r Number
    • 要转换的颜色的红色值。
  • g Number

rgbToHsl

(
  • h
  • s
  • l
)
Object static (静态)

将指定的 HSL 值转换为 RGB 空间。

参数：

  • h Number
    • 要转换的颜色的色相值。
  • s Number
    • 要转换的颜色的饱和度值。
  • l Number
    • 要转换的颜色的亮度值。

返回值：

Object:

作为对象的 RGB 值 -> { r, g, b }。
