gs.TilemapLayer 类

Tilemap 图层用于显示 gs.Tilemap 的单个图层。 不建议直接使用此类。 有关如何使用 tilemap、功能和限制的更多信息，请阅读帮助文件中的“Scripter's Guide”。

构造函数

gs.TilemapLayer

(
  • viewport
  • tilemap
  • width
  • height
  • mapData
  • tileSize
  • tilesetBitmap
  • animationSpeed
)

参数：

  • viewport gs.Viewport
    • 要与 tilemap 图层关联的视口。
  • tilemap gs.Tilemap
    • 要与 tilemap 图层关联的 tilemap。
  • width Number
    • 图层的宽度，以瓦片为单位。
  • height Number
    • 图层的高度，以瓦片为单位。
  • mapData Number
    • 图层的地图数据。
  • tileSize Number
    • 此图层的瓦片大小。
  • tilesetBitmap Number
    • 要使用的瓦片集。
  • animationSpeed Number
    • 动画瓦片的动画速度。（显示下一个图案之前的帧数持续时间）

方法

dispose

()

释放 tilemap 图层并释放资源。 如果不再需要 tilemap 图层，则应调用它。

update

()

更新 tilemap 图层。 每帧必须调用一次。

属性

angle

Number

旋转角度。

animationSpeed

Number

动画瓦片的动画速度。（显示下一个图案之前的帧数持续时间）

color

Boolean

颜色。 可用于闪烁效果等。

mask

gs.Mask

用于遮罩效果的遮罩。

tilemap

gs.Tilemap

与图层关联的 tilemap。

tilesetBitmap

gs.Bitmap

用于此图层的瓦片集。

tileSize

Number

单个瓦片的大小。 单个瓦片需要是正方形，因此值 32 表示 32x32 像素。

tone

gs.Tone

色调。

zoomX

Number

x 轴上的缩放。

zoomY

Number

y 轴上的缩放。
