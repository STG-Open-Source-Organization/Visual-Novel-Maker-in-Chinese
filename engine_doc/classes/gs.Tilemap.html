gs.Tilemap 类

Tilemap 可用于显示游戏关卡/地图的环境。有关如何使用 tilemap、功能和限制的更多信息，请阅读帮助文件中的“Scripter's Guide”。

方法

convertTileId

(
  • tile
  • index
  • framesX
  • x
  • y
  • z
)
Number

如有必要，您可以覆盖或修补此方法，将 tile-id 转换为另一个 ID 空间。 默认情况下不进行转换，它返回 tile-id 而不进行任何更改。

参数：

  • tile Number
    • 要转换的 tile id。
  • index Index
    • 地图数据数组中 tile id 的索引。
  • framesX Number
    • 图集中 x 轴上的图块数。
  • x Number
    • tilemap 上图块的 x 坐标。
  • y Number
    • tilemap 上图块的 y 坐标。
  • z Number
    • 图块所在的图块层。

返回值：

Number:

转换后的 tile id。

dispose

()

释放 tilemap 并释放内存。 如果不再需要 tilemap 来释放资源，则应调用此方法。

setup

()

初始化 tilemap。 必须在设置 tilemap 设置、地图数据和图集数据后调用。

update

()

更新 tilemap 的滚动等。 每帧需要调用一次。

属性

animationSpeed

Number

动画图块的动画速度。 它定义了显示下一个动画帧之前的帧持续时间。

默认值：16

autotiles

gs.Bitmap[]

标准格式的自动图块数组，它们会自动展开并绘制在展开的图集位图上。

color

Boolean

颜色。 可用于闪烁效果等。

depth

Number

tilemap 层的计数。

默认值：3

expandedAutotiles

gs.Bitmap[]

展开的自动图块数组。 它们是从 autotiles 属性自动生成的。

height

Number

tilemap 的高度（以图块为单位）

默认值：50

layers

gs.TilemapLayer[]

用于渲染 tilemap 图层的图层对象数组。

mapData

Number

存储地图数据的数组。 数组中的每个数字都指向图集上的一个图块。

mask

gs.Mask

用于遮罩效果的遮罩。

priorities

Number

一个数组，存储每个 tile-id 的数字，用于控制哪些 tile 重叠。

tileset

gs.Bitmap

用于构建 tilemap 的图集位图。

tilesetConfig

gs.TilesetConfiguration

用于配置图集大小、常规图块、自动图块和动画图块的图集配置。 如果要更改配置，则必须在调用 tilemap 的 setup 方法之前进行。

tileSize

Number

单个图块的大小。 图块需要是正方形的，因此 32 的值意味着 32x32 像素。

默认值：32

tone

gs.Tone

色调。

width

Number

tilemap 的宽度（以图块为单位）

默认值：50
