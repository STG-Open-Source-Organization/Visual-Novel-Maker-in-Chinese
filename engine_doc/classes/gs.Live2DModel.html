gs.Live2DModel 类

该类用于从 .live2d 存档加载 Live2D 模型。 更多信息请查看帮助文件中的资源标准。

构造函数

gs.Live2DModel

(
  • filePath
  • [languageCode=null]
)

参数:

  • filePath String
    • Live2D 资源的路径。
  • [languageCode=null] String 可选
    • 用于根据语言加载 Live2D 资源的语言代码。
