gs.Renderer 类

渲染器用于在屏幕上渲染图形对象，如图像、彩色矩形等。它的行为 类似于状态机。因此，第一步是设置原点、旋转角度、颜色等，然后渲染 具有该设置的图形对象。

方法

changeTone

(
  • rect
)

更改指定区域的色调。 需要每帧调用一次才能保持更新。

参数：

  • rect gs.Rect
    • 要着色的区域。

clipRect

(
  • rect
)

设置当前的裁剪矩形。 所有在裁剪区域之外的渲染调用都将被裁剪。

参数：

  • rect gs.Rect
    • 裁剪区域。

clipTo

(
  • x
  • y
  • width
  • height
)

设置当前的裁剪矩形。 所有在裁剪区域之外的渲染调用都将被裁剪。 它 等同于 clipRect，但使用直接坐标而不是 gs.Rect。

参数：

  • x Number
    • 裁剪区域的 x 坐标。
  • y Number
    • 裁剪区域的 y 坐标。
  • width Number
    • 裁剪区域的宽度。
  • height Number
    • 裁剪区域的高度。

dispose

()

释放渲染器并释放所有已分配的资源/内存。

drawBitmap

(
  • bitmap
  • x
  • y
  • srcRect
  • [ox=0]
  • [oy=0]
)

在屏幕上绘制指定的位图。

参数：

  • bitmap gs.Bitmap
    • 要绘制的位图。
  • x Number
    • 位图位置的 x 坐标。
  • y Number
    • 位图位置的 y 坐标。
  • srcRect gs.Rect
    • 要绘制的位图区域。
  • [ox=0] Number 可选
    • 原点的 x 坐标。
  • [oy=0] Number 可选
    • 原点的 y 坐标。

drawBitmapSimple

(
  • bitmap
  • x
  • y
  • w
  • h
  • sx
  • sy
  • sw
  • sh
)

“简单”地绘制位图，没有任何视觉效果，例如旋转、着色、alpha 混合等。它比 常规 gs.Renderer.drawBitmap 更快。

参数：

  • bitmap gs.Bitmap
    • 要绘制的位图。
  • x Number
    • 位图位置的 x 坐标。
  • y Number
    • 位图位置的 y 坐标。
  • w Number
    • 位图的宽度。
  • h Number
    • 位图的高度。
  • sx Number
    • 要绘制的位图区域的 x 坐标。
  • sy Number
    • 要绘制的位图区域的 y 坐标。
  • sw Number
    • 要绘制的位图区域的宽度。
  • sh Number
    • 要绘制的位图区域的高度。

drawLive2D

(
  • object
)

绘制 Live2D 对象。

参数：

  • object gs.Live2DObject

drawQuad

(
  • position
  • size
)

绘制一个四边形。 四边形可以是纹理化的、旋转的、着色的等，具体取决于 渲染器设置。

参数：

  • position Number
    • 位置，表示为数字数组。
  • size Number
    • 大小，表示为数字数组。

参数：

  • sh Number
