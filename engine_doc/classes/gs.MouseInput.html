gs.MouseInput 类

该类提供对鼠标或触摸输入的访问。 在智能手机等触摸设备上，鼠标按钮或鼠标位置会自动映射到触摸输入。 例如：单次点击算作鼠标左键单击，而双击算作鼠标右键单击。

方法

clear

() static

清除鼠标按钮的状态。

initialize

() static

初始化鼠标/触摸系统。 必须先调用此函数，然后才能接收任何鼠标/触摸输入。

press

(
  • button
)
Boolean static

检查是否按下了指定的鼠标按钮。

参数：

  • button Number
    • 要检查的按钮。

返回：

Boolean：

如果true表示按钮被按下。 否则false

update

() static

更新鼠标/触摸输入系统。 需要每帧调用一次。

属性

buttonDown

Boolean static

指示当前是否有鼠标按钮被按下。

buttons

Uint8Array static

存储鼠标按钮的状态。

buttonUp

Boolean static

指示鼠标按钮之前一直被按下，现在抬起。

initialized

Boolean static

指示鼠标输入系统是否已初始化。

mouseMoveOnTouchDevices

Boolean static

指示是否应为触摸设备支持鼠标移动。

默认值：false

moved

Boolean static

指示鼠标/触摸指针是否已移动。

touchButtonsEnabled

Boolean static

指示是否启用了不可见的虚拟触摸按钮。 有关虚拟按钮的更多信息，请参见帮助文件。

默认值：false

wheel

Number static

鼠标滚轮的当前状态。 它是滚轮增量。

wheelChanged

Boolean static

指示鼠标滚轮状态是否已更改。

x

Number static

鼠标/触摸指针位置的 x 坐标。

y

Number static

鼠标/触摸指针位置的 y 坐标。
