GSLive2DView 类

Live2D 显示一个关联的 Live2D 模型的预览，并允许对其进行移动和缩放。这对于让用户为 Live2D 模型选择位置或显示 Live2D 动作的预览很有用。

Properties

BindingSignal.zoom

Number

发送 Live2D 模型当前的缩放级别（以百分比表示）。

BindingSlot.expression

String

设置要设置的 Live2D 表达式的名称。

BindingSlot.motion

String

设置要播放的 Live2D 动作的名称。

BindingSlot.motionGroup

String

设置要播放的 Live2D 动作组的名称。

BindingSlot.motionGroupPlayType

String

设置 Live2D 动作组的播放类型。

  • 0 = ORDERED
  • 1 = RANDOM

BindingSlot.zoom

Number

设置 Live2D 模型当前的缩放级别（以百分比表示）。

folder

String

用于从其加载 Live2D 模型的文件夹。
