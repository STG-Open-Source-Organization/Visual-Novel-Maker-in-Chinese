GSSplitView 类

一个分割视图。

  • 索引
  • 属性

项目索引

属性

  • minDividerMargin
  • orientation
  • paneSplitter
  • views

属性

minDividerMargin

Number

默认：[0, 0]

orientation

String

分割视图的方向。可以是 "vertical" 或 "horizontal"。

默认："horizontal"

paneSplitter

Boolean

指示分割视图是否具有一个粗的窗格分割器来调整视图大小，而不是一个细的。

默认：false

views

View[]

由分割视图显示的视图数组。视图由分隔符分隔，分隔符可用于调整视图大小。每个视图只是一个常规视图描述符。
