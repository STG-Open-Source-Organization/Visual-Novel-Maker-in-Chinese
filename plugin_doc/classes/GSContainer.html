GSContainer 类

容器定义了一个子视图，或者可以将自定义视图嵌入到当前视图中。

  • 索引
  • 属性

项目索引

属性

  • parameters
  • viewUid

属性

parameters

对象

传递给嵌入视图的参数。参数对象具有以下结构：

{ identifier1: { fd1: value, fd2: value, fd3: value, ... }, identifier2: { fd1: value, ... }, ... }

标识符描述了参数应传递到的部分或项目，而 fdX 对 描述了要为部分或项目设置的不同字段值。示例：

{ "myCheckBox": { "text": "Check Me", "attribute": "checked" } }

在该示例中，标识符为“myCheckBox”的项目中的“text”和“attribute”属性 被设置为值“Check Me”和“checked”。这有助于创建更具可重用性和更灵活的 可嵌入视图。

viewUid

字符串

要嵌入的视图的 UID。
