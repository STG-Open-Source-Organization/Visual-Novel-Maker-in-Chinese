GSDispositionView 类

布局视图允许用户选择一个或多个图形单元格的位置、大小和属性。 单元格可以关联图像，也可以只有颜色。根据设置，用户可以拖动和移动 单元格并调整它们的大小。双击会打开自定义单元格属性（如果已配置）。

属性

allowCellResize

布尔值

指示用户是否可以调整单元格的大小。

BindingSlot.backgrounds.[index]

图像

设置指定背景层的图像。

BindingSlot.cells.[index]

对象

将绑定值设置为

BindingSlot.zoom

数字

设置所有单元格的缩放级别。这是一个百分比值。

cellColor

对象

通用单元格颜色。如果单元格没有自己的颜色定义，则使用此颜色。

cellPropertiesDialog

DialogDescriptor

当单元格被双击时用于单元格属性的对话框。数据会自动写入 到单元格对象中。

cells

对象

预定义的单元格数组。

cells[cell].color

对象

单元格的颜色。必须是颜色对象，例如：{ red: 255, green: 255, blue: 255, alpha: 255 }

cells[cell].size

对象

单元格的大小。必须是大小对象，例如：{ width: 100, height: 100 }

cells[cell].x

数字

单元格位置的 x 坐标。

cells[cell].y

数字

单元格位置的 y 坐标。

dynamic

字符串

指示视图是动态的还是静态的。动态视图允许在运行时添加/删除单元格，例如通过 按钮或其他控件。

storeMode

字符串

控制数据如何存储。如果为single则仅存储第一个单元格。如果为multiple则存储所有单元格的数组。
