展开视图

对象

展开视图包含 GSQ 项，这些项仅在用户通过单击展开箭头图标展开

命令时可见。它应仅用于不那么重要或不经常更改的设置。

展开视图分为列，每列都有一组上下排列的部分。每个部分都可以有一个自己的标题文本来稍微描述其内容。每个部分包含一组行，每行包含一组并排放置的项目。

示例:

"expandedView": { "columns": [ { "sections": [ { "label": "Header Text", "rows": [ { "items": [] } ] } ] } ] }
