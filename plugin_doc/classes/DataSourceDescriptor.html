DataSourceDescriptor 类

描述了用于 GSComboBox、GSTable 等控件的数据源。

属性

allowEmptySelection

布尔值

指示数据源是否提供“(无)”值用于空/无选择。

filter

字符串

在运行时过滤源项的公式。它有两个参数，“d”是 当前项，“customData.object”包含视图的数据对象。过滤器应返回true以允许项通过。否则应返回false以跳过该项。

prefixSource

对象

前缀源放在source之前。它是一个预定义的 项目数组。每个项目可以只是一个字符串，例如：

["Apple", "Banana", "Orange"]

在这种情况下，将存储所选项的索引。但也可以定义 一个单独的别名值，该值将被存储，例如：

[{ name: "Apple", alias: "fruit_apple"}, { name: "Banana", alias: "fruit_banana" }]

其中name仅为显示名称，alias是存储的值。

source

字符串 | 对象

应从中获取数据的源。它可以是数据库类别名称或预定义的 项目数组。如果未配置其他设置，则存储所选项的索引。如果存在prefixSource，则会将前缀源中的项数添加到索引值。 对于预定义的数组，每个项可以只是一个字符串，例如：

["Apple", "Banana", "Orange"]

在这种情况下，将存储所选项的索引。但也可以定义 一个单独的别名值，该值将被存储，例如：

[{ name: "Apple", alias: "fruit_apple"}, { name: "Banana", alias: "fruit_banana" }]

其中name仅为显示名称，alias是存储的值。

sourceFormula

对象

在运行时计算source的公式。它接受一个参数“d”，即 视图的数据对象。
