DialogDescriptor 类

描述了某些 UI 控件（如 GSPopupField、GSTable 等）支持的对话框弹出窗口。

  • 属性

项索引

  • parameterFormula
  • parameters

属性

inheritParentObject

布尔值

指示弹出对话框的数据对象是否具有一个parentObject，其中包含来自调用视图的数据。当弹出对话框需要访问调用视图中的数据时很有用。仅 GSTable 支持

默认：false

parameterFormula

字符串

用于计算内部弹出对话框的对话框参数的公式。

parameters

字符串

参数用于将选项传递给内部弹出对话框，例如用于图形选择弹出对话框的文件夹。支持以下参数：

  • dialog.selectGraphicResource - { folder, multiSelection, emptySelection }
  • dialog.selectVideoResource - { folder, multiSelection, emptySelection }
  • dialog.selectAudioResource - { folder }
  • dialog.selectVariable - { dataSource }
  • dialog.selectParameters - 无参数

uid

字符串

用于弹出对话框的自定义视图的 UID。有 5 个保留 UID 用于 显示内部弹出对话框，例如图形或音频选择：

  • "dialog.selectGraphicResource" - 显示一个弹出对话框以选择图形资源。
  • "dialog.selectVideoResource" - 显示一个弹出对话框以选择视频资源。
  • "dialog.selectAudioResource" - 显示一个弹出对话框以选择音频资源。
  • "dialog.selectVariable" - 显示一个弹出对话框以选择变量。
  • "dialog.selectParameters" - 显示一个弹出对话框以选择参数，例如用于通用事件。

uidFormula

字符串

用于计算用于弹出对话框的自定义视图的 UID 的公式。仅 GSTable 支持
