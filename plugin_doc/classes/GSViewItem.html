委托

对象

委托用于将用户操作委托给指定的项目控制器例程。一个很好的例子

是 GSButton 项目，它会在点击时向 GSTable 或 GSCollectionView 添加新项目。该按钮

只是将点击委托给表视图的内部控制器的一个例程。每个项目都有一个内部
控制器来管理项目的逻辑。许多控制器提供公共例程，可以使用委托来调用这些例程来触发某个操作。

委托使用以下格式定义：

"delegates": [ { "identifiers": ["myTable"], "selector": "addItemUsingDialog" } ]

identifiers - 应在其上调用指定选择器的项目数组。

selector - 要调用的操作/例程。

委托触发的时间取决于项目。

框架

数字

项目的坐标和大小，格式为坐标数组，如 [0, 0, -1, 200]。位置坐标

不是以像素为单位。如何解释坐标取决于布局。但对于最常见

的标准布局，“dynamicGrid”，位置是 [列, 行] 对。因此，以如下方式显示项目：

item1 item2

item3 item4

这些项目的位置将是：[0, 0]，[1, 0]，[0, 1] 和 [1, 1]

对于大多数项目，大小是可选的。例外情况是多行文本字段、表视图、文档树等。通常

大小会根据布局自动计算。也可以为大小值指定 -1，让布局处理。例如，要只指定项目的高度，您可以指定 [0, 0, -1, 200] 来

将高度设置为 200 像素，而宽度仍由布局自动计算。

对于所有布局，大小以像素为单位。

组

字符串
  • 将项目分配给指定的组。组关联的处理方式取决于项目。
  • 例如：单选按钮使用组在点击时禁用该组中的所有其他单选按钮，而

标签使用组调整自身大小以适应具有最高宽度值的标签。
