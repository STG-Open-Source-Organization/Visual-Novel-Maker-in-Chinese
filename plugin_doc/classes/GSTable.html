GSTable 类

一个具有一个或多个列的表视图。用户可以通过右键菜单或双击最后一行（如果配置了）来添加/删除项目。

属性

addItem

Delegate

使用表列的默认值添加新项目。

addItem:withData:

Delegate

使用指定数据添加新项目。数据描述项目本身。

addItemAtSelectedIndex:withData:

Delegate

使用指定数据在当前选定项目后添加新项目。数据描述项目本身。

addItemUsingDialog

Delegate

使用关联的对话框弹出窗口添加新项目。

BindingSignal.[attributeName]

Object

当前选定项目的全部属性。

BindingSignal.items

Object

所有项目。

BindingSignal.selectedItem

Object

当前选定的项目。

BindingSlot.[attributeName]

Object

当前选定项目的任何属性都可以设置。

columns

Object

表的列数组。

columns[column].content

Object | String

列内容。它可以只是一个公式或一个键值映射。公式有一个参数 "d"，它是当前表项。

键值映射的格式为 { key: "aKey", values: { key1: value, key2: value, ... } }。"key" 是当前表项的属性名称。该属性的值用作values

的键来获取并显示值。例如：
列内容属性： { key: "favoriteFruit", values: { "apple": "Apple", "banana": "Banana" } }

项目数据： { favoriteFruit: "apple" }

该示例将返回 "Apple" 作为示例项目数据。

columns[column].hidden

Boolean

指示列是否隐藏。

columns[column].icon

String

用于列的图标名称。

columns[column].text

String

如果表头可见，则为列的表头文本。

columns[column].width

Number

列的宽度（以像素为单位）。

contextMenu

ContextMenu

表的上下文菜单。可用于提供复制、粘贴、删除等操作。

copyItem:

Delegate

复制选定的项目。

cutItem:

Delegate

剪切选定的项目。

dataSource

DataSourceDescriptor

表的源数据。这仅适用于只读的表，用户无法修改。源数据可以是记录集合或预定义的值数组。有关更多信息，请参阅 DataSourceDescriptor。

dataType

String描述表中数据类型的 MIME 类型。如果不存在，则类型为 novelsharp/。如果identifier

不存在，则类型为 novelsharp/custom-item。

deleteItem:

Delegate

删除选定的项目。

dialog

DialogDescriptor

用于添加/编辑项目的对话框。如果不存在，用户将无法添加/编辑任何项目。

editItemUsingDialog

Delegate

使用关联的对话框弹出窗口编辑选定的项目。

emptyItem

Boolean指示表是否使用额外的行，允许用户通过双击该行来添加新项目。该行的文本可以使用emptyItemText

属性进行控制。

emptyItemText

String如果设置了emptyItem

，则为额外行的文本。

headerView

Boolean

指示表头是否可见。

pasteItem:

Delegate

从剪贴板粘贴项目。

removeSelectedItem

Delegate

删除选定的项目。

sortFormula

String
