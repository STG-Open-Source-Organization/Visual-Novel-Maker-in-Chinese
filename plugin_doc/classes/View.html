View 类

一个（自定义）视图可以在许多不同的地方使用，例如用于弹出窗口或作为可嵌入 视图。相同的格式也用于分割或标签视图的视图。

属性

bindings

Binding

用于将本地视图数据绑定到项的视图绑定数组。

sections

ViewSection

定义视图内容的节数组。

windowSize

Object

如果视图显示为弹出窗口，则定义窗口大小。格式 为 { w, h }。

windowSizeFormula

Object

如果视图显示为弹出窗口，则使用公式计算窗口大小。该公式 没有参数。公式必须返回一个像 { w, h } 这样的对象大小。

windowTitle

String

如果视图显示为弹出窗口，则定义窗口标题。
