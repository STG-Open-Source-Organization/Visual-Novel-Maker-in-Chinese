GSQItem 类

描述了每个 GSQ 项可以拥有的所有通用属性。GSQ 项用于描述场景命令的单个字段，例如角色选择、持续时间值、弹出列表等。

属性

attribute

String

后端字段的路径，项应在此路径中存储其数据。例如：

myField

将数据存储在命令对象的 params.myField 中。也可以指定如下路径：

myField.mySubField

在上面的例子中，数据被写入命令对象的 params.myField.mySubField。如果myField不存在，它将被自动创建并初始化为空对象。也可以指定数组值的路径，如下：

myField.mySubArray.4

在上面的例子中，数据被写入params.myField.mySubArray[4]。如果数组或索引不存在，它将 被自动创建。在我们的例子中，索引 0 到 3 的值被初始化为null

identifier

String

项的唯一标识符。它可以是任何文本，只要它在命令中 是唯一的。所以您不需要遵循任何格式或语法。如果identifier不存在，attribute将被自动用作标识符。标识符可用于 引用该项，例如在enableItems或showItems属性中。

label

String

字段的标签文本，用于显示字段的简短描述。

lockable

Boolean

指示字段是否可锁定并在左侧显示锁定图标。如果true，则 params 对象包含 一个特殊属性fieldFlags，其中包含每个属性的标志。如果字段被锁定，则设置标志 0x01。例如：

locked = params.fieldFlags["myField"] & 0x01

上面的例子检查myField是否被锁定。在游戏脚本中，有一个常量可以代替 0x01 使用：

locked = params.fieldFlags["myField"] & gs.CommandFieldFlags.LOCKED

或者辅助方法：

locked = gs.CommandFieldFlags.isLocked(params.fieldFlags["myField"])

被锁定的字段将被命令忽略，并使用默认值。但确切的行为取决于命令在gs.Component_CommandInterpreter类中的实现。

tooltip

String

如果鼠标指针在字段上停留几秒钟，则显示弹出帮助文本。帮助文本弹出窗口的确切行为 取决于操作系统。

type

String

项的类型，例如是数字字段、文本字段等。支持以下类型：

  • GSQStepper
  • GSQTextArea
  • GSQPopupField
  • GSQDataRecordField
  • GSQCheckBox
  • GSQSlider

valueFormula

String

定义一个 JavaScript 公式来计算字段值的显示文本。局部变量 "p" 是 params 对象的引用。如果公式不返回字符串，则对返回值执行toString方法。例如：

"valueFormula": "return p.myValue"

valueTranslator

Object

值转换器可用于在写入或读取项的值之前对其进行转换。它具有 以下格式：

valueTranslator: { read: "return ROUND(v * 100)", write: "return v / 100" }
  • read - 公式用于在读取值之后、将其传输到项之前进行转换。它有一个参数 "v"，即原始值。
  • write - 公式用于在将值写入后端之前进行转换。它有一个参数 "v"，即原始值。

在上面的例子中，值存储为 0.0 到 1.0 之间的因子，但显示为 0 到 100 之间的百分比。

variableButton

Object

指示字段是否可以通过变量计算。仅适用于 GSQStepper、GSQTextArea、GSQPopupField 和 GSQDataRecordField。该对象具有以下格式：

"variableButton": { "dataSource": "numbers "}

该dataSource描述变量类型，可以是 "numbers"、"strings"、"booleans" 或 "lists"。

width

Number | String

字段的宽度（以像素或百分比为单位）。可以是：

  • "50%" - 百分比值
  • 50 - 以像素为单位表示宽度的数字值
  • "auto" - 宽度将自动计算

默认："auto"
