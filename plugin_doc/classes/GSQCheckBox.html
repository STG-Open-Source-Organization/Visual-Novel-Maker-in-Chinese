GSQCheckBox 类

复选框字段基于 GSQPopupField，但只包含“是”和“否”。因此，也可以通过直接使用 GSQPopupField 来创建复选框字段，但使用 GSQCheckBox 会更方便，如下例所示：

{ "label": "我的复选框", "type": "GSQCheckBox", "attribute": "myField" }

所以您不需要指定valueFormula和dataSource。
