previewResolution ()

Object返回游戏的分辨率，用于调整布局视图以匹配游戏屏幕尺寸。如果项目首选项中未设置 "Original Size Preview"（原始尺寸预览），则分辨率会按 50% 缩减。Otherwise it returns the original game screen size.

Returns:

Object:

游戏的分辨率，格式为 { width, height } 对象。

previewScale

() Number

返回布局视图和其他图形编辑器用于缩放图形的比例因子。如果项目首选项中设置了 "Original Size Preview"（原始尺寸预览），则比例因子为 1.0。

Otherwise it is 0.5 so all graphics are scaled down by 50% to make placement easier for large game resolutions.

Returns:Number

:

取决于设置的比例因子。
