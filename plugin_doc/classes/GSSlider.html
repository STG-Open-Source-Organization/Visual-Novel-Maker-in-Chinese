GSViewItem

GSSlider 类

滑块允许用户通过移动鼠标拖动的图形滑块旋钮来选择一个数值。适用于不需要精确值的数字选择。

属性

maximum

Number

用户可以输入的最高数值。

minimum

Number

用户可以输入的最低数值。如果不存在显式默认值，则使用最小值作为默认值。

orientation

String

滑块的方向。可以是vertical或horizontal。
