GSDocumentTree 类

文档树显示文档（如场景或章节）的层次结构，并 允许用户选择一个文档。它仅存储文档的 UID。如果您希望用户选择场景或其他类型的文档，则此功能很有用。

属性

autoLoad

布尔值

指示是否在选中时自动加载文档。在大多数情况下，这并非必要。

BindingSignal.[itemName]

对象

允许发送选定文档的项目集合中的任何项目。

BindingSlot.[itemName]

对象

允许设置选定文档的项目集合中的任何项目。

controller

字符串

用于视图的内部树控制器类的名称。它可以是以下值之一：

  • GSDocumentTreeController - 通用文档控制器
  • GSVNSceneTreeController - 场景文档控制器。提供场景的额外操作和处理。

documentTypes

String

文档类型数组，例如 vn.scene, vn.chapter 等。

headerText

String

树状视图的标题文本。如果不存在，则标题行将隐藏。

outline

Boolean

指示树状视图是否应具有轮廓/边框。

readOnly

Boolean

指示文档是否只能选择而不能编辑、删除或添加文档。

rootHidden

Boolean

指示根节点（即项目文档）是否将被隐藏。
