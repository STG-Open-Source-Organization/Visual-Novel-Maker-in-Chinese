FormatHelper 类

格式助手包含一系列函数，可在脚本或 JavaScript 公式中使用，这些函数通常用于计算显示文本。这些函数在技术上不绑定 到 FormatHelper 类。例如：

错误： { ........ "valueFormula": "return FormatHelper.fmtNumVar(p.variable)" } 正确： { ........ "valueFormula": "return fmtNumVar(p.variable)" }

fmtDuration

(
  • durationValue
)
字符串

返回持续时间值的显示文本。它将持续时间值（在内部以帧存储）转换为 毫秒，并添加“ms”后缀。因此，输入值 60 将产生“1000ms”显示文本。（如果 GS.CONST.GAME_FRAME_RATE 为 60）。

参数：

  • durationValue Number
    • 获取显示文本的持续时间值。

Returns:

String:

显示文本。
