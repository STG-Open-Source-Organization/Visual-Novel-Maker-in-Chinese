在 Web 平台进行测试

 

只需从菜单栏选择“构建为 > Web”进行快速测试构建。 之后，只需导航到你的项目文件夹或从菜单栏选择“游戏 > 打开游戏文件夹”。 在那里你会找到一个 build 文件夹，里面有一些文件和一个 index.html 文件。 你只需用 Firefox 打开该文件即可玩你的游戏。或者，你可以设置一个本地 Web 服务器进行更真实的测试，或者直接将 build 文件夹上传到你的 Web 服务器。

 

音频和视频资源

 

在撰写本文时，一半的 Web 浏览器只支持 .m4a/.mp4/.mp3/.aac/.wav 音频和 .mp4 视频，而另一半只支持 .ogg/.wav 音频和 .webm 视频。 如果你打算支持所有主流浏览器，你必须确保你的游戏包含所有音频和视频文件的至少两种格式。 唯一的例外是 .wav 文件，用于简单的声音效果。

 

VN Maker 允许你多次导入同一个文件，但使用不同的格式，然后在运行时自动加载正确的文件。

 

注意：

 

由于安全限制，视频播放可能在某些移动 Web 浏览器中无法正常工作。
