什么是视觉小说制作器？

Visual Novel Maker 是一个专注于制作视觉小说及其子类型的引擎。它允许用户创建交互式或非交互式故事，并发布到 PC 端和移动端。这种易于上手的编辑器，可以让您在没有编程知识的前提下相对轻松地创作视觉小说。视觉小说编辑器是由 André Radomski 开发的。

 

主要特点

Visual Novel Maker 具有强大的用户友好界面，同时为程序员们保留了灵活性和高级功能。

 

支持多平台

在 Windows、MacOSX 和 Linux Ubuntu 上创建游戏！

 

易于理解的场景编辑器

场景编辑器可以让你更轻松地为游戏创造场景。

 

精简的数据库（Streamlined Database）

这种数据库允许用户自由地修改数据，而不受特别的限制。它也允许用户在文件夹内轻松排序数据。

 

高级脚本和插件系统

脚本语言支持 CoffeeScript 或 JavaScript。您可以很容易地定制您的游戏外观或改变整个游戏系统。如果您需要更多功能，您甚至可以借助强大的插件系统为编辑器添加新功能。

 

语言配置 (Language Configuration)

你想把游戏翻译成其他语言的吗？使用这个特性，你可以很轻松地办到这点。

 

多种游戏包选项 (Multiple Game Package Options)

您可以为多个操作系统和设备构建游戏

  • HTML5 / Web
  • Windows 32/64 位
  • Linux Ubuntu 32/64 位
  • OS X 32/64 位
  • SteamOS
  • Android
  • iOS

 

最低配置要求

使用本 Visual Novel Maker 所需的最低配置如下：

 

操作系统（OS）

 Windows 7/8.1/10 (64bit), Mac OS X 10.10 (64-Bit), Linux Ubuntu (64-Bit)

处理器（Processor）

 Intel Core 2 Duo 或更好

显卡（Graphics）

 DirectX / OpenGL 可用 GPU

显示器（Display）

 1280x768 或更好显示

内存（Storage）

 3 GB 可用空间

附加说明 (Additional Notes)

 需要 OpenGL 硬件驱动程序支持才能进行 OpenGL 加速渲染。
