    场景命令

 

场景命令描述了场景视图中的单个命令，用户可以使用它来定义场景的逻辑。所以您可以在这里添加新命令，甚至修改或删除现有命令。

 

  • 自定义视图

  • 自定义视图是一个独立的视图，可以被其他视图或场景命令以多种不同方式使用。例如，自定义视图可以用作弹出控件的弹出对话框，或者可以嵌入到另一个视图中作为部分视图。

  • JavaScript 文件

 

JavaScript 文件可供视图或场景命令使用，用于在运行时定义常量、计算文本或其他逻辑，或在设计时组合 JSON。
