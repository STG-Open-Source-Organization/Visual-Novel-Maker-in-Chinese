视频

 

Visual Novel Maker 让在屏幕上加载和显示视频变得非常容易。您可以同时加载和显示任意数量的视频，还可以添加旋转、缩放或调色等效果。

 

播放视频

 

视频由 gs.Video 对象表示，可以使用 gs.ResourceManager.getVideo 方法加载。gs.Video 对象本身不知道如何在屏幕上直接显示自己。所以要显示视频，我们需要使用 gs.Sprite 对象。整个过程与 gs.Bitmap 对象非常相似。以下示例在屏幕上显示了一个视频：

 

###*
* 为场景准备所有视觉游戏对象。
###  
prepareVisual: ->
    # 创建一个新的 Sprite 对象以在屏幕上显示我们的视频。
    @sprite = new gs.Sprite(Graphics.viewport)
    # 将我们的视频分配给 Sprite 以在屏幕上显示
    @sprite.video = @video
    # 设置屏幕上的位置。我们将其居中。
    @sprite.x = (Graphics.width - @video.width) / 2
    @sprite.y = (Graphics.height - @video.height) / 2
    # 定义我们要显示在屏幕上的视频部分。
    @sprite.srcRect = new gs.Rect(0, 0, @video.width, @video.height)
    
    # 开始视频播放。否则我们将只看到视频的第一帧。
    @video.play()
    # 我们已完成准备视觉对象。因此，我们可以开始屏幕过渡，以便平滑地淡入我们新创建的对象。
    @transition()
    
###*
* 准备场景的所有数据并加载必要的图形和音频资源。
### 
prepareData: ->
    # 加载视频 "fog.webmhd"
    @video = ResourceManager.getVideo("Movies/fog.webmhd")
    # 启用循环，以便视频不间断地重复播放。
    @video.loop = yes
###*
* 更新场景的内容。
###         
updateContent: ->
    # 更新视频渲染。
    @video.update()

 

正如我们所见，我们只是将视频对象分配给 Sprite 对象的 video 属性。或者，我们也可以将视频对象分配给 bitmap 属性，这没什么区别。但建议使用 video 属性。

 

由于我们使用 gs.Sprite 对象来显示视频，我们可以轻松地为我们的视频使用 Sprite 提供的所有功能和效果。与常规位图的一个区别是我们必须每帧调用一次视频的 update 方法来更新视频渲染。如果您停止调用 update 方法，视频仍在后台播放，但在屏幕上看起来是冻结的。此外，在加载视频后调用 play 方法以开始视频渲染非常重要。

 

 

平板电脑和智能手机

 

如果您计划在 Android 或 iOS 设备等移动设备上发布游戏，我们建议不要过多依赖视频。某些设备仍然存在通过 OpenGL 渲染的视频的内存和性能消耗过高的问题。
