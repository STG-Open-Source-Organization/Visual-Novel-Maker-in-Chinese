角色

 

The 角色命令允许您操纵场景中的角色。

 

加入场景

将角色添加到场景。

  • 角色- 您想添加到场景中的角色。他们必须在数据库中设置。

  • 表情- 加入场景时的角色表情。他们必须在数据库中设置。

  • 位置- 角色的位置。

  • 预定义允许选择在数据库 > 系统 > 预定义对象位置中配置的预定义位置之一。

  • 直接 允许您使用图形编辑器设置位置。

  • 计算允许通过变量计算位置。

  • 持续时间- 加入动画的持续时间（以毫秒为单位）。

  • 继续将立即继续场景。

  • 等待将等待直到加入动画完成。

  • 效果- 这些选项会影响角色如何出现。

  • 缓动设置角色的缓动运动。有关更多信息，请参阅缓动效果页面。

  • 运动模糊- 设置“是”以应用运动模糊，“否”以关闭它。

    • 生成时间- 创建新副本后的帧数。默认值为 2。

    • 溶解速度- 复制品消散的速率。具体来说，复制品的透明度每帧都会降低。

    • 不透明度- 复制品生成时开始的透明度。默认值为 100。
      例如，如果溶解速度为 2，则阴影/幽灵/粒子将在 50 帧后完全不可见/消失。

  • 显示- 允许您指定角色的显示顺序和锚点。

  • 锚点设置角色在左上角和中心之间的锚点。将锚点设置为中心仅在缩放和旋转命令将使用时才重要，并且不会影响定位。

  • Z 顺序设置角色的显示顺序。

  • 视口- 将分配给角色的视口。视口决定角色是否受摄像机移动或屏幕效果的影响。

    • 场景- 角色被分配到场景视口，并像属于场景的对象一样行为，因此会受到摄像机移动和屏幕效果的影响。

    • 用户界面- 角色被分配到 UI 视口，并像属于用户界面的对象一样行为，因此不会受到摄像机移动和屏幕效果的影响。

  • 表情- 要设置的新表情。他们必须在数据库中设置。

  • 持续时间- 更改动画的持续时间（以毫秒为单位）。

角色效果

将效果应用于角色。

  • 类型- 将应用于角色的效果。

  • 抖动使角色以不规则和摇晃的动作移动。

    • 强度设置抖动的强度。强度越高，抖动效果越明显。

    • 速度 设置抖动的速度。速度越高，移动越快。

    • 方向- 设置抖动方向。

      • 垂直将抖动方向设置为垂直方向。

      • 水平将抖动方向设置为水平方向

      • 两者将抖动方向设置为两个方向。

    • 持续时间设置效果持续的时间（以毫秒为单位）。

  • 模糊对角色没有影响。

  • 像素化使角色看起来像素化/块状。

    • 宽度设置单个块/像素的宽度。

    • 高度设置单个块/像素的高度。

    • 持续时间设置从像素化达到指定的块/像素大小所需的时间（以毫秒为单位）。使用此选项可以平滑地像素化角色。

  • 缓动将缓动应用于效果动画。更多信息可在缓动效果页面查看。
