可以将来自现有视图的部分包含到另一个视图中，甚至可以在必要时覆盖某些属性。 要从现有视图中包含部分，可以使用以下部分定义： { "include": "<uid>" }

该部分定义将包含指定视图的所有部分。 但也可以只包含特定部分：

 

{ "include": "<uid>", "sections": ["mySection1", "otherSection"] }上面的示例仅包含标识符为“mySection1”和“otherSection”的部分。 其他部分将被忽略。


有时也有必要更改包含部分的某些属性，如某些标签或部分标题。 这可以通过以下包含定义来实现：

{ "include": "<uid>", "sections": ["mySection1", { "identifier": "otherSection", "overwrite": { "name": "New Title" } } ] }

 

上面的示例用“New Title”覆盖了“otherSection”的标题。 覆盖过程只是将覆盖对象与部分属性合并。

 

包含项

 

可以将某个视图中某个部分的项包含到另一个视图的某个部分中，甚至可以在必要时覆盖某些属性。 要包含项，可以使用以下项定义：

 

{ "include": "<uid>", "section": "mySection1" }

 

上面的示例包含指定视图中 section "mySection1" 的所有项。 但也可以只包含特定项：

 

{ "include": "<uid>", "section": "mySection1", "items": ["item1", "item2"] }

 

上面的示例仅包含标识符为“item1”和“item2”的项。 其他项将被忽略。 有时也有必要更改包含项的某些属性，如某些标签。 这可以通过以下包含定义来实现：

 

{ "include": "<uid>", "section": "mySection1", "items": ["item1", { "identifier": "label", "overwrite": { "text": "New Text" } }] }

上面的示例用“New Text”覆盖了“label”项的 text 属性。 覆盖过程只是将覆盖对象与项属性合并。
