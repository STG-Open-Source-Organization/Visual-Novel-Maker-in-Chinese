HTML 视口

视口

 

I如果您浏览 VN Maker 引擎的源代码，您会偶然发现一个名为“gs.Viewport”的东西。在 VN Maker 中，单个视口包含一个图形对象列表，例如 Sprite、平铺 Sprite 等，并控制它们的渲染。例如，Graphics.viewport 是根视口。

 

将视口用作游戏内相机

 

视口定义屏幕上的一个区域，在 Graphics.viewport 的情况下，该区域占据整个屏幕。所有子对象都相对于该区域，这意味着如果视口区域从 100,100 开始而不是从 0,0 开始，则位置为 (0,0) 的 gs.Sprite 将在屏幕上的 100,100 处出现。因为它的位置是相对于视口区域的。

 

此外，视口本身也是一个图形对象，也可以移动、旋转、着色等。关于旋转等变换有趣的是，它会自动影响所有子对象。因此，如果视口移动，所有子对象也会移动。如果视口绕其中心旋转，所有子对象也会绕视口中心旋转。这使得视口成为游戏内相机，允许您滚动浏览游戏场景。

 

如果视口被着色或上色，只有视口区域会被着色或上色。在 Graphics.viewport 的情况下，如果您为该视口设置了棕褐色调，则整个屏幕都会变成棕褐色，这对于特殊效果很有用。让我们快速尝试一下：

# ===================================================================
#
#   脚本：Component_TestBedBehavior
#
#   在此处填写您的名字
#
# ===================================================================
class Component_TestBedBehavior extends gs.Component_SceneBehavior
    ###*
    * 一个测试用例场景行为。您可以在此处使用 Visual Novel Maker 的
    * 游戏引擎进行尝试，以更好地感受一切。
    ###
    constructor: ->
        super
        
        # 定义资源上下文属性
        @resourceContext = null
    
    ###*
    * 初始化场景。
    ###
    initialize: ->
        super
        
        # 创建一个新的资源上下文
        @resourceContext = ResourceManager.createContext()
        
        # 设置当前对象管理器
        gs.ObjectManager.current = SceneManager
        
        # 设置其为当前资源上下文
        ResourceManager.context = @resourceContext
        
    ###*
    * 处置场景。
    ###  
    dispose: ->
        super
    
    ###*
    * 为场景准备所有视觉游戏对象。
    ###  
    prepareVisual: ->
        # 创建一个背景 Sprite 并将其分配给根视口。
        @background = new gs.Sprite(Graphics.viewport)
        # 分配 "Bench_Morning" 位图给它。
        @background.bitmap = ResourceManager.getBitmap("Graphics/Backgrounds/Bench_Morning")
        # 设置 srcRect 以显示整个位图
        @background.srcRect = new gs.Rect(0, 0, @background.bitmap.width, @background.bitmap.height)
        
        # 创建一个角色 Sprite 并将其分配给根视口
        @character = new gs.Sprite(Graphics.viewport)
        # 分配 "JaneDate_Normal" 位图给它。
        @character.bitmap = ResourceManager.getBitmap("Graphics/Characters/JaneDate_Normal")
        # 设置 srcRect 以显示整个位图
        @character.srcRect = new gs.Rect(0, 0, @character.bitmap.width, @character.bitmap.height)
        # 将角色居中放置在屏幕上。
        @character.x = (Graphics.width - @character.bitmap.width) / 2
        
        # 将视口的锚点设置为其中心。
        Graphics.viewport.anchor.x = 0.5
        Graphics.viewport.anchor.y = 0.5
        # 设置视口的色调为棕褐色
        Graphics.viewport.tone.set(35, -35, -70, 255)
        # 将视口缩放到 150%
        Graphics.viewport.zoomX = 1.5
        Graphics.viewport.zoomY = 1.5
        
        # 我们已完成准备视觉对象。因此，我们可以开始屏幕过渡，以便平滑地淡入我们新创建的对象。
        @transition()
        
    ###*
    * 准备场景的所有数据并加载必要的图形和音频资源。
    ### 
    prepareData: ->
        # 加载背景图像
        ResourceManager.getBitmap("Graphics/Backgrounds/Bench_Morning")
        # 加载角色图像
        ResourceManager.getBitmap("Graphics/Characters/JaneDate_Normal")
        
    ###*
    * 更新场景的内容。
    ###         
    updateContent: ->
        # 我们需要每帧更新一次视口以应用变换、效果等。
        Graphics.viewport.update();
        
gs.Component_LayoutSceneBehavior = Component_TestBedBehavior

如果我们测试一下，我们将看到一个带有角色的背景，它们都显示为完全的棕褐色调并放大。我们在这里所做的是，我们首先将根视口着色为棕褐色，然后为其添加缩放，这将着色和缩放整个场景。当然，这种缩放也可以与动画结合，以实现漂亮流畅的游戏内摄像机移动。

 

这一切都是因为 Sprite，背景和角色，都属于根视口，因为我们将根视口传递给了两个 Sprite 的构造函数。您可以尝试接下来更改视口的 angle 属性来旋转整个场景！

 

自定义视口

 

在某些情况下，创建自定义视口是有意义的。例如，您可以将所有角色和背景放在一个视口中，将所有消息和游戏内 UI 元素放在另一个视口中。然后，如果您只想着色场景但保留游戏内 UI 的彩色，您只需要着色包含角色和背景的视口。对于游戏内相机也是如此，如果您想滚动浏览场景或放大，您可能不希望游戏内 UI 受滚动或缩放的影响。

 

因此，在以上情况下，创建自定义视口是有意义的。您可以通过简单地创建一个 gs.Viewport 类的实例来轻松创建自定义视口。然后，如果您创建其他图形对象（如 Sprite），您只需将自定义视口对象传递给图形对象的构造函数即可。

 

###*
* 为场景准备所有视觉游戏对象。
###  
prepareVisual: ->
    # 创建一个自定义视口
    @viewport = new gs.Viewport(0, 0, Graphics.width, Graphics.height, Graphics.viewport)
    # 将视口的锚点设置为其中心。
    @viewport.anchor.x = 0.5
    @viewport.anchor.y = 0.5
    # 设置视口的色调为棕褐色
    @viewport.tone.set(35, -35, -70, 255)
    # 将视口缩放到 150%
    @viewport.zoomX = 1.5
    @viewport.zoomY = 1.5
    
    # 创建一个背景 Sprite 并将其分配给根视口。
    @background = new gs.Sprite(@viewport)
    # 分配 "Bench_Morning" 位图给它。
    @background.bitmap = ResourceManager.getBitmap("Graphics/Backgrounds/Bench_Morning")
    # 设置 srcRect 以显示整个位图
    @background.srcRect = new gs.Rect(0, 0, @background.bitmap.width, @background.bitmap.height)
    
    # 创建一个角色 Sprite 并将其分配给根视口
    @character = new gs.Sprite(@viewport)
    # 分配 "JaneDate_Normal" 位图给它。
    @character.bitmap = ResourceManager.getBitmap("Graphics/Characters/JaneDate_Normal")
    # 设置 srcRect 以显示整个位图
    @character.srcRect = new gs.Rect(0, 0, @character.bitmap.width, @character.bitmap.height)
    # 将角色居中放置在屏幕上。
    @character.x = (Graphics.width - @character.bitmap.width) / 2
    
    # 创建一个可以用来显示消息的方形对象。
    # 我们将其分配给根视口，因此它不会受到缩放的影响。
    @square = new gs.Quad(Graphics.viewport)
    # 设置颜色为透明黑色
    @square.color = new gs.Color(0, 0, 0, 100)
    # 将其放置在屏幕底部
    @square.rect.set(0, Graphics.height - 150, Graphics.width, 150)
    
    # 我们已完成准备视觉对象。因此，我们可以开始屏幕过渡，以便平滑地淡入我们新创建的对象。
    @transition()
    
    ###*
    * 更新场景的内容。
    ###         
    updateContent: ->
        # 我们需要每帧更新一次视口以应用变换、效果等。
        @viewport.update();

在这里，我们创建了一个自己的 gs.Viewport 对象，并将其传递给我们的两个 Sprite 的构造函数。我们还创建了一个正方形，但将其传递给根视口。如果我们测试一下，我们将看到只有角色和背景 Sprite 受到影响。我们的正方形对象没有改变，因为我们可能想用它来显示消息，所以它将成为游戏内 UI 的一部分，因此我们不希望对其进行缩放。由于视口本身是一个图形对象，因此需要将其默认的根视口传递给其构造函数。

 

根视口

 

根视口，可以通过 Graphics.viewport 访问，是一个特殊的视口。与其他视口不同，无论您将哪个视口传递给图形对象的构造函数，根视口都会自动包含游戏的所有图形对象。所以即使您创建了一个自定义视口并将其分配给您的图形对象，该图形对象也会自动添加到根视口。

 

这是因为根视口管理着图形对象的实际渲染。
