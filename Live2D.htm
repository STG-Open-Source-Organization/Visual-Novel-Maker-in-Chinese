Live2D 命令

 

The Live2D 命令用于在屏幕上显示 Live2D 模型。

 

重要 说明

  • 来自角色类别的 [移动角色]、[沿路径移动角色]、[缩放角色]、[摇晃角色] 和 [混合角色] 命令也会影响 Live2D 模型。

 

Live2D 加入场景

让一个 Live2D 角色加入场景。

  • 角色- 要加入的角色。

  • 模型- 要使用的 Live2D 模型。

  • 位置- Live2D 角色的位置。

  • 预设 allows to select one of the predefined positions configured in Database > System > Predefined Object Positions.

  • 直接允许您使用图形编辑器设置位置。

  • 计算允许您通过变量计算位置。

  • 持续时间- 加入动画的持续时间（毫秒）。

  • 继续将立即使场景继续。

  • 等待将使场景等待直到加入动画完成。

  • 效果- 这些选项会影响角色如何出现。

  • 缓动设置角色的缓动移动。更多信息请参阅缓动效果页面。

  • 运动模糊- 设置“是”以应用运动模糊，“否”以关闭它。

    • 生成 时间- 创建新副本后的帧数。默认为 2。

    • 消散 速度- 生成的副本消散的速率。具体来说，副本的不透明度每帧都会降低。

    • 不透明度 - 复制图像在生成时开始的不透明度。默认值为 100。
      例如，如果消散速度为 2，则阴影/鬼影/粒子将在 50 帧后完全消失/死亡。

  • 显示- 允许您指定角色的显示顺序和锚点。

  • 锚点设置角色在左上角和中心之间的锚点。仅当使用缩放和旋转命令时，设置锚点为中心才重要，并且不会影响定位。

  • Z 序设置角色的显示顺序。

  • 视口- 将分配给角色的视口。视口决定了角色是否会受到相机移动或屏幕效果的影响。

    • 场景- 角色被分配到场景视口，并表现得像属于场景的对象，因此会受到相机移动和屏幕效果的影响。

    • 用户界面- 角色被分配到 UI 视口，并表现得像属于用户界面的对象，因此不会受到相机移动和屏幕效果的影响。

 

Live2D 退出场景

让 Live2D 角色退出场景。

  • 角色- 要从场景中移除的角色。

  • 持续时间- 退出动画的持续时间（毫秒）。

  • 继续将立即使场景继续。

  • 等待将使场景等待直到退出动画完成。

  • 效果- 这些选项会影响角色如何消失。

  • 缓动设置角色的缓动移动。更多信息请参阅缓动效果页面。

  • 动画设置角色的移动。

    • 移动将角色从屏幕左/上/右/下方向移出。

    • 混合允许您淡出角色。

    • 遮罩允许您将角色遮罩到遮罩文件。

      • 模糊 遮罩边缘的平滑度。

 

Live2D 动作

为 Live2D 角色设置新动作。

  • 角色- 要设置动作的 Live2D 角色。

  • 动作- 要设置的动作。

  • 重复- 指示是否应重复动作。

  • 持续时间- 退出动画的持续时间（毫秒）。

  • 继续将立即使场景继续。

  • 等待将使场景等待直到退出动画完成。

 

Live2D 动作组

为 Live2D 角色设置新的动作组。动作组是 Live2D 文件中配置的一组常规动作，可以随机或按顺序播放。

  • 角色- 要设置动作组的 Live2D 角色。

  • 动作 组- 要设置的动作组。

  • 重复- 指示是否应重复动作组。

  • 持续时间- 退出动画的持续时间（毫秒）。

  • 继续将立即使场景继续。

  • 等待将使场景等待直到退出动画完成。

  • 淡入- 为动作添加淡入时间。如果设置为 0，动作将立即显示。

 

Live2D 表情

更改 Live2D 角色的面部表情。

  • 角色- 要更改面部表情的 Live2D 角色。

  • 表情- 要设置的新 Live2D 面部表情。

 

Live2D 移动

将 Live2D 角色移动到屏幕上的指定位置。

  • 角色- 要移动的 Live2D 角色

  • 模型- 要使用的 Live2D 模型。

  • 位置- Live2D 角色的目标位置。

  • 预设 -允许选择在数据库 > 系统 > 预设对象位置中配置的预设位置之一。

  • 直接- 允许使用图形编辑器设置目标位置。

  • 计算- 允许通过变量计算目标位置。

  • 持续时间- 移动动画的持续时间（毫秒）。

  • 继续将立即使场景继续。

  • 等待将使场景等待直到移动动画完成。

 

Live2D 参数

将 Live2D 角色的模型参数设置为指定值或进行动画处理。

  • 角色- 要为其设置/动画参数的 Live2D 角色。

  • 参数- 要设置/动画的参数。它必须是 Live2D 模型的一个有效参数，例如 PARAM_ANGLE_X、PARAM_EYE_L_OPEN 等。

  • 值- 要设置的目标值。

  • 持续时间- 动画的持续时间（毫秒）。

  • 继续将立即使场景继续。

  • 等待将使场景等待直到动画完成。

  • 缓动设置动画的缓动算法。更多信息请参阅缓动效果页面。

 

Live2D 设置

允许更改 Live2D 角色的设置，例如默认待机动画和眨眼。

  • 角色- 要更改设置的 Live2D 角色。

  • 呼吸强度- 呼吸动画的强度，范围从 0.0% 到 100.0%。如果指定 0.0%，则禁用呼吸。

  • 空闲强度- 默认空闲动画的强度，范围从 0.0% 到 100.0%。如果指定 0.0%，则禁用空闲动画。

  • 唇同步灵敏度- 值越高，嘴巴的张合程度受音量的影响越大。如果指定 0.0%，即使在较高的音量下，嘴巴的张合程度也不会受到影响。

  • 眨眼- 允许您配置眨眼。

  • 启用- 启用/禁用默认眨眼动画。

  • 间隔- 两次眨眼之间的最大时间间隔（毫秒）。

  • 闭眼 动作- 眼睛保持闭合的时间（毫秒）。

  • 闭合 动作- 眼睛闭合动画所需的时间（毫秒）。

  • 睁眼 动作- 眼睛睁开动画所需的时间（毫秒）。

 

Live2D 默认值

允许覆盖 Live2D 特定命令的默认值。

  • 出现 持续时间是加入动画的持续时间（毫秒）。

  • 消失 持续时间是退出动画的持续时间（毫秒）。

 

  • 出现 效果 - 缓动是用于加入动画的缓动设置。

  • 出现 效果 - 动画是加入动画的动画设置。

 

  • 消失 效果 - 缓动是用于退出动画的缓动设置。

  • 消失 效果 - 动画是退出动画的动画设置。

  • 显示 - Z 序是 Live2D 角色的 Z 索引。
