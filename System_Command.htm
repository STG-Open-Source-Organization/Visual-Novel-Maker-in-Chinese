T

 

系统命令用于控制数据库和游戏系统功能的特定目的。

 

调用公共事件

调用选定的公共事件。如果公共事件勾选了“并行运行”复选框，则场景将不会等待公共事件完成。

  • 事件 -要调用的公共事件

  • 参数- 公共事件的可选参数（如果公共事件有任何）。

 

结束公共事件

结束选定公共事件的执行。

  • 事件 -要结束的公共事件。

 

恢复公共事件

从停止点恢复选定公共事件的执行。

  • 事件- 要恢复的公共事件。

 

解锁 CG

解锁选定的 CG，使其在 CG 画廊菜单中对玩家可见。

  • CG- 要解锁的 CG

 

UI 访问

更改玩家对某些游戏内 UI/菜单的访问权限，例如保存菜单。

  • 保存菜单- 指示是否可以访问保存菜单。

  • 加载菜单- 指示是否可以访问加载菜单。

  • 菜单- 指示是否可以访问主菜单。

  • 日志- 指示是否可以访问日志。

 

保存持久数据

保存所有持久变量的当前状态。在持久变量被修改后应调用此命令。此命令可能耗时，因为它会将数据写入磁盘。

 

保存设置

保存当前游戏设置。在更改设置后（例如通过设置游戏数据命令）应调用此命令。
