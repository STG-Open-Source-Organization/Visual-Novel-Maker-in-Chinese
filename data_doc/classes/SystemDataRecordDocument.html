属性

items.data.aspectRatio (items.data.宽高比)

Number (数值)

如果选择了预定义的分辨率，则为游戏分辨率的宽高比。

  • 0 = 4 : 3
  • 1 = 16 : 10
  • 2 = 16 : 9

gs.Color (gs.颜色)

items.data.introInfo (items.data.片头信息)

Object (对象)

片头场景，紧接在语言选择之后，但在标题画面之前。

items.data.introInfo.scene (items.data.片头信息.场景)

gs.DocumentLink (gs.文档链接)

指向实际应作为片头场景使用的场景的文档链接。

items.data.menuBuzzerSound (items.data.菜单蜂鸣声)

items.data.menuSelectSound (items.data.菜单选择声)

gs.AudioResource (gs.音频资源)

items.data.resolution (items.data.分辨率)

Number (数值)

游戏的分辨率（高度值，如 720p）。

items.data.resolutionType (items.data.分辨率类型)

Number (数值)

选择的分辨率类型。

  • 0 = 预定义分辨率
  • 1 = 自定义分辨率

items.data.startInfo (items.data.开始信息)

Object (对象)

items.data.startInfo.scene (items.data.开始信息.场景)

gs.DocumentLink (gs.文档链接)

指向实际应作为开始场景使用的场景的文档链接。

items.data.useIntroScene (items.data.使用片头场景)

Boolean (布尔值)

指示是否应该使用片头场景。
