SceneDocument 类

继承自 gs.Document
模块：vn

存储场景的数据。

  • 索引
  • 属性

条目索引

属性

  • items.booleanVariables (条目.布尔变量)
  • items.chapterUid (条目.章节UID)
  • items.commands (条目.命令)
  • items.listVariables (条目.列表变量)
  • items.localizableStrings (条目.本地化字符串)
  • items.numberVariables (条目.数值变量)
  • items.order (条目.顺序)
  • items.parentId (条目.父级ID)
  • items.stringVariables (条目.字符串变量)

属性

items.booleanVariables (条目.布尔变量)

gs.Variable (gs.变量)

按索引存储所有本地布尔变量的定义。

items.chapterUid (条目.章节UID)

String (字符串)

场景关联的章节的 UID。

items.commands (条目.命令)

vn.SceneCommand (vn.场景命令)

包含场景的所有命令。

items.listVariables (条目.列表变量)

gs.Variable (gs.变量)

按索引存储所有本地列表变量的定义。

items.localizableStrings (条目.本地化字符串)

Object (对象)

包含场景中使用的所有文本，这些文本可以通过语言配置视图/编辑器进行翻译。 请参阅 LocalizableString (本地化字符串) 文档。

items.numberVariables (条目.数值变量)

gs.Variable (gs.变量)

按索引存储所有本地数值变量的定义。

items.order (条目.顺序)

Number (数字)

用于控制编辑器中场景排序的顺序索引。

items.parentId (条目.父级ID)

String (字符串)

场景父级文档的 UID。 它可以是另一个场景或章节。

items.stringVariables (条目.字符串变量)

gs.Variable (gs.变量)

按索引存储所有本地字符串变量的定义。
