CommonEventParameter 类

模块：gs

存储单个通用事件参数定义。

  • 属性

属性

booleanVariable

gs.Variable

如果 type 为 "Switch"，则存储布尔变量。

label

String

在自动生成的 UI 表单中向用户显示的文本。

numberList

gs.CommonEventParameterNumberList

如果 numberValueType 选择 "Number List"，则存储数字列表。

numberValueType

String

如果 type 为 "Number"，则描述存储的数字值的类型。

  • number - 常规数字值
  • numberList - 来自弹出列表的值
  • characters - 角色 ID
  • characterExpressions - 角色表情 ID
  • cgGallery - CG 图库条目 ID
  • commonEvents - 通用事件 ID
  • animations - 动画 ID

numberVariable

gs.Variable

如果 type 为 "Number"，则存储数字变量。

stringValueType

String

如果 type 为 "Text"，则描述存储的文本值的类型。

  • text - 常规文本值
  • sceneId - 场景的 UID。
  • Graphics/Characters - Graphics/Characters 文件夹中的图形资源名称
  • Graphics/Backgrounds - Graphics/Backgrounds 文件夹中的图形资源名称
  • Graphics/Pictures - Graphics/Pictures 文件夹中的图形资源名称
  • Graphics/Transitions - Graphics/Transitions 文件夹中的图形资源名称
  • Graphics/Fonts - Graphics/Fonts 文件夹中的字体资源名称
  • Audio/Sounds - Audio/Sounds 文件夹中的音频资源名称
  • Audio/Music - Audio/Music 文件夹中的音频资源名称
  • Movies - Movies 文件夹中的视频资源名称
  • Live2D - Live2D 文件夹中的 Live2D 资源名称

stringVariable

gs.Variable

如果 type 为 "Text"，则存储字符串变量。

type

Number

参数类型。

  • 0 = Text
  • 1 = Number
  • 2 = Switch
