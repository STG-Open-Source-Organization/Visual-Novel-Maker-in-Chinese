Document Class（文档类）

Module:（模块：）gs

Visual Novel Maker存储的所有数据，除了图形和音频资源，都遵循文档格式。 所有文档都可以在项目的data文件夹中找到。 每个文档都以 .json 文件存储，并使用其唯一的标识符 (UID) 作为文件名。

  • Index（索引）
  • Properties（属性）

Item Index（项目索引）

  • items
  • items.name
  • items.type
  • lastModificationTime

Properties（属性）

items

Object（对象）

包含文档的实际数据。 保持数据处于可序列化/反序列化状态非常重要。

items.name

String（字符串）

文档的显示名称。

items.type

String（字符串）

文档的类型。 这个字段是必要的，因为 Visual Novel Maker 需要知道如何处理这个文档。 以下是可用的公共文档类型：

  • vn.scene
    • - Scene（场景）
  • vn.chapter
    • - Chapter（章节）
  • data_record
    • - Database Record（数据库记录）
  • game_script
    • - Game Script in Script-Editor（脚本编辑器中的游戏脚本）
  • script
    • - Script in Extension Editor（扩展编辑器中的脚本）
  • event_command
    • - Scene Command for Scene-Editor/View（场景编辑器/视图的场景命令）
  • DataRecordView
    • - Database Category + View（数据库类别 + 视图）
  • custom_view
    • - Custom View/Form for use in other views/forms/scene-commands（用于其他视图/表单/场景命令的自定义视图/表单）
  • application_language_bundle
    • - Language Bundle to translate custom plugins into different languages（用于将自定义插件翻译成不同语言的语言包）
  • language_profile
    • - Language Profile definition for the game's supported languages（游戏支持的语言的语言配置文件定义）
  • language_bundle
    • - Language Bundle which contains all texts of a game language（包含游戏语言所有文本的语言包）
  • custom_strings_bundle
    • - Contains localized custom texts for use in game scripts（包含用于游戏脚本的本地化自定义文本）
  • global_variables
    • - Stores all global variable definitions（存储所有全局变量定义）
  • persistent_variables
    • - Stores all persistent variable definitions（存储所有持久变量定义）
  • settings
    • - Stores project specific settings（存储项目特定设置）
  • extension
    • - Holds data about an installed plugin（保存有关已安装插件的数据）

lastModificationTime

Number（数字）

文档的最后修改时间的时间戳。它总是zero（零）并且仅因内部原因而存在。

uid

String（字符串）

文档的唯一标识符（UID）。 这个 ID 也必须用作 .json 文件的名称。
