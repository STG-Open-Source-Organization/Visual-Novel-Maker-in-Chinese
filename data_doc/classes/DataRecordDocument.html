DataRecordDocument 类

继承自 gs.Document
模块：vn

存储数据库的数据记录。

  • 属性

属性

items.category

字符串

数据记录所属的数据库类别。

items.data

对象

包含记录的实际数据。

items.data.booleanVariables

gs.Variable

按索引存储所有本地布尔变量定义。

items.data.index

对象

游戏中使用的数据库中数据记录的索引。 从 0 开始。所以 0 = 记录 0001，1 = 记录 0002，等等。

items.data.listVariables

gs.Variable

按索引存储所有本地列表变量定义。

items.data.name

对象

游戏中使用的数据记录的名称。

items.data.numberVariables

gs.Variable

按索引存储所有本地数字变量定义。

items.data.stringVariables

gs.Variable

按索引存储所有本地字符串变量定义。

items.id

字符串

与 data.index 匹配的数据记录的 ID。

items.isFolder

布尔值

指示数据记录是否为文件夹。

items.localizableStrings

对象

包含场景中使用的所有文本，可以通过语言配置视图/编辑器进行翻译。 请参阅 LocalizableString 文档。

items.parentId

字符串

数据记录的父文档的 UID。 它可以是配置为文件夹的数据记录，或者null如果它是顶级数据记录。
