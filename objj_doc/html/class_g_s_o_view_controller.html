详细描述

一个视图控制器允许您轻松地创建和管理一个GSOView（从原始视图描述符、文档或文档的 UID）。

它还管理视图的正确创建，包括缓存机制。下面的示例从自定义视图创建 GSO 视图：

// 从自定义视图创建视图控制器
var controller = [[GSOViewControlleralloc] initWithUid:@"<custom-view uid>"];
// 访问 GSOView 对象
var view = [controller view];
// 添加到父视图或任何其他视图。
[parentView addSubview:view];

- (id)initWithDescriptor: (id) aDescriptor
cacheAccess: (BOOL) cacheAccess 
实现

初始化一个新创建的视图控制器。

参数
aDescriptor用于构建视图的视图描述符。
cacheAccess指示视图是否应从缓存中恢复（速度更快）。这仅在描述符具有已分配的 id 属性时有效。此外，如果您对视图描述符进行了任何更改，并且视图是从缓存中恢复的，则这些更改将不会影响视图。

- (id) object
实现

获取视图将从中读写数据的对象。

此方法将立即触发一个写入进程到对象。请注意，您获得的*对象*与您通过setObject:方法设置的对象不是同一个实例。

返回
包含视图当前字段值的对象。
