详细描述

默认的窗口控制器类，用于显示由 JSON 视图描述符定义的对话框/窗口，例如自定义视图。

建议使用GSODialog助手，以便轻松地从 JSON 中定义的对话框描述符创建对话框。

另请参阅
GSODialog

要将自定义视图显示在自己的窗口中，可以使用以下示例：

var windowController = [[GSOWindowControlleralloc] initWithUid:@"<您的自定义视图的 UID>"];
[windowController setObject:{ value1: 100, value2:"Test"}];
[windowController showModalWindowWithTarget:selfdidEndSelector:@selector(windowDidEnd:code:)];
fragment

有特殊的 UID 可以触发内部对话框，例如图形选择或变量选择对话框。一个例子如下：

var windowController = [[GSOWindowControlleralloc] initWithUid:@"dialog.selectGraphicResource"parameters: { folder:"Graphics/Characters"}];
[windowController showModalWindowWithTarget:selfdidEndSelector:@selector(windowDidEnd:code:)];
fragment

查看GSOInternalDialogs了解更多信息。

- (id) initWithDescriptor: (id) aDescriptor
implementation

- (id)initWithDescriptor: (id) aDescriptor
cacheAccess: (BOOL) cacheAccess 
implementation

使用指定的 JSON 视图描述符初始化新的窗口控制器。

参数
aDescriptor一个 JSON 视图描述符。它只是一个 JSON/对象，格式与 Extension Editor 中的相同。
cacheAccess指示是否应从缓存恢复视图/窗口。通常，从视图描述符创建的窗口/视图会被缓存以节省性能。但如果您指定NO，则窗口/视图将从指定的描述符重新创建和重新计算。
