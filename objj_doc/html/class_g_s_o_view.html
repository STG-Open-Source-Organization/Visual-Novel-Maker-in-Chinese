详细描述

此视图是基于 JSON 的视图/布局系统的核心。

它接收一个视图描述符，这是一个 JSON 结构，以与扩展编辑器中的自定义视图相同的方式描述视图，并从中构建一个即用型视图。推荐使用GSOViewController而不是直接处理GSOView。如果您直接使用GSOView，将没有缓存机制，这意味着视图将在每次创建此类实例时完全重建，这是一个耗时的过程，取决于视图的内容。

要从现有自定义视图构建视图，可以使用以下示例：

// 通过 UID 获取自定义视图
var customView = [[GSDocumentManagerdefaultManager] documentByUid:@"<custom view uid>"];
// 创建一个新视图，您可以只传递一个零矩形。
var view = [[GSOViewalloc] initWithFrame:CGRectMakeZero()];
// 设置描述符，它只是自定义视图文档的整个项容器。
[view setDescriptor:customView.items];
// 创建描述符定义的所有项视图
[view createItemViews];
// 更新所有项视图
[view update];
// 建立由委托、绑定等定义的项视图之间的连接。
[view createItemViewConnections];
// 正确布局所有项视图
[view layoutSubviews];
// 调整视图大小以适应其内容
[view sizeToFit];
// 现在视图已准备就绪
// ......
