VN Maker API 文档描述了 VN Maker Editor-Plugin 开发的所有公开的 Objective-J 类和函数。由于 VN Maker 使用 Cappuccino 框架和 Objective-J 编程语言，因此建议查看Cappuccino 网站和Cappuccino API 文档。

使用 Objective-J 和 VN Maker API 开发插件通常仅对更复杂的插件（如自定义 UI 控件）是必要的。对于许多其他插件，仅使用基于 JSON 的视图和 JavaScript 就足够了，这要容易得多。有关如何为 VN Maker 创建插件的更多信息，请查看 VN Maker 的帮助文件中的“脚本和插件参考 > 扩展文档”。

如何开始？

首先，建议至少对桌面应用程序开发和/或传统 GUI 开发有一些了解，以便更好地理解。

您应该首先了解文档管理系统 (DMS)，以了解如何存储和访问数据。首先查看GSDocument、GSDocumentManager和GSDatabase类，以了解 DMS。之后，您应该查看资源管理系统 (RMS)，了解如何加载和访问资源，如图像、音频等。查看GSResource、GSResourceManager以了解它。

下一步应该是 (自定义) 项视图，也称为“自定义控件”，用于使用 JSON 定义构建扩展编辑器中的视图和窗口。是的，您可以创建自己的自定义控件类型，并在 JSON 中以与内部控件相同的方式使用它们。查看GSOItemView、GSODialog以及所有其他 GSO 类以了解更多信息，并查看帮助文件中的“脚本与插件参考 > 扩展文档”部分中的“自定义控件”。

隐藏/未记录的类和函数

您可能会发现 VN Maker 中有很多隐藏/未记录的类和函数，因为 VN Maker API 文档仅涵盖了整个系统的一小部分。请避免访问和/或反向工程这些类和函数，因为它们并非供外部访问，如果使用不当，可能会导致 VN Maker 处于不稳定状态。

如果您觉得某些隐藏/未记录的类或函数应该被公开并添加到 VN Maker API 中，请随时访问我们的官方论坛，我们乐于讨论此类情况，并可能在合理的情况下扩展 VN Maker API。有时，我们可能只是错过了添加和描述某些类或函数。

如果我需要帮助？还有其他示例或教程吗？

如果您需要帮助，或者文档中没有您想要的信息，请随时访问我们的官方论坛并创建相应类别的主题。使用搜索功能查看您的问题是否已被他人提出。

还强烈建议阅读帮助文件中的“脚本和插件参考”，其中您还可以找到许多示例。如果您对如何处理基础引擎更感兴趣，尤其是因为该引擎也可以在编辑器中使用，您还应该查看帮助文件中的“脚本编写指南”。

请尽情享受为 VN Maker 开发插件的乐趣！
