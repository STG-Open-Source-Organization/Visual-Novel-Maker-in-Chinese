详细描述

该项视图工厂用于根据类型创建项视图。

您还必须在此处使用registerItemView:forTypeName: (GSOItemViewFactory)方法注册您的自定义项视图，以便在您的自定义视图中使用。例如，在扩展编辑器中的一个 Objective-J 文件会像这样：

@implementationMyItemView :GSOItemView
{
// 属性....
}
// 实现....
@end
[GSOItemViewFactory registerItemView:MyItemViewforTypeName:@"MyItemView"];
片段

在此之后，您可以在视图中使用自定义项视图，如下所示：

{
"type":"MyItemView",
"frame": [0, 0],
......
}

方法文档

- (GSOItemView) createViewFromItemDescriptor: (id) anItemDescriptor
实现

创建由指定的项描述符描述的项视图。

参数
anItemDescriptor要创建的项的项描述符。
返回
新创建的项视图，或者nil如果无法为指定的项描述符创建项视图。
+ (objj_class) itemViewClassForTypeName: (CPString) aTypeName
实现

获取指定类型名称的已注册项视图类对象。

仅适用于自定义项视图类。您无法获取内置类对象。

参数
aTypeName在基于 JSON 的视图中使用的项视图的类型名称。
+ (void) registerItemView: (objj_class) anItemViewClass
实现

注册一个新的项视图。

类名用作类型名称。您需要先注册一个项视图，才能在自定义视图中使用它。通常，您会在项视图实现的正下方调用此方法。

参数
anItemViewClass要注册的项视图类对象。
