详细描述

此类与GSResourceManager一起，定义了Visual Novel Maker资源管理系统（RMS）的核心。

所有项目资源，也称为“资产”，如图像、音乐、声音等，都使用资源进行存储和访问。所有资源都存储在项目的resources目录中。

+ (GSResourceType) typeFromFolderPath: (CPString) aPath
实现

根据根文件夹路径获取资源的类型。

它检查文件夹路径的第一部分，并根据以下规则集确定资源类型：

  • 如果文件夹路径以“Graphics”开头，则资源类型为“graphic”。
  • 如果文件夹路径以“Audio”开头，则资源类型为“audio”。
  • 如果文件夹路径以“Movies”或“Videos”开头，则资源类型为“video”。
  • 否则，资源类型为“unknown”。
返回
一个资源类型。
