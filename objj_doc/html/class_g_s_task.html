详细描述

任务处理一项需要完成的阻塞工作，例如：编译脚本、保存项目、创建游戏包等。

正常情况下，在任务完成之前，用户无法继续使用 VN Maker 工作。有关更多信息，请查看GSTaskManager。

此类是 VN Maker 中所有任务的基类。因此，要实现自己的任务，您必须从此类派生一个新类并实现必要的方法。正常情况下，您只需要实现“run”方法。

@implementationCustomTask :GSTask
{
}
- (id)init
{
self= [superinit];
[selfsetDescription:@"My Custom Task"];
return self;
}
- (void)run
{
// Task Logic Here.
}
@end

如果在任务执行过程中发生错误，则需要调用此方法。例如，如果您在任务逻辑周围放置了一个 try-catch 块，然后在 catch 块中调用此方法。

- (void) setDelegate: (CPObject)
implementation

设置代理。

如果实现了以下方法，则会在代理上调用：

  • task:(GSTask)aTask statusDidChange:(CPInteger)aStatus - 任务状态更改时调用。
  • task:(GSTask)aTask detailsDidChange:(CPInteger)details - 任务详细信息消息更改时调用。
  • task:(GSTask)aTask descriptionDidChange:(CPInteger)aDescription - 任务描述消息更改时调用。
  • task:(GSTask)aTask errorDidOccur:(id)errorData - 任务执行期间发生错误时调用。
  • taskDidFinish:(GSTask)aTask withResult:(id)resultData - 任务完成时调用。
Parameters
aDelegate要设置的代理。
