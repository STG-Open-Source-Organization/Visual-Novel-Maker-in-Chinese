所有内部对话的枚举，可以使用以下方式轻松触发：

GSOWindowController或GSODialogcreateDialog:{ uid:dialog.selectGraphicResource

显示图形资源选择对话框。接受以下参数：
folder - 要显示的资源文件夹，例如：Graphics/Pictures。

  • emptySelection - 指示是否允许选择“(无)”。
  • multiSelection - 指示是否可以选择多个资源。
  • dialog.selectVariable

显示视频资源选择对话框。接受以下参数：
folder - 要显示的资源文件夹，例如：Graphics/Pictures。

  • emptySelection - 指示是否允许选择“(无)”。
  • multiSelection - 指示是否可以选择多个资源。
  • dialog.selectVariable

显示音频资源选择对话框。接受以下参数：
folder - 要显示的资源文件夹，例如：Graphics/Pictures。

  • emptySelection - 指示是否允许选择“(无)”。
  • multiSelection - 指示是否可以选择多个资源。
  • dialog.selectVariable

显示变量选择对话框。接受以下参数：
dataSource - 要选择的变量类型。可以是“numbers”、“booleans”、“strings”或“lists”。

  • dialog.selectParameters
