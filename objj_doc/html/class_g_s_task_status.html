Detailed Description

All possible status values for a single task.

GSTaskStatusInitialized
Indicates that the task has been initialized and is ready to run.

GSTaskStatusRunning
Indicates that the task is currently running.

GSTaskStatusFinished
Indicates that the task has been finished.

GSTaskStatusErrorOccurred
Indicates that the task has been aborted with an error.
