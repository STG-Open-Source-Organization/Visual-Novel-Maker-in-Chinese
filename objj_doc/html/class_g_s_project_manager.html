详细描述

项目管理器持有并管理当前项目，并提供打开、关闭、创建和删除项目的功能，以及获取项目信息（如项目在磁盘上的位置等）的功能。

请注意，创建、打开、关闭或删除项目是高级功能，会阻塞用户界面操作。用户将被进度条窗口阻塞，直到操作完成。

不建议创建新的GSProjectManager实例。相反，您可以使用defaultManager (GSProjectManager)方法访问默认的项目管理器。除非您确切知道自己在做什么，否则也不建议介入 VN Maker 的项目管理。

项目信息对象

项目信息对象只是一个纯 JavaScript 对象，包含一些头部信息，如项目名称、gameTitle、template 和 filePath。您可以通过 GSProjectManager::currentProject 方法访问该对象。主页视图中的最近项目列表由存储在 `<install-dir>/projects/projects.json` 文件中的项目信息对象组成。如果您选择一个最近的项目，该信息对象将被传递给openProject: (GSProjectManager)来打开项目。

项目文档

项目文档只是一个常规的GSDocument，其行为与其他任何文档一样。它存储项目的常规信息，如项目名称、游戏标题和版本号。您可以通过 GSProjectManager::projectDocument 函数轻松访问项目文档，或者：

// 使用文档管理器获取项目文档。
varprojectDocument= [[GSDocumentManager defaultManager] documentByType:@"project"];
// 打印项目名称
console.log(projectDocument.items.name):
