详细描述

步进器控件将 CPTextField 和 CPStepper 组合在一个数字输入控件中，右侧带有向上/向下按钮。

以下示例创建了一个新的步进器控件：

// 创建一个宽度为 200px 的新步进器控件。
var stepper = [[GSStepperalloc] initWithFrame:CGRectMake(0, 0, 200, 0)];
// 允许浮点数值
[stepper setNumberFormatterStyle:CPNumberFormatterDecimalStyle];
// 设置最小值、最大值和当前数字值
[stepper setMinimum:1];
[stepper setMaximum:1000];
[stepper setFloatValue:10.5];
// 将步进器控件添加到内容/父视图。
[contentView addSubview:stepper];
