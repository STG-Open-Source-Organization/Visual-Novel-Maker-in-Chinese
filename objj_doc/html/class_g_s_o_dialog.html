+ (GSOWindowController)createDialog: (id) aDescriptor
forItemView: (GSOItemView) anItemView 
实现

根据指定的对话描述符创建窗口控制器。

您只需调用控制器的一个 show 方法即可显示对话框。此方法还需要 item-view，以便能够处理计算出的对话框 UID（uidFormula 属性）和计算出的参数（parameterFormula 属性）。

参数
aDescriptor一个对话描述符。
anItemView调用对话框的 item-view。
返回
新创建的窗口控制器。
