示例：使用组件

 

With 组件，您可以为控件添加特定的逻辑。您可以添加已有的组件或编写自己的组件。如果您熟悉实体-组件系统，您可能已经知道组件是什么。

 

让我们看看下面的例子：

 

{

"类型": "ui.StackLayout",

    "组件": [{ "id": "numberInput", "type": "Component_NumberInput", "params": { "digits": ($ -> $tempFields.digits) } }],

"sizeToFit": true,

"id": "numberField",

"zIndex": 10,

"alignmentX": "center",

"框架": [12, 50],

"dataField": $ -> $tempFields.digits

"template": {

"类型": "ui.FreeLayout",

"margin": [5, 5, 5, 5],

"sizeToFit": true,

"控件": [

{

"类型": "ui.Image",

"图像": "entrybox"

},

{

"类型": "ui.Text",

"框架": [0, 0],

"sizeToFit": true,

"alignmentX": "center",

"alignmentY": "center",

"样式": "numberInputEntryText",

"文本": "0"

}

]

}

}

 

该示例定义了一个文本控件，文本为“New Game”，并为其分配了一个动作。但问题是，文本控件默认不支持单击动作。我们需要首先使用 components 属性添加这种行为。使用该属性，我们可以将多个组件添加到我们的控件中。在我们的示例中，我们只添加了一个类型为“Component_HotspotBehavior”的组件。有了这个组件，我们的文本控件现在支持单击动作，并在我们单击它时启动一个新游戏。

 

如果我们查看脚本编辑器中的“Components”文件夹，我们将看到一个名为 gs.Component_HotspotBehavior 的组件类。这并非偶然，我们使用的 type 属性指的是我们要添加的组件的类名。组件默认需要是 gs 模块的一部分，或者您可以使用 module 属性指定另一个模块。要添加您自己的自定义组件，只需使用其类名并将其定义为 gs 模块的一部分或指定您自己的模块（这是推荐的）。

 

编写自己的组件

在最后一个示例中，我们看到了如何添加一个现有组件来允许文本控件执行单击动作。在本示例中，我们将编写自己的自定义组件来为控件添加一些新行为。

 

class Component_MyCustomBehavior extends gs.Component

# Create your component from optional params-object.

setup: ->

# Setup your component, the object-reference has been set to the control-object.

update: ->

# Implement your update code if necessary.

action_method1: (sender, params) ->

# Implement action logic here

gs.Component_MyCustomBehavior = Component_MyCustomBehavior

 

您上面的示例可以作为您自己的自定义组件的模板。要现在使用我们自己的组件，我们只需编写：

 

"components": [{ "id": "custom_component", "type": "Component_MyCustomBehavior", "params": { "param1": "Hello" } }]

 

id 属性是可选的，但它允许您将您的组件指定为操作目标，以调用您组件上的操作，如示例 6 中所述。params 属性也是可选的，允许您将参数传递给组件的构造函数。
